12 类简化色调（PDF 14）

V / 锐调 / 纯色调（最鲜艳的色调）：彩度最高，看起来鲜艳锐利的色调。

B / 明调 / 明清色调（明亮纯净的）：在锐调的基础上加强了明度的色调。

P / 淡调 / 明清色调（明亮纯净的）：清澈淡淡的色调。

Vp / 最淡调 / 明清色调（明亮纯净的）：明度最高、色彩最淡的色调。

S / 强调 / 浊色调（浑浊的）：比锐调的彩度略低、色彩强烈的色调。

Lgr / 淡弱调 / 浊色调（浑浊的）：高明度、色彩较弱、略显浑浊的色调。

Gr / 涩调 / 浊色调（浑浊的）：低彩度、略显青涩的色调。

L / 弱调 / 浊色调（浑浊的）：中彩度、中明度、色彩较弱的色调。

Dl / 钝调 / 浊色调（浑浊的）：比弱调的明度更低的色调。

Dp / 浓调 / 暗清色调（暗沉的）：比锐调的明度低、色彩浓重的色调。

Dk / 暗调 / 暗清色调（暗沉的）：比浓调的明度和彩度都更低的暗沉色调。

Dgr / 最暗调 / 暗清色调（暗沉的）：明度最低的暗沉色调。
