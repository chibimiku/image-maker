# 原作品分层选样与近重复处理的确定规则

**在看任何指标分数之前**冻结。同一规则用于全部画风，不允许针对某个画风手工挑图。

## 1. 候选池

- 数据源：本地**原作品**目录（pixiv / FANBOX 下载语料），不使用生成图、不使用转载裁剪图。
- 扫描：递归匹配 `.jpg/.jpeg/.png/.webp`，排除含 `.mask.`、`-bak`、`metadata`、`thumbnail` 的文件名。
- 可用性：短边 ≥ 800px；PIL 能解码。
- 上限：每个画风按路径字典序取前 240 张（保证可重复）。

## 2. 冻结属性（`utils/style_experiment_attributes.py`，版本 `style-experiment-attributes/1`）

| 属性 | 算法 | 分类阈值 |
|---|---|---|
| 构图 | OpenCV Haar 正面人脸检测，取最大脸的可见面积占比 | `face_closeup ≥ 5%`、`upper_body ≥ 1.5%`、其余 `full_body_or_scene` |
| 亮暗 | 中部 15% 边距内区域灰度中位数 | `≥ 128` 为 `bright` |
| 背景密度 | 主体掩膜（梯度 75 分位 + 膨胀 + 闭运算）中位于四边环形带的比例 | `≥ 0.85` 为 `busy` |
| 主配色 | HSV 加权（S×V）36 桶色相直方图 + 加权中位色相 | 用于 E2 的配色相近分块 |
| 近重复指纹 | dHash-64 + 16×16 灰度缩略图 + SHA-256 | 见下 |

## 3. 近重复处理

- 阈值：dHash 汉明距离 ≤ 4，或 16×16 灰度归一化平均绝对差 ≤ 0.008，或 SHA-256 相同。
- **只有 SHA-256 完全相同的才会自动剔除**（确定性重复）。
- 其余模糊候选**一律标记为待人工核查**，接触表写在 `PLAN/near-duplicate-review/`，
  由人看图确认后写入 `review` 字段；协议要求的「检测并人工核查后冻结」没有被跳过，
  在人类核查完成前本项记为 `awaiting_human`。

## 4. 分层选择

把可用池按 `(framing, brightness, background_density, path)` **稳定排序**，再按索引奇偶交替分配：

- 偶数索引 → reference（取前 6 张）
- 奇数索引 → query（取前 6 张）
- 其余 → `reserved_e2_pool`（E2 的 P/N 候选池）

这样每个画风的 6 参考 / 6 query 在三个分层维度上尽量均匀，且完全可复现。
实际分布与不平衡都会在报告里如实列出（不声称已完全消除混杂）。

## 5. 同作品规则

- `work_id` = 源文件主文件名（保留 `_p0` / `_p1` 后缀）。
- 同一作品的裁剪、放大、改色、转载视为同一 `work_id`，不得跨 split。
- 本地语料按页（`p0`/`p1`）分为独立作品；未做跨来源的转载比对，报告单列该限制。
