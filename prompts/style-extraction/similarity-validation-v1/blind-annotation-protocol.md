# 人类标注 / 盲评操作协议（E4、E5）

> 这两项**必须由实际人类完成**。模型、agent、脚本都不得代填 `confirmed=true`，
> 也不得替人类在盲评问卷里选答案。未提供时实验只报 `awaiting_human`。

## A. E4 区域标注（两名标注者 + 一人 24 小时后复标）

### 参与者

| 代号 | 要求 |
|---|---|
| H1 | 标注者一，独立看图标注，不看任何指标分数 |
| H2 | 标注者二，独立标注，不看 H1 的结果 |
| H1-repeat | 标注者一在 **≥24 小时** 后对同一批图重新标注一次 |

### 步骤

1. 打开 `E4/human-annotation-entry.html`（单文件，含每张原图、自动候选叠图与该图 SHA-256）。
2. 先看叠图，记下自动候选哪里偏了（眼睑是否压到眼下、发丝路径是否跑到皮肤/衣服），
   再自己按原图重新标。
3. 按 `E4/annotation-brief.json` 里的 `style-regions/1` schema 写 JSON；
   坐标是 **EXIF 转正后**的 0–1 归一化坐标。
4. 核对 `image_sha256` 必须等于该图自身的 SHA-256，`confirmed` 设为 `true`。
5. 保存为 `<image_id>-H1.json` / `<image_id>-H2.json` / `<image_id>-H1-repeat.json`，
   放到 `E4/human-annotations/`。
6. 重跑：`python -u tools/style_similarity_experiment.py run --stages E4`（会读取人工标注并统计）。

### 硬性禁止

- 不给不可见部位补线（闭眼就标 `closed`，遮挡就标 `occluded`）；
- 没有 3 根可读细发丝时 `hair_strands` 留空，**不得**用发束轮廓或衣服边缘替代；
- 不把自动候选直接另存成"人工标注"（这会污染 A↔H1 偏差统计）；
- 标完前不要看 E1/E2/E3 的分数，避免被指标暗示。

### 会被计算的东西

- 自动定位返回率 / 可用率 / 人工确认后完整配对覆盖率与逐项覆盖率（分母含 10 张图，含历史失败图）；
- 眼睑曲线到人工曲线的平均与 95 分位距离，**除以人工眼宽**；
- 头发 mask IoU、发丝采样带完全位于有效头发内的比例、明显跑到皮肤/衣服的路径数；
- A↔H1、H1↔H2、H1↔H1-repeat 的原始分量差异、最终分数差异与排名翻转率；
  闭眼、遮挡、不同视角单列。

## B. E5 盲评（两名人类，各 ≥24 个有效独立题）

### 材料

- `E5/blind/blind-questionnaire.html`：A/B 两图并排，隐藏配置名、槽位、指标与模型分数；
- `E5/blind/blind-map.json`：A/B 位置由固定种子 `20261006` 打乱（**评完后才可查看**）；
- `E5/blind/blind-answers-template.json`：作答模板。

### 作答规则

1. 每题在**相同主体、相同目标画风**的前提下判断哪张更接近参考画风；
2. 允许 `tie`（平局）与 `unknown`（无法判断），不允许不选；
3. 必须记录依据：线条、眼睛、头发、明暗、配色、背景；
4. 问卷含重复题（同题重复出现）用于检验个人一致性，**重复题不计入主统计**；
5. 不得跨主体排序凑题数；不得查看任何指标结果后再改答案。

### 计算的东西

- 两人分歧率、各自重复题一致率（门槛各 ≥80%）；
- 预注册主指标与人类非平局共识的方向一致率（门槛 ≥80%）；
- 按主体组分块的 Kendall tau-b（组内样本足够时）；
- 视觉模型与人类的一致率、主体门禁是否拦住严重主体错误。

### 当前缺口（如实记录）

历史只有 2 张 Gemini 产物，且分属两个不同目标画风，因此：
**有效独立 A/B 题＝1 组组内比较 + 跨画风对照**，远少于 24 题门槛；
补齐需要 E5 的 18 个新增生图槽位（**当前未授权任何付费额度**）。
