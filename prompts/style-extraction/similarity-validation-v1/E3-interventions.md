# E3 受控局部干预定义（与 `utils/style_experiment_synthetic.py` 常量逐项一致）

图样：`1024×1024` 参数化可控正面单脸，抗锯齿由 4× 超采样 + AREA 降采样保证；
脸型、眼睑曲线、虹膜、睫毛、头发区域与发丝路径**由同一组几何参数解析产生**，
标注坐标与像素同源（不使用任何自动定位候选）。

预期主要响应是**该指标贴近度随干预强度下降**（贴近度 1.0 = 与原图完全一致）。

| 干预 | 弱 / 中 / 强参数 | 实现 | 预期主要响应 |
|---|---|---|---|
| 发丝粗细 | 宽度 ×1.15 / 1.30 / 1.50 | 三条细发丝描边宽度缩放，路径不变 | `hair_fineness` |
| 仅发丝断口 | 可见长度缺失 5% / 10% / 20% | 沿路径中点按比例切出缺口，标注保留完整路径 | `hair_continuity` |
| 虹膜亮度 | 虹膜填充灰度 ×0.95 / 0.90 / 0.80 | 只缩放虹膜多边形填充值 | `eye_brightness` |
| 上下眼睑间距 | 眼开口高度 ×1.05 / 1.10 / 1.20 | 绕眼中心缩放上/下眼睑弧高，端点不动 | `eye_height` |
| 单眼宽度 | 两眼各绕自身中心宽度 ×1.05 / 1.10 / 1.20 | 眼弦长缩放，中心不动 | `eye_width` |
| 双眼间距 | 两眼向外各移脸宽 0.005 / 0.01 / 0.02 | 整只眼（含虹膜与睫毛）平移 | `eye_gap` |
| 睫毛笔画 | 固定 2 根可见睫毛宽度 ×1.15 / 1.30 / 1.50 | 睫毛描边宽度缩放 | `eyelashes` |
| 上眼睑弧度 | 两眼端点固定，中段弓高 ×1.10 / 1.20 / 1.40 | 仅上眼睑 `upper_arc` 缩放 | `eye_curvature` |

## 负对照

| 编号 | 操作 | 期望 |
|---|---|---|
| NC1-hair | 头发区域**外**（画面右侧边缘）画一条黑线 | `hair_fineness`、`hair_continuity` 的贴近度必须精确为 1.0 |
| NC2-eye | 眼区**外**（左颊）加一个白点 | `eye_brightness` 的贴近度必须精确为 1.0 |

## 冻结的预期耦合（不要求其他项恒定，但必须逐项报告）

- 改眼宽会同时改归一化眼高比例与上眼睑弧度（弦长变化）；
- 改眼高会同时改眼开口面积与眼亮度的像素集合；
- 加粗发丝会同时改变可见连续支持（`coverage`）；
- 双眼外移会同时改变眼中心到鼻/口的归一化距离（`face_ratios`，诊断项）。

## 未建立受控干预的 5 项（只能作诊断，**不得**宣称已验证）

`iris_ratio`、`eye_highlights`、`lid_weight`、`eye_tilt`、`face_ratios`。

## 限制

这是**机制测试**：证明测量会响应指定几何变化，并证明负对照不被误伤。
它不代表真实插画的效度，也不能推广到未测的画法、视角与分辨率。
