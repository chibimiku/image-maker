画风评估：为什么不能只看 palette

2026-10-06 · 16 个样本（9 个画风 × 多条件）· 三种评估层交叉对比： ① HSV 口径（palette / gram_hsv / render / copy）② 深度口径（VGG Gram / AdaIN / LPIPS / CSD）③ 我逐张看图的多维判读。

1. 结论先说

palette 是颜色直方图距离，不是画风指标：它把「明度基调是否同族」量出来了，但把线条、笔触、材质、留白、构图密度全丢了； 在这 16 个样本上，palette 与我的判读呈 负相关（ρ = −0.39）——也就是说，按 palette 排序会挑错。 真正与判读同向的是深度指标：VGG Gram 距离 ρ = +0.37~0.43、 AdaIN 统计距离 ρ = +0.43~0.45（取负号后）、 以及 copy 风险 ρ = +0.42（高 copy 常伴随「画得更像参考」，但也可能是搬了参考角色）。

6. 以后怎么评（落地建议）

用途用什么不要用什么
快速筛（几十张一批）gram_deep（VGG Gram 距离）+ copy 标记palette 排序、style_score 排序
正式验收深度四指标（Gram/AdaIN/LPIPS/CSD）分别报告 + 我看图的多维判读任何单一自动指标下结论
配色是否同族（粗判）palette 只看「是否 > 0.45」这一档（明显不同族）用 palette 比大小挑最优
内容保真copy + 人工确认是否搬了参考角色/构图只信 copy（同画风相似构图也会高分）

工具：data/test-result/style-lab/eval_style.py（统一评估器）、eval_compare3.py（三层交叉）、 eval_judge.py（多维判读）、make_judge_grid.py（拼对照网格）。
