# refine 背景颜色条款实验（2026-10-08）

用户要求执行上一轮计划。完成旧图验收校准，以及两个固定人物输入各一次「当前背景模板 / 弱颜色锚」对照，共4张。弱条款未在两个输入上同时改善；没有触发条件性的2张复验，也没有进入以眼睛稳定为前提的金边/甲片实验。生产模板及画风配置未修改，未重启应用。

## 方法

输入为前轮 C2 和 R-person 两张人物图；原图用于验收和身份锚，不另附到背景图片请求。模型从当前重绘配置读取为 `gemini-3.1-flash-image`，2K、3:2、每格一次、360秒、无自动重试。走应用的 `generate_image_repaint`，附件会按原有上传规则压缩到2048宽，传输hash在预算slot中保留。

baseline 是当前 `refine-background.md`，以代理人工观察的固定身份锚及背景任务渲染，不新调用诊断模型。weak 仅替换最后一个颜色段，减少对眼睛颜色的强调，要求原色素和暗层不动。其他文字、输入和参数完全相同，2156 / 2128字符。此轮不是全自动诊断链复验，不能证明诊断稳定；每格仅一张，随机性与输入差异不能作因果归因。

提示词全部位于 `prompts/style-tests/refine-background-20261008/`。通用实验入口扩展在既有 `tools/gpt_image2_gen.py --repaint-plan <plan.json> --plan-job <id>`，文本为 `--plan-audit <id>`，支持 `--dry-run`。计划锁定源图/配置/prompt hash，有独立6图3文本硬额度，请求记录独占创建，失败/未知状态不能自动重发；不保存密钥。

## 验收校准

第一次文本判读对旧 D1、D2、R-background 都给出至少一项颜色失败，能阻止整体颜色pass；但 D2 明显更饱和仍 `iris_chroma_preserved=true`，正例字段true又写不确定，逐维语义未校准。实验审计追加明确规则：「保持」指接近输入，增加饱和度须false，不确定也false；不把变化仅仅仍是绿色当作保持。

标注与HSV仅辅助观察：初始共用多边形因几何位移采到边缘，已撤回并保留为 REJECTED 文件。修订标注使用每图两个3×3色素样本，远不足以代表整只眼睛，部分位置仍有边缘/暗层不确定；其统计不用于排序或放行，没有跨画风通用阈值。最终主要依据原像素裁剪与直接视觉比较。
