# App「多图画风提取」流程与字段说明

## 输入与边界

入口是 App 的「多图画风提取」Tab，实现在 `modules/image_analysis/style_analyzer.py`。任务至少需要两张同画风参考图；单图无法可靠地区分稳定画法与某个角色、服装、动作或背景。画风前缀决定结果 JSON 文件名。可导入旧 JSON 续训，也可导入一段旧 Prompt 作为新任务的初始基线。

参考集应尽量覆盖不同角色、发色、服装、动作和场景。如果全部图片都是同一角色与同一构图，即使提示词规定只提取画法，模型仍缺乏足够证据判断哪些特征只是内容。

## 运行顺序

1. **全图共性提取或对账精修**：没有基线时读取 `prompts/style-iter-common.md` 从零提取；有导入基线或上一轮结果时读取 `style-iter-reconcile.md`，保留已证实特征并对全部参考图补充、削弱或删除描述。两者都要求 80% 共性阈值。
2. **单图差异检查**：每轮随机抽取设定数量的图片，读取 `style-iter-refine.md`，检查当前母版与单图之间的差异。单图只提供反例和局部证据，不能单独把某个内容特征写成全局规则。
3. **可选三路测试生图**：每轮先从当时的母版派生模型专用 Prompt，再用同一固定主体和同一张测试画风参考图生成 Gemini 直出、GPT-image-2 首图、GPT 首图经 Gemini 完整画风图重绘三份产物。输出比例自动跟随测试画风参考图。测试请求不再附加配置中任意旧画风，因此结果只评估当前提取画风；三个通道分别失败时互不影响，已有产物仍会保存。
4. **局部裁剪细化**：把每张图裁成头发、面部、上半身、下半身和中央细节区域，再按“同一区域、不同参考图”分批比较，用 `style-iter-local-extract.md` 提取全图阶段不易看清且跨图复现的眼睑、睫毛、发束、手指、衣褶和轮廓线细节，最后由 `style-iter-local-merge.md` 合并回母版。裁剪名包含来源路径哈希，同名参考图不会互相覆盖。
5. **全量最终审查**：把合并后的母版和全部参考图交给 `style-iter-final-review.md`，消除矛盾、重复和少数样本过拟合，生成最终母版。
6. **按模型和场景派生 Prompt 包**：`style-iter-variants.md` 基于最终母版和全部参考图生成 Gemini 完整说明、Gemini 重绘条款、五官头发条款、GPT-image 八字段短版、身份保持强度、肖像/全身/环境场景配置、负面规则和证据摘要。

## 结果 JSON

`<画风前缀>_style_iter_result.json` 保存：

- `iterations`：每一步的输入基线、差异、修订结果、置信度与模型。
- `test_images`：每轮使用的画风母版、当轮模型专用 Prompt 包、固定主体 Prompt、测试画风参考图，以及 `gemini_direct` / `gpt_first_pass` / `gpt_repainted` 三组路径。状态重建会保留全部轮次，不再只剩最后一次。
- `final_art_style_prompts`：最终完整母版。
- `prompt_variants`：各模型与场景的派生版本。
- `prompt_variants.style_entry`：可写入画风配置的明确映射：`prompt`、`prompt_gpt`、`repaint_clauses`、`face_hair_clauses`、可选 `motif_clauses` / `motif_enabled`、`enabled`。GPT 八字段短版校验失败时，`style_entry.prompt_gpt` 留空，并在 `gpt_image_prompt_errors` 中说明原因，避免把不合规短版送入首图链路。

`face_hair_clauses` 是分析资料字段；当前完整重绘真正使用的是 `repaint_clauses`，所以后者本身仍必须包含眼睛、脸型、发束与轮廓线规则。需要启用额外五官修订时，应先人工复核参考角色泄露风险，再在画风配置中设置 `face_hair_refine=true`。

## 结合现有 Gemini 重绘经验的检查重点

- **身份与画法分开**：眼睛形状、眼睑线宽、虹膜层次、脸型抽象和发束组织可以提取；具体瞳色、发色、服装、姿势、道具和背景不能成为画风强制项。
- **颜色写关系而非色样**：优先写冷暖组织、明暗分离、饱和度和局部反光规律。只有样本确实跨角色仍稳定时，才把某个色域列为强共性，避免 Gemini 把参考角色配色搬入源图。
- **线条需要层级与连续性**：分别描述外轮廓、主结构线和内部纹理笔触；明确长线连接、收尖、线重与允许消失的边缘。只写“精细线稿”容易增加碎线。
- **二维面部与三维材质可拆开**：像 inf-nikki 一类混合画风，应单独描述面部抽象程度和环境/PBR 维度，防止“UE5”把脸推成真人。
- **构图变化必须是可选策略**：Q 版、海报式重构或大留白若不是大多数样本共同规律，应放进 `usage_profiles.transformative`，不要写进默认身份保持版。
- **重绘条款必须保护源图真值**：条款应说明如何重画，同时明确保留源图身份、固有发色瞳色、服装、姿势和构图；确有授权设计变化时再单独配置。
- **装饰母题只进入首次生成**：蝴蝶、花瓣、邮票边框、几何符号等可放入 `motif_clauses`，但必须少量、可省略、从属于主体，并限定在兼容场景的背景或边缘。兽耳、发饰、固定服装、人物物种、家具和整片环境不是母题。Gemini 重绘不使用该字段，避免凭空改变源图内容。

## 已知限制

固定比例裁剪默认假设主体大致位于画面中央；主体偏置、多人图或极端构图可能让局部裁剪错过目标。80% 阈值由提示词与多轮对账约束，当前没有计算机视觉层面的硬投票。最终 Prompt 包仍需在至少一个固定主体上跑三路测试，才能确认画风贴合、角色泄露和线条连续性。高完成度参考图不一定是最安全的参考图：强角色、服装或场景符号可能被 GPT 首图和完整参考图重绘复制，必须分别评价画风贴合与主体保持。
