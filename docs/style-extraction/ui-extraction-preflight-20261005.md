# DeepSeek 选图 → UI 提取流程检查（2026-10-05）

## 检查结论

现有选图契约及 UI 启动链路可用。检查并修复了候选导入和选中版本续训时丢失重绘参考模式的问题；导入正式画风前重新校验 GPT 短版实际文本，不仅信任结果中的 valid 标记。历史结果没有重绘模式时保持历史 `style` 模式，新运行默认 `none`。

续训种子保留选图清单来源，并按选中候选恢复重绘模式。自动比较 tooltip 改为准确的分批请求说明，不再声称只调用一次 API。

相关 53 项不联网回归全部通过，包括：清单元数据/覆盖率/重复图校验、图片复制与源目录保留、导入后实际点击 UI 开始按钮的任务参数、首次 5 轮、每轮默认检查 4 张、三路提示词字段、无效短版阻止 GPT 请求、source-only 重绘、部分失败提示、评分覆盖校验与缓存、旧结果续训、NPU 指标状态及报告。修改的 Python 文件通过编译检查。

这次没有为另一个风格调用在线 API；本地测试保证流程接线和错误处理，不能保证服务可用、模型评分稳定或所有参考内容复制都能被自动门禁识别。

## 新风格的操作顺序

1. 让具备识图能力的 DeepSeek 按 `style-dataset-curator` skill 审查源目录，交付 UTF-8 `selection-manifest.json`，版本为 `image-maker.style-dataset.v1`。清单须覆盖范围内全部图片，推荐约 12 张同画法、内容有变化的成稿，指定代表参考图。不得编造哈希或把未审查项标成完成。
2. 重启 app，打开「多图画风提取」→「导入 Agent 筛图清单」。检查导入预览和推荐参考图，确认英文画风前缀。入选图会复制到独立数据集目录，源图保留；导入会清除上一风格的训练状态。
3. 首次保持 5 轮、每轮检查 4 张，填写一个固定测试主体。若入选少于 4 张，调低每轮检查图片数。勾选每轮测试生图、完成后自动比较、自动深度指标；设备保持 NPU 优先。重绘附画风图默认关闭。
4. 点击「开始多轮迭代画风提取」。5 轮及终审版本各有 Gemini 直出、GPT 首图和 GPT 首图的 Gemini 重绘；每一路会记录成功、失败或未执行原因。先检查两套图片 API 节点和文本视觉 API 的模型/key 配置。
5. 跑完观察比较报告中的 12 维证据、主体门禁及四项深度指标。评分覆盖失败会显示“未选型”，可重试比较，复用已完成批次，不重新生图。NPU 指标成功不等于视觉复核成功。
6. 手动选中已测试候选后加入画风列表；不要假定 round5 或终审必然最优。正式导入会保留该版本的重绘模式。需要增量分析时，选中版本后继续迭代，默认新增 3 轮，生成新的运行目录。

当前 UI 新风格流程不执行合并验证工具的跨包请求复用：各轮各自生成测试图。`style_merge_validate.py` 是额外的跨轮字段组合验证工具，其独立重复和配对复用修正不能被误解为 UI 会把两轮共用一张图。
