## 候选材料

`prompts/wardrobe/reference-study/` 已留下完整转化共同条款、五类衣装候选条款、专用 extract-wardrobe 模板。共同条款允许改变原服装类别和剪裁；明确保留衣物的用户要求仍优先。人物、体型、画幅、场景不从素材迁移；颜色和标志配饰保留；近景仅设计可见衣物部分。

候选条款是根据抽样观察整理的初稿，其中需要独立验证的设计建议不能称为全量数据共性。模板未接入生产、没有联网提取或生图，不因提供这批参考图就复用 Round3 的收费额度。

已有画风提取流程可复用清单、抽样、分批看图、证据对账、缓存和跨轮报告；提取字段、比较对象及终审必须更换为衣装结构。不能复用画法八字段或艺术风格深度相似评分作为衣装类别门禁。测试首先验证完整衣装类别、剪裁结构、用户颜色/配饰与人物条件，再比较装饰风格；姿势和画幅只作独立约束。

## 下一步材料研究顺序

先从每个主要系列挑结构可见、设计互异的 12～20 张，另外保留跨类和不完整衣装样本做反例；补足横图与竖图，不让 portrait 的数量优势决定共性。Chinese/Japanese 单独复核具体上身、袖、腰、裙的连接，以防退化为普通旗袍或和服。筛样阶段不能仅按颜色或标签自动确认为正例。

小规模测试可使用同一成熟人物、同一构图和不同原衣物（卫衣/工装/制服），分别套五类完整转换，检查不再只是原衣物加蕾丝。三大系列优先，文化融合随后；固定人物颜色锁的对照可以检验子风格是否依赖颜色。当前仅规划，没有启动新实验。

抽样图集与清单均位于 `data/test-result/20261005/wardrobe-reference-study/`，保留原图映射便于继续复核。生产模板不变，不需要因此重启 App。
