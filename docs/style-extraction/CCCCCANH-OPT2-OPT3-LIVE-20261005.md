## 为什么继续小修

opt2 的柔亮 GPT 重绘保住了粉发、棕眼、米色衬衫、蓝裤、棕色平底鞋、石凳与双脚，脸部和细发束比直出更有参考画法的特征。暗景 GPT 重绘也增加了柔和色面，但继承首图左下角签名样痕迹，并把黑色内搭领口抬高。

opt3 保留 opt2 的主画法，只改以下内容：

1. 禁止文字、签名、水印和角落签名样笔划；重绘清除这类生成痕迹。
2. 锁定领口、领子开口、袖长、闭合方式和鞋型／鞋跟。
3. 修正被首图和重绘共用的条款：新图的内容来自请求描述，重绘的内容来自生成源图；画风参考图始终不提供人物或场景事实。原 opt2 的“source image is the sole content truth”在仅附画风图的首图请求里容易产生歧义。

GPT 八字段短版 571 字符，项目规则校验通过。母题与额外五官头发修订继续关闭。

## 同步修复的代码

`modules/others/api_backend.py`：

- 当 generations 明确返回 image 字段 unsupported／unknown_parameter 时，直接进入既有 edits 回退，停止无效的同体重试。其他原有重试和拒绝拦截保留。
- edits 使用 multipart 的 image[] 文件，不把 generations 的 base64 image 再作为普通表单重复提交。
- 同一批 save_dir 收口还在 whatai 成功分支留下未赋值问题，补回 `resolve_save_dir`，避免已经拿到响应后保存失败。

新增测试验证一次 generations 拒绝后仅一次 edits、表单不重复含 base64，以及 whatai 实际下载保存到指定绝对目录。相关五组测试合跑 **213 passed**；修改的两个 Python 文件 py_compile 通过。未改画风 GUI 布局或通用重绘固件，未重启在运行的 app。
