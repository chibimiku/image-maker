## app.py 入口的流程变化

- 首次默认 5 轮，每轮检查 4 张；打开历史结果默认新增 3 轮，并恢复检查数、测试主体、参考图。
- 每次运行创建独立绝对目录，避免生图后端重复拼接日期目录；打开历史不改写源 JSON。
- 续跑将旧终审图归档为独立比较阶段，局部细化、终审和进度使用累计结束轮次。
- 分析超时至少 600 秒，低合并置信度在日志及报告中展示。
- 视觉比较每批最多 4 个候选，各批使用全部源图；成功批次缓存，后续批次失败可重试复用。同分提示人工观察，不能用 ID 排序代替选择。
- 默认自动接续独立深度指标，沿用 NPU 优先；手动取消比较时不自动启动深度计算。结果仍由用户观察报告后选用。

操作与字段见 [界面流程说明](../style-analyzer-workflow.md)。跨批次视觉分仍可能有校准误差；新的分批策略尚未重新在线验证 taya_oco，测试只验证编排、缓存、恢复与报告行为。
