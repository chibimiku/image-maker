# 深度指标界面集成与真实图片验证 · 2026-10-04

读取 DeepSeek 的 `style-metrics-report-20261004.md` 后，实际加载既有模型，对 millon-knots 的 12 张源图与 16 张各轮/终审候选图逐张比较。原图、原候选图、原画风选择均保留；没有请求生图或视觉评分 API。

## 界面操作

重启 app → 多图画风提取 → 打开训练结果 →「计算深度指标」。默认「NPU 优先」依次检查 NPU、CUDA、CPU；NPU 可用时不调用 CUDA 探针。若希望绝不占用 GPU，选择「仅 Intel NPU」，该模式不可用时报告错误，不回退到 CUDA。

「深度指标」表显示全部候选的 CSD↑、Gram↓、AdaIN↓、LPIPS↓均值和覆盖率；选择一行可读逐参考图原始数值。「查看深度指标报告」提供离线自包含 HTML，包含源图、候选图、参数、实际权重哈希、预处理、同图自检与实际设备证据。已有视觉评分时也更新视觉报告的算法状态和指标表。手动选择与从某轮续训继续使用视觉比较页，不用未经主体审查的深度指标自动改画风。

计算在独立进程，避免 GUI 先加载 Qt/ORT 后导入 torch 的 DLL 问题；模型随子进程结束释放。取消会停止子进程，训练 JSON 与指标 JSON 使用原子替换。GUI 实测启动子进程、回读 16 行、完成后恢复按钮均通过。1100×750 默认窗口布局验证通过；本环境 offscreen 截图字体呈方框，因此没有声称完整验证 Windows 原生字体显示。

## 固定口径

- 参考集：训练 JSON 的全部 `dataset.images`，本次 12 张；候选：全部各轮/终审已生成图片，本次 16 张。
- 每个候选逐张与全部源图比较，参考图等权，报告算术平均、中位数、最小/最大值。
- 配对缺失/非有限值/同图自检失败时，不给该指标完整均值；保留错误，不当 0 分。
- 四种指标分别报告，不换算相似度百分比，不和视觉评分混合排序；LoRA training loss 仍不适用。
- VGG-19 固定 512×512 方形拉伸，Gram 五层、AdaIN 四层；LPIPS-Alex v0.1 固定 256×256 方形拉伸；CSD 官方 style head、224 短边缩放与中心裁剪。具体参数及实际权重哈希写进结果。
- Gram **沿用部署实现**：`G=FFᵀ/(C·H·W)`，每层贡献 `||G₁−G₂||²/(4C²)`，再逐层求和。这是项目的额外通道归一化距离，不能声称等同于 Gatys 原论文的标准 style loss。未悄悄修改已部署模型指标。
- 缓存包含图像内容 SHA-256、实现代码、实际权重 SHA-256、模型/预处理、运行库版本、实际设备名与精度。缺失/失败结果不作为成功缓存。优先策略变化但实际设备与精度相同可复用成功缓存，更新实际选择说明。

## 实测证据

结果位于 `data/20261004/style-extraction/millon-knots/`：

- `deep-feature-comparison-cuda-fp32.json`：四项全部成功，192 组真实配对。
- `deep-feature-comparison-npu-fp16.json`：四项全部成功，192 组真实配对；GUI 默认选择 `auto-npu`，实际 `npu`。
- `deep-feature-comparison.html`：当前 NPU 报告，包含全量数值与图片。
- `millon-knots_style_iter_result.json`：增加 `deep_feature_comparison`，原有提示词及生图记录保留。

NPU VGG、LPIPS、CSD 的执行证据均为 `execution_devices=["NPU"]`。Gram/AdaIN 通道统计和 CSD 点积在 CPU，不声称所有运算都在 NPU。对一张真实源图自比：Gram=0、AdaIN=0、LPIPS=0、CSD=1；均满足部署时既定容差。NPU FP16 与 CUDA FP32 为独立版本，不合并记录。

本次全候选均值跨设备最大绝对差：Gram `2.9152e-8`、AdaIN `0.021584`、LPIPS `0.00014986`、CSD `0.00070903`。这些是该集合的观察值，不证明所有图片或设备等价。

默认 NPU 优先重复运行已验证命中成功缓存，无重复推理。最初沙箱无法读取用户级 lpips/clip/pytest，前两项可跑、后两项如实报缺失；获得目录访问后四项均跑通。没有重复安装包、修改驱动或调整系统环境。

## 内容混杂的实际观察

CUDA 数据中 CSD 均值最高的是 `final/gpt_repainted/0`（约 0.6912），其 LPIPS 均值也最低（约 0.5306）；Gram/AdaIN 最低是 `round_2/gpt_repainted/0`。这与先前选择 `round_5/gemini_direct/0` 的主体保持判断不同。原视觉检查发现部分重绘带入参考角色颜色，因此“深度特征更接近”不能单独推翻主体检查或证明更适合导入。未修改现有 millon-knots 配方。

CSD 上游权重免责声明、中心裁剪缺失边缘、所有指标受内容影响、没有人工偏好校准等限制继续保留。
