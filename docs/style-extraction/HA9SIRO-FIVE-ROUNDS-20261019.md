## 可审阅的画风描述

- **线条**：以连续、细薄的局部色轮廓组织发束、脸缘和材质边；细发束边常叠窄亮丝。较强线重集中于上睑、睫毛根和关键遮挡，不能泛化为全图粗外轮廓。
- **色彩**：浅白/灰中性色承担空气感与亮值，蓝紫冷影对粉/珊瑚/橙金反光；局部允许高饱和的棱彩过渡。人物原有发色/瞳色和服装固有色仍需保持。
- **光影**：平滑明暗面与硬边小亮片、星点和窄反光带并置；辉光集中于焦点和边缘，外围有选择的失边/光学柔化，保留暗缝与遮挡层次。整幅彩虹滤镜不能替代结构。
- **构图**：肖像以脸眼和前景材质建立焦点，常有遮挡及斜向引导；全身补充则以大轮廓、留白和明暗底色形成层级。道具种类及翼形内景为可变题材，不要求复制。
- **材质**：皮肤大面低纹理；头发为连贯细束与窄条亮边；反光硬材质可有明确反光/折射边界，布料按实际材质保持漫反射、褶皱与透明度，不能一律变玻璃/金属。物体内部完整风景属于系列视觉母题，不是每种材质的物理规则。
- **人物**：虹膜在眼裂中占比高、近圆，细环带/放射纤维/不规则小色片叠加，中心可亮白、反光或图案化，配星芒/圆点等有组织高光；鼻口简省、颊颌平滑紧凑。具体瞳色、白色睫毛、垂直瞳孔等不是全部样本的强制共性。

**生成限制**：当前结果较好迁移了高亮动漫、细发丝和冷暖反光，但绿眼往往仍是普通渐变＋少量白点；参考的高频虹膜色片和亮心结构没有充分复现。自动复评给出的眼部分数8/9偏宽松，不作为人工眼部相似度验收。
