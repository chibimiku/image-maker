# DeepSeek 受控实验结果复核（2026-10-06）

复核对象：`DEEPSEEK-SIMILARITY-CONTROLLED-RESULTS-20261006.md` 与 `data/test-result/20261006/style-similarity-controlled-v1/run-20261006-01/`。

**结论：已有实测数据有价值，但现有报告不能作为严格验收结论。发现统计方向、实验配对、曲线误差定义及冻结/重试约束问题，需要修订。当前仍不足以证明画风方案可靠，也不能根据这份报告断言大多数局部测量失效。**

本次没有修改生产计算函数或原实验结果，没有发出任何接口请求、没有重启 app。复核现有数值/代码、48张图像hash、定位叠图，并重跑现有21项本地实验回归（全部通过）。测试目前不覆盖 E2/E3 的核心统计判定，故21项通过未发现下述错误。

## 1. [P1] E2 正确偏好方向反了，且实际配对不符合协议

位置：`utils/style_experiment_controlled_phases.py` 的 `e2()`、`e2_stats()`。

协议要求比较 anchor→P 与 anchor→N。实际程序用 P/N 作候选，与各画风的6张参考图比较，再取 P/N 对 anchor 所属画风参考集的均值。anchor 本身没有进入这两组配对，request 中的 anchor 字段只记在账本。这是不同实验，不能冒充原协议的直接困难对照。

统计代码又把方向写反：CSD 正确条件应 P>N，却用 `second-first > 0`；距离正确条件应 P<N，却用 `first-second > 0`。tone/edges/lines/space 也不能全按距离方向处理，应读冻结的 METRIC_DIRECTION。

对**现有错误配对定义下的同一数值**修正方向，结果为：

| 指标 | 原报告正确数 | 修正方向后正确数（分母12） |
|---|---:|---:|
| Gram | 3 | 9 |
| AdaIN | 3 | 9 |
| LPIPS | 6 | 6 |
| CSD | 2 | 10 |
| tone | 9 | 9 |
| edges | 5 | 5 |
| lines | 3 | 3 |
| space | 4 | 4 |

四个本地贴近度原代码恰好用了适合相似度的差值，因此其现有判定数值不反转；但统一宣称“距离”仍错误。
**10/12不能用来宣称协议E2达标**，应保留为参考集诊断，另算冻结 anchor→P/N 的24个直接配对。P/N选择由自动代理完成、缺人工背书，需保留原偏离说明。

撤回“困难对照仅2/12，因此极可能只匹配内容/配色”的依据；混杂风险仍须通过正确对照验证。

## 2. [P1] E3 混淆原始分量与贴近度方向，并错排亮度剂量

位置：同文件 `e3_stats()`、`_direction_series()`、`_monotonic()`。

- 加宽眼睛等干预让原始宽度增加，但相对于原图的贴近度应该下降。代码把 increase 用到了 closeness，导致眼高、眼宽、眼距、弧度等正确响应被系统性判失败。
- 亮度倍率按数值升序排列，得到原图→0.80→0.90→0.95，即强→中→弱；应按 original/weak/medium/strong 固定顺序。
- `_monotonic()` 丢掉 None 后仍能给出 pass，缺强档测量不能算完整通过。常数序列也不能证明真实响应，需要同时核查原始分量与非零变化。
- 原图行把所有面部项硬写为1/ok，而未看 descriptor 是否可用；whole_image 同样全部硬写为1，Gram/AdaIN/LPIPS 的同图距离应为0。基线必须来自共享函数与实际有效状态。

复核保存数值，按剂量名称排序、要求4档完整、贴近度非递增且强档比原图至少下降1e-6，得到以下**诊断性重统计**（不代替完整原始分量验收）：

| 干预 | 完整单调下降且有响应 |
|---|---:|
| 发丝粗细 | 2/6 |
| 发丝断口 | 6/6 |
| 眼睛亮度 | 6/6 |
| 上下眼睑间距 | 6/6 |
| 眼睛宽度 | 6/6 |
| 双眼间距 | 6/6 |
| 睫毛粗细 | 3/6 |
| 上眼睑弧度 | 6/6 |
| 合计 | **41/48＝85.4%** |

原“12.5%”不能保留为有效失败率。修正后仍未达90%门槛，且发丝粗细/睫毛存在反向波动或缺失，确实需要排查。示例 E3-PU-02 发丝贴近度为1→0.881→0.789→0.830，中到强反而更近。

保存的负对照12/12都是pass；报告结论却说“未全通过”，原因是报告从 gate 内读取不存在的 negative_controls_passed，而值在 analysis 顶层。应修正报告字段，不重做图片。

## 3. [P1] E4 把采样点密度差异计为曲线偏差

位置：同文件 `e4_geometry_against_truth()`。

解析真值有65个眼睑点，自动候选通常较少。程序对每个真值点取“最近候选顶点”距离；即使候选折线沿正确曲线，顶点之间的真值点仍会被罚。这不是到曲线的距离。

使用同一已保存图/区域进行点到候选线段的几何复核，E3-PU-01 的四条眼睑平均偏差从约5.1–5.4%眼宽降为0.93–1.64%；其他案例仍有真实偏差，例如 E3-PU-03 上眼睑约7.1–7.4%。因此不能引用原4.8–9.5%范围作为准确曲线误差。

正式修订应统一曲线重采样与点到折线距离，补对称距离、端点误差和95分位，不以本次单向均值替代完整定位验收。当前真值复核未算头发IoU/采样带有效率（hair字段为空），还不完整。

真实 Gemini 的叠图已检查：发丝路径仍有明显穿过脸、颈与衬衫的情况；自动定位不宜作为默认可靠输入。这项风险没有因误差计算修正而消失。

## 4. [P2] 冻结不足以保证本次代码可追溯

- 48张 E1 图片 SHA-256 均匹配；四画风 reference/query 的 work_id 无交集。这支持数据未被替换，但不等于作者来源与模糊近重复已经人工验真。
- `PLAN/code-freeze.json` 与当前文件不匹配：`utils/style_experiment_controlled.py`、`utils/style_experiment_reports.py`、`modules/image_analysis/style_comparison.py`。
- 冻结清单遗漏决定E1–E5统计的 `utils/style_experiment_controlled_phases.py`，以及实验CLI等关键执行代码。load_plan/run没有验证冻结hash。

不能据此指控有意挑结果，但“同一冻结代码严格执行”无法成立。应记录每次修订的代码hash、影响阶段及缓存兼容性；原包不可原地重新freeze。只修改统计可复用原配对值，但必须标新统计版本；涉及视觉提示词/排序实现的变更另记版本和已产生请求。

## 5. [P2] 重试上限被按CLI运行重新计数，账本也不能等同HTTP次数

`with_retries()` 每次调用把局部 attempts 归零，只累计 attempt_id；同job可再次获得3次尝试。报告明确把协议解释为“单次运行最多3次”，与协议要求按job恢复不重置相违背。例如 `e5:review:puracotte:dataset` 有6条failed记录。

该job说明是本地接线失败，不能仅凭6条failed推断6次实际收费；缓存命中也可能被外层记录为ok/可能收费。当前账本无法准确区分外层调度、SDK内置重试、实际HTTP发送、本地失败与已复用结果。

应按稳定job＋request hash累计外部发送次数和重试额度；本地修复重算可独立分类，不得重置外部额度。收窄异常类别，区分确定未发送、状态未知、拒绝、格式错、可重试服务错误；收费状态未知先查证再补。保留所有原记录，不按本次审核再次调用接口。

## 6. 哪些现有结论可保留

| 项目 | 复核意见 |
|---|---|
| E0 16项记录通过 | 可保留测试记录；“进程重启复算”实际主要为同进程新缓存目录计算，证据不等同重启测试；未补齐所有面部入口一致性 |
| E1 CSD 16/24＝66.7% | 当前未发现方向错误；Wilson区间约46.7–82.0%，未过预注册80%门槛，仍是有限试验集诊断 |
| E2 CSD 2/12 | 撤回；方向反了且配对不符协议 |
| E3 12.5%、仅连贯性有效 | 撤回；修正后的数值支持多种几何/亮度响应，但粗细/睫毛仍需排查 |
| E4 自动定位可用4/8 | 这是程序descriptor覆盖定义，不是人类确认精度；真实图错误明确存在，曲线误差数值须修订 |
| E5 已完成4次视觉复核 | 实际是2张历史产物×2参考顺序，不是4张独立产物；每风格1候选，“最佳未变”不能验证排序稳定性 |
| E5 Sakurapion 主体不符门禁 | 保存响应依据为露出双手、违背“不示手”；可保留为该模型的审计结果，不等同人类共识 |
| 人类/新增生图尚未提供 | 正确标待项；不能宣布E0–E5已全部验收完成 |

## 7. 下一轮顺序

1. 先修实验统计和报告，不优先改生产相似度公式；为E2相似度/距离方向、E3完整剂量排序/缺失/原始分量、E4同曲线不同采样密度、累计重试上限补有实际反例的回归。
2. 保留原结果，发布带hash的新审计/统计版本：用已有数值修E3及报告；E2在冻结P/N上计算24个正确直接配对，单列原参考集诊断；E4几何误差本地重算。
3. 再决定生产算法的优先改进：发丝/睫毛宽度采样稳定性、真实图定位准确性、全图混杂辨别。不根据当前错误失败率一并推翻局部算法。
4. 人类标注与盲评、原作品来源/近重复核查、确认集仍独立列待项；无需为了修统计重复成功生图或补发视觉请求。

本审核不将85.4%诊断值当新验收通过声明；正式验收还要满足原始分量响应、完整覆盖及新版本追溯。
