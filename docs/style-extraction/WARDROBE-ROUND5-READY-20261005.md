## Round5 矩阵

冻结包：prompts/wardrobe/round5/generation-pack.json；每通道 14，合计 28；文本/视觉收费调用 0。人物仍为 32 岁、棕色皮肤、短棕发、黑框眼镜的成年女性，灰背景全身双脚可见，以保持 Round4 对照。不能代表多人物/多场景泛化。

| 槽位（各通道一张） | 目标与策略 | 重点 |
|---|---|---|
| GP / GF | Lolita 古典 replace / 哥特 fill_missing | 保留完整制服/工作服，不能加裙或蕾丝 |
| LP / LF | 成人内衣 replace / fill_missing | 显式保留与完整已穿衣装时不能改内衣 |
| HA / LA | Lolita 甜美 / 成人内衣 reinterpret | hoodie+jeans 类别保留；已有 camisole+boyshorts 类别保留 |
| UC / HC | 甜美 fill_missing / replace | 衣装未写时补完整裙装；橙 hoodie 真正转化 |
| LC / LU | 成人内衣 replace / fill_missing | 橙色目标上下装与鸟胸针；衣装未写时完整补全 |
| C-waterink / C-kishida 各 image/text | 同衣装与画风文本，只改图附件 | 分别检查皮肤、背景、双脚与衣装 |

画风四组附件对照的请求正文与 params 字典完全相同，GPT 两档都用 generate；文字包含相同参考角色排除条款。图附件为空时这些排除条款保留，因此这是“同一文本下附件效果”的实验，不是生产各默认参考模式总体胜负。Gemini 两档同样保留相同 instructions/post_instructions。结果比较需先看身份与场景，再看画法；有图相似度不能抵消肤色与构图漂移。
