1. **明暗分支被软化。** 完整文本大量使用“可暖可冷、可柔可强”的宽泛选项，短版则以 ivory haze、pearly diffuse glow 为重心。源集中的暗色块、强局部反光和更鲜明的结构边界没有同等表达。应把柔亮与暗色强对比分成可选使用场景，共享脸、发束、笔触与边缘规则。
