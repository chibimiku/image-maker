# 画风评分 v2：研究依据、权重及边界

本项目的“训练轮次”是参考图分析、提示词修订与测试生图的迭代，不是更新模型权重的 LoRA 训练。报告的 `style_score` 是视觉模型按量表判断的 0–10 分。它没有被校准为人类相似度或百分比，也不能被称作 Gram/LPIPS/CSD 实测值。

## LoRA 的 loss 到底是什么

[LoRA（Hu 等）](https://arxiv.org/abs/2106.09685) 用低秩矩阵表示可训练权重增量，例如冻结原权重 W，学习缩放后的 BA 增量。它没有定义一项通用的“画风 loss”；优化目标由被微调模型与任务决定。

[DDPM（Ho 等，§3.4）](https://arxiv.org/abs/2006.11239) 的简化目标为随机时间步和随机噪声下的噪声预测均方误差：`E[||ε − εθ(x_t,t)||²]`。[Latent Diffusion（Rombach 等）](https://arxiv.org/abs/2112.10752) 将扩散过程放在编码后的潜空间。[Diffusers 官方 LoRA 示例](https://github.com/huggingface/diffusers/blob/main/examples/text_to_image/train_text_to_image_lora.py) 根据 scheduler 预测目标选择噪声 epsilon 或 velocity，并计算 MSE。不同模型也可能使用其他目标，不能把所有现代图像 LoRA 都归为同一种 loss。

[Min-SNR（Hang 等）](https://arxiv.org/abs/2303.09556) 对时间步损失加权，目标是减少不同时间步的优化冲突。在官方示例中，epsilon 分支与 velocity 分支的权重分母不同。因此，不同噪声目标、时间步采样、加权、数据和预处理下的 loss 不宜直接跨运行比大小。由训练目标本身可推知：训练 loss 并非独立测量生成图画风相似的指标；下降还需用固定验证图、内容保持与泛化检查解释，不能单凭最低 training loss 选艺术效果最好的版本。

这里没有 VAE latent、随机噪声与时间步、可训练权重、模型噪声预测或训练日志，真实 training loss 标为“不适用”。禁止用 `10−style_score` 冒充 LoRA loss。

## 值得参考的图像指标

**2026-10-04 部署后更新**：下表“本次未计算”记录最初的视觉评分实现状态。现已通过 `utils/style_metrics` 部署并接入本地逐张计算，CUDA/NPU 都在真实 millon-knots 12×16 图片集合上运行成功，详见 [集成验证记录](deep-metrics-integration-20261004.md)。视觉量表仍独立于四项深度指标；未引入未校准的合成总分。Gram 沿用部署实现的额外通道归一化，报告写明精确公式，不能冒称其数值等同于论文原始 loss。

| 方法 | 算法要点 | 本项目能借鉴什么 | 边界与计算状态 |
|---|---|---|---|
| [Gatys Gram style loss](https://arxiv.org/abs/1508.06576) | 比较多层卷积特征通道间的相关统计 | 多尺度笔触、纹理与画面统计，不只看角色相似 | 要加载特征网络；本次未实现/未计算。不是纯粹的身份或动漫脸型判断 |
| [AdaIN（Huang、Belongie）](https://arxiv.org/abs/1703.06868) | 对齐深度特征通道均值和标准差 | 分离内容结构与画法统计、观察材质/质感规律 | 特征统计不等于原图 RGB 均值；本次未计算 |
| [LPIPS（Zhang 等）](https://openaccess.thecvf.com/content_cvpr_2018/html/Zhang_The_Unreasonable_Effectiveness_CVPR_2018_paper.html) | 学习感知特征距离，使用人类图像差异判断评估 | 同内容图/同区域的感知差异复核 | 不同角色、姿势、构图会混入内容差异；不直接把 `1−LPIPS` 当画风百分比；本次未计算 |
| [CSD（Somepalli 等）](https://arxiv.org/abs/2404.01292) / [官方代码](https://github.com/learn2phoenix/CSD) | 专门训练的对比式画风描述子，用于风格检索和归因 | 更直接面向画风而不是一般语义相似；颜色、纹理、形状需要联合看 | 需要官方权重和预处理，检索基准效果不证明本项目的动漫素材已校准；本次未计算 |

这些论文支持把画风与内容分开、多层次考察画法的方向。下面的 12 个可解释视觉维度和具体权重是项目设计，不是论文定义或验证的“标准画风分”。当前不自动安装包或下载权重，缺失算法指标不会置为 0，也不参与总分。若以后接入实际特征指标，应单独记录模型/权重哈希、预处理、参照集合聚合方式及 raw distance，完成内容变化与人工偏好校准后再决定是否纳入排序。

## 固定量表 v2

| 等权组（各占 20%） | 组内等权维度 | 比较内容 |
|---|---|---|
| 线条与边缘 | 线条笔触、边缘层级 | 线重、收尖、连续性、硬软消失边缘与内外线强弱 |
| 五官与头发 | 脸型抽象、眼睛画法、发束组织 | 脸部平面与简化、眼睑虹膜高光、发束层次；排除角色身份及固有颜色 |
| 明暗与光照 | 明暗塑形、光照处理 | 色块/渐变和接触阴影、辉光/反射/轮廓光规律；不复制光源位置 |
| 配色逻辑 | 配色逻辑 | 冷暖、明度、饱和度、色彩阴影与重点色的关系；不要求同发色同服装色 |
| 表面与层次 | 纹理质感、材质响应、细节层级、背景画法 | 肌理、皮肤布料金属等的抽象画法、微细节分布及背景简化方式；不复制场景 |

组内取平均，再对五组取平均得到 S，总分仍为 `0.85×S + 0.15×主体符合度`。分组避免仅因把某一项拆成更多子项而增加它在总分中的比重。每项必须返回源图可见依据、候选可见依据与差异；悬浮分数可读证据，报告展示全部证据、组分与论文。无法看到必要区域时标 uncertain，禁止编造不可见细节。

参考内容抄入、重大结构缺陷、明确主体不符、不确定四类门禁继续独立于数值。源画法本来简单就不因“细节少”扣分；源画法本来平涂就不因缺少写实塑形扣分。总分由本地 Decimal 计算，显示三位小数，排序使用未舍入值，同分按候选 ID。

## 升级与验证

评分模板改为 `prompts/style-comparison-v2.md`，输入摘要包含版本与模板，旧 v1 缓存不能冒充 v2。旧五项结果仍可在界面读取；升级需点击“比较并选最佳”重新评分既有测试图，不必重新生图。v1/v2 数值不要作为同一尺度直接比较。

已验证十二维分组权重、逐项证据缺失拒绝、旧版结果解析、缓存复用、报告参数/来源/状态及默认窗口按钮布局。新模板的模型响应通过 mock 验证，未在线重新评分既有画风图，尚无人工一致性标注或量表准确性校准。单一测试主体只证明该主体上的观察，不证明跨内容泛化；后续若要判断稳定性，应增加固定主体组和重复采样，并分别报告波动，不能由这一次分数声称普遍贴近。
