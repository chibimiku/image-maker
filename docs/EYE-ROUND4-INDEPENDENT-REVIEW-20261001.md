## 需要修正的解读

1. CSV 的 `identity` 列全部为 pass，而实际门禁 4 张 fail。`scores.json` 将这一列称为 `source_identity_kept`，似乎用于表示没有整个人物替换，但导出表不说明这一层含义。应分成整体身份保留的视觉观察与实际 identity gate 两列，不能把该列当门禁结论。
2. REPORT 开头“阻断来自全图画风，不是身份/结构/背景”过于概括。全图画风是共同阻断项，另有 4 张身份失败、两张最终结构审计条目和一份运行时 anatomy invalid。报告正文有列出这些情况，摘要也应保留。
3. common.md 明确要求眼睛以外保留源图画法，而最终审计以 sheya 参考评整张图的画风。因此全图风格失败并不意外，不能据此说眼部变量造成画风失败。局部收益判定与生产发布门禁应分开呈现，发布仍按当前门禁阻断。
4. 独立目视不能确认 b 组的“两次都 +1”：case-04 control 的虹膜边界、白色高光与睫毛并非明显比 case-02 variant 弱；变体更趋向简化虹膜内部层次，而“更简化”不等于“更清晰”或“更贴合参考”。这些是视觉复核意见，不能代替新的盲评分数。a 组 case-03 的变化也没有显著优于 control，支持不采纳。
5. b 组 case-07 的嘴部较 base 更趋于闭合，眼睛以外严格保留的要求至少需要进一步核对表情漂移。身份审计 pass 不代表所有非眼部像素与表情完全不变。

## 结论

同意本轮“不采纳、不写回正式配置”的最终决定。现有证据支持“眼部画法发生变化，收益尚不稳定”，不足以认定 b 组已经可重复提升。下次先在现有图上做匿名复评，按上睑、睫毛、虹膜轮廓与高光组织分别给理由，并核对瞳色/表情；再决定是否需要新预算。不要用放宽全图门禁来证明眼部实验有效。
