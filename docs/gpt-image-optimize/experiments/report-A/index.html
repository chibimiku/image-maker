结论与注意点

  • 线条连续性：2.5 两档均优于 gpt-image-2。sunburst 碎片率最低（0.0153 vs 0.0202），线条最长最连贯。
  • 细节清晰度：flare 最强（十项锐度指标全面第一，梯度>30% 占比 6.63% vs 基线 4.07%），蕾丝镂空与发丝可数。
  • 画面完整度：sunburst 会给远景加村庄 / 雪山 / 天鹅等多层景深，gpt-image-2 背景偏平。
  • 不推荐：2.5-flare-c 同 prompt 下明显更软（tenengrad 5534，仅基线 75%），不适合线条对比。
  • Safety 行为差异：同一份详细 Lolita prompt，gpt-image-2 稳定通过，2.5-flare / flare-c 连续被拒 6 次；压成一行、缩短、去掉年龄与袜类描述后一次通过。
  • 用量：gpt-image-2 output_tokens=1105，两个 2.5=1372；耗时基线约 30–35s，2.5 约 30–55s。
  • 建议：要刀锋线稿感选 flare，要细节连贯 + 画面耐看选 sunburst。
