# 背景与双人头发修复：本轮设计及后续路径

用户观察 A/B/C 背景普遍破碎、C 双人头发破碎，要求分别比较长短 prompts 并规划后续。此轮先直接进行代理视觉诊断，不调用付费文本分析。

旧背景指令只允许 tiny/microscopic/noise，要求不确定碎块保持；B 诊断连 debris-like objects 也保护，容易把问题原样锁住。旧 person 只修 garment micro-structure 且保护 hair，因此未真正尝试修复头发。以上是指令的潜在限制，不是已证明的失败因果。

本轮八次：ABC 背景短75词/长283–285词各一次，C 独立头发短84词/长266词各一次。分别从相同 person 输出起步；C 背景与头发是独立分支。沿用 Flash Image、2K、3:2、360s、单输入、无画风参考/细节后缀/调光/自动重试。旧背景候选仅同源历史对照。本轮条件只有一张，长版比短版多程序与场景条件，不能解释成纯长度效应。不先改生产模板。

背景新规则允许修复较大结构：先大块形体，再连接线条，最后保留有依据的细节；无可识别轮廓/连接/材质功能的碎块并回周围既有材质；已能识别但破损的物件先局部重建。保护真实植物与物件，避免简单删除整个区域。头发按头皮→主发束→遮挡→末端连接，给两人各自归属、保持轮廓和风向，减少无根短线和珠串高光。

后续按本轮结果选择，以下均尚未执行：

1. **复验有收益的版本**：对至少两个不同场景同版本各重复两次；检查不仅变干净，还要保住人物、植物、建筑数量、材质和景深。若收益只在单张出现，不改默认。
2. **背景分两阶段**：先恢复建筑/地面/物件的大块连贯结构，再处理植被与光点。每阶段限定对象；避免一次要求保留全部微细画法又消除全部碎纹。结构已经清楚的区域不再重画。
3. **具名区域诊断＋替代材质**：诊断输出区域、破碎证据、可修复对象、不能动对象、目标连续形状，以及无意义碎块移除后补回什么材质。使用明确任务表，减少“所有不确定都保护”。先校验诊断，避免把花叶、手指或头发当背景碎线。
4. **区域编辑或 mask 实验**：背景和头发各有明确局部编辑边界时，再核对当前 API 是否支持真实 mask/inpainting；不能把文字区域约束叫作 mask。若支持，可保护人物像素；不支持则用带区位描述的原图单输入，不默认上传派生裁剪。
5. **头发独立步骤**：人体/衣装修复后先修头发，再背景。双人重叠复杂时分别指定左右人物的发束归属，必要时两次各修一个人的头发；检查另一人及相交处是否变化。最终保真审计应允许获授权的发丝重接，仍限制发色、轮廓与身份。
6. **审计补“修好没有”**：保真之外，单独问建筑边界、物件可辨认度、地面连续性、发束连通和两人归属是否改善。把“保持内容”和“达到修复目标”分开；任何 pass 仍需人工等尺度对照校准。

只有在 prompt 方案反复无效时再单独测试其他编辑模型；固定源图/任务/尺寸，记录成本与保真风险，避免同时换 prompt 和模型无法判断原因。本轮没有自动增加模型或后续费用。

本轮初步观察后的优先调整：A 短版背景虽连贯，却重画建筑并删除部分明显树木；B 长版出现疑似新的白色花叶组合。下一版应给“可修内部、不可改布局”的对象合同：保留建筑开口的位置/数量，保留每棵主要树木的树干连接、根部位置和整体占位，保留现有花盆和花簇的位置/数量；只在这些既有轮廓内部合并碎纹。不能把“可辨认”理解为增加新花/窗/城堡尖塔。草稿附加句：`Keep every existing major object's footprint, position and count. Reconnect its internal structure within the existing silhouette; do not replace the scene layout, remove recognizable trees, add new flower clusters or change architectural openings.` 这条尚未发送或验证。

候选流程是：人体/衣装 → 独立头发连通 → 背景结构修复 → 背景植被/材质整理（仅仍有问题时）→ 配饰 → 光照。每步保真和目标改善检查后才继续；优先减少无收益重绘次数，不默认启用所有步骤。
