# refine 下一轮计划（2026-10-07）

先提高瞳色与衣装保真，再讨论更强的清理。现有证据仅为一个精灵源图，不能据此推广到全部画风或场景。当前里程碑不执行新的收费实验。

## 1. 零成本准备：校准验收尺子

从 `data/test-result/20261007/elf-fidelity-round2/` 固定原图、C2、R-person、D1、D2、R-background 的 hash，制作同尺度脸部/虹膜及衣装对照。C2/R-person 作为人工认为瞳色较接近的对照，D1 的偏灰和 D2/R-background 的亮黄绿作为漂移反例，不能把任一图片预先标成完整保真正例。

人工标注虹膜，排除瞳孔、高光、眼白与边缘混色，分别记录色相、明度、饱和度。像素统计辅助人工判断，不设未经验证的全画风统一阈值。核查审计是否能分辨「还是绿色」与「已经变亮/变黄/失去暗层」。离线准备不调用文本接口；新增模型判读也是收费请求，留到下一批预算。

## 2. 有限付费实验：只改背景步骤的颜色条款

候选设计为固定 C2 与 R-person 两个输入，各比较目前背景模板与减少强调瞳色、强调保持原暗层的弱颜色锚模板，每格一次，共4张。除该条款外，模型、分辨率、比例、附件、背景任务与其余 prompt 全部冻结；沿用无自动重试。不能把不同人物输入之间的差异归因于条款。

若候选在两个输入上都更好，再用胜出模板对两个相同输入各复验一次，共最多6张图片。先人工核验人体、主要破损、金边与眼睛，再批量比较；最多3次文本判读，失败/超时保留证据而不追加请求。执行前单独核对价格与预算，取得用户对这批新增费用的授权，当前历史额度不延用。

采用条件：无明显多肢，瞳色三维均无肉眼可见漂移，接受的人物衣装未被背景步骤改写，背景清理确实改善。任何条件失败都不改生产模板。若审计漏过人工明确反例，先修验收方式，不用总分掩盖失败。

## 3. 眼睛稳定后再试衣装

另立小批次，只改变人物步骤对金边路径/宽度、甲片边界与主要裂口的表达；原图始终为结构依据，局部放大用于诊断和比较。与原人物模板同输入对照，不能同时改背景、画风或多项参数。通过第二源图、另一种衣装材质及无人物场景复验后，才讨论扩大默认适用范围。

还需要检查色调/加墨后最终产物的颜色，区分模型漂移与后续本地处理造成的变化。现有 refine 审计只覆盖人物和背景两个模型步骤。
