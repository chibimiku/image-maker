# 服饰主题策略模板

本模板用于定义单个主题的采集与生图策略，便于后续新增 `theme/style/hybrid` 时做到：

- 可复现
- 可比对
- 可精准修改

建议每新增一个正式主题，就复制本模板生成一份主题规格文档。

## 示例：甜美洛丽塔

- 主题名称：`甜美洛丽塔`
- 目标人设：穿甜系 Lolita 服饰的少女，全身像
- 颜色词：`pink`, `white`, `ivory`, `light blue`
- 元素词：`lace`, `frill`, `ribbon`, `bow`, `floral`
- 来源优先级：
  - `dress -> lolibrary`
  - `shoes -> wear`
  - `socks -> wear`
- 推荐 style：
  - `梦幻柔光`
  - `日系插画`
  - `高细节蕾丝`
