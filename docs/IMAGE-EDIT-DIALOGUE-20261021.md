# 批量图片编辑：对话编辑

在原「批量图片编辑」tab 右侧增加「对话编辑」，保留原直接批量编辑入口。

## 使用

1. 添加或拖入图片，切换到「对话编辑」。
2. 勾选决定本轮范围；没有勾选时用高亮选择，再没有选择时用列表全部。一次最多 24 张。模型还能根据编号、文件名、缩略图内容在范围内进一步筛选。
3. 输入要求后点击「发送并编辑」。例：“选黑裙的两张，调整为更自信的表情，保留人物和原画风”。
4. 对话会显示逐图解释、执行状态和结果复核。版本列表可预览或双击打开。后续可说“只改第二张”，或指定“#2 的 v1”。左侧 # 编号是对话内稳定 ID；“第几张”按当前左侧列表顺序解释。
5. 输入来源可选按对话（默认最新）、原图、版本列表中的具体版本。选具体版本时本轮限该图，且必须属于左侧选择范围。

新对话会归档旧记录；当前对话保存在 `data/image-edit-dialogue/current.json`，跨日重启仍可读取。归档在同目录 `conversation-<id>.json`，可通过「打开对话」继续。生产图片保存在 `data/<日期>/image-edit-dialogue/`。不覆盖原图或旧版本。

## 执行规则

- 文字视觉模型读取主窗口当前文字分析配置；图片通道独立使用 `apis.aigc2d`，不会跟随全局 GPT 默认通道。模型、分辨率和单次超时可在对话面板调整；不改公共配置。
- 一轮先用带编号缩略图解释意图和选图；每个目标再以较大预览分析实际输入，生成图专属指令。图片编辑串行执行，一次只发当前图片，不附加画风模板、额外五官或通用重绘固件。Gemini 比例用 auto，默认跟随输入。
- 返回图片后保存版本、父版本、SHA256、实际 prompt、模型和 usage，再用输入图＋输出图复核请求达成与明显漂移。失败或不确定明确显示；复核不构成完整可靠性证明，也不自动重画、抹掉候选或把旧结果标成通过。
- 「停止后续任务」不丢弃正在返回的收费产物；当前请求返回后保存，停止剩余任务和未发送的复核。网络请求受超时限制，退出时等候已发送请求，不强杀正在落盘的线程。
- 「重试本轮失败项」只重试最新一轮失败/中断/尚未执行项，复用原输入和已有有效指令，成功项不重发。图片已返回而复核超时不变为生图失败。无任务的选图分析失败请重新发送；重试/超时可能产生的费用以服务商账单为准。
- 正常一轮 N 张是 1 次选图分析＋N 次逐图分析＋N 次图片编辑＋N 次结果复核；纯问答/澄清只做首个文字视觉请求。SDK 与 Gemini 自动重试关闭，无拒绝换端点逻辑。
- 所有输入与输出都有路径和 hash；源文件被替换后旧版本拒发。再次添加已替换文件会建立新 ID。重启不会自动续费执行，进行中任务转为中断；已保存结果保留。
- 模板在 `prompts/image-edit-dialogue/{route,plan,review}.md`。逐图规划包含适用性字段，性感化要求只处理明确成年角色；年龄不明确跳过，普通非性化编辑不受此限制。
- GUI 与原批量任务互斥。请求使用主线程拍下的配置快照；worker 只通过 Qt signal 更新界面。公共 Gemini 后端新增可选 `config_snapshot` 参数，其他调用方行为不变。

## 验证和局限

离线覆盖：范围约束、无效 JSON/字段、逐张附件、配置快照、原图/最新/指定版本、重复发送、后台线程、停止保存、失败重试、源 hash、损坏历史、复核失败不重画等。测试数据进入 `data/test-result/`；本机系统 TEMP 的原子 replace 被沙箱拒绝，测试用工作区 `--basetemp` 后通过。

真实测试使用自行合成的两张几何卡片，没有上传用户角色图。先两张圆形改金星，再只改第二张为银灰星，随后纯问答确认颜色；最终追加第二张边框修复及自动复核。证据在 `data/test-result/20261021/image-edit-dialogue-online/`，包括 session、输入/结果、请求回放、usage、界面截图和 summary。初次沙箱连接失败保留为失败轮次，获用户本轮付费测试授权后按原端点执行，没有自动重试。

最终针对性测试合计 **44 passed＋6 subtests**；5 个运行时/CLI 文件编译、app 导入及 diff-check 通过。实际 **4 次图片请求全部返回、9 次文字视觉请求成功**，4 个文件 hash 与解码 hash 均唯一，4 个父输入 hash 对账通过、输入未改。金额未核实。最终修复的模型复核为 pass，但代理查看仍见右侧边缘细微白灰伪影；不等同于像素级修复通过。首轮误落生产日期目录的本轮 6 个自有产物/回放已逐文件迁入隔离目录并更新 session 路径，原始路径记录保留在 `output-relocation.json` 与迁移前快照；未移动用户历史产物。

人工查看发现 Gemini 会额外增加小框、破坏外框，即使指令要求保留。此功能实现对话选图与执行，不保证像素级保真；复核同样可能漏检。现阶段测试不能证明人物/多人/复杂服装编辑稳定性。GUI 做了 1100×750 离屏排版与真实 QThread 测试，未操作运行中的旧桌面窗口。需重启 app 加载新代码，未自动重启、提交或改公共模型配置。

## 无头入口

```powershell
python -u tools/image_edit_chat.py --session data/my-edit-conversation.json --images a.png b.png --instruction "只修改第二张的背景"
python -u tools/image_edit_chat.py --session data/my-edit-conversation.json --retry-failed
```

可选 `--model` / `--resolution` / `--timeout` / `--output-dir`；`--dry-run` 不联网也不落盘。生产 GUI、CLI 与测试共用同一执行器。
