# Gemini / GPT 提示词优化按钮

入口：图片生成 →「单图调试生图」（Gemini 或其 GPT 通道），以及「gpt-image-2 生图/编辑」。提示词框上方新增「优化提示词」。重启 app.py 后加载代码。

输入简单中文或英文描述，点击按钮；后台文字模型将其展开为一条英文生图正文并回填，用户检查后自行点击生成。Ctrl+Z 可恢复优化前文案。不会自动生图、修改画风设置或追加图片处理。

优化包括主题具体化、人物外观与衣装、动作、场景、构图、光照配色；保留人数、身份、颜色、覆盖程度、用户要求的文字及其它显式约束。当前尺寸/画幅优先；当前画风只作为上下文，画风说明和参考图仍由原生图请求单独组装。编辑模式保留图号引用，只明确编辑目标，不杜撰未见附件。性感主题未指定年龄时采用明确成年人物与成熟比例。

仅发送原文与文字形式的界面选项（通道、模式、尺寸/比例、画风名称、内容附件数量）；不向文字优化请求上传附件或画风参考图。结果限制为 2000 字符以内，不截断完整句子来假装成功。

读取现有文字分析 API 配置与环境变量密钥，主请求最多等待 120 秒，客户端自动重试关闭。备用使用现有配置的开关和触发规则：默认拒绝才切换，若设置为任何失败则跟随该设置。主端点成功不请求备用。纯文本兜底复用 NSFW 模型时不替换成视觉模型；原有视觉分析调用默认行为保持。

本机磁盘配置在实现时是 gpt-5.6-luna / deepseek-flash；用户提到 gpt6 luna / deepseek v4.1，本次没有猜测模型别名或修改配置。以后在设置中切模型，按钮下一次点击随配置加载。

优化期间禁用生成和重复优化。用户编辑原文、切换选项或替换附件时，旧优化结果不覆盖新状态。接口失败、拒绝、截断、无效 JSON、缺字段、过长结果均保留原文。GPT 重绘模式禁用优化，保留固件专用规则。按钮后台日志通过 Qt 信号返回主线程；关闭 app 的既有等待线程逻辑会识别新线程。
