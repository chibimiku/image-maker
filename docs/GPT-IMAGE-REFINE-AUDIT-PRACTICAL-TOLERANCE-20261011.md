# GPT refine 审计实用容差调整（2026-10-11）

用户检查 20261011 三个 GPT 原图的流程后要求降低审计严格程度。本轮调整审计语义，不将历史失败改为通过，不重发图片或文本请求。

- 低饱和灰蓝、灰紫、淡紫灰虹膜的小幅色调和饱和度变化可以接受；明显换色、发光瞳块和丢失瞳孔暗层仍失败。细小虹膜的精细色差无法分辨时记 limitations，关键颜色和结构无法判断仍失败。
- 允许碎发合并后单束宽度、卷曲和边缘细丝的小幅变化；明显新增发量、长度、改发型或跨人物连接仍失败。
- 背景完成标准改为主要诊断缺陷有可见有效改善；少量次要碎纹或小缺口不要求全部消失。主要结构仍明显断裂、无清理效果或改善无法核实仍失败，需要逐目标证据。
- 允许内容与视角保持时的小幅位置、尺度及边缘变化。审计输入增加三张图的实际显示尺寸及宽高比（含 EXIF 方向），禁止凭预览猜比例；3% 内栅格取整差异本身不构成构图失败。重要人物或物件被裁切、改机位或改姿势仍失败。
- 审计实用容差明确优先解释修复任务里的 exactly/unchanged，避免把保留结构误读为逐像素一致。

判定代码仍要求全部保真字段为 true、无 unacceptable_changes、confidence 至少 0.8。人体、重大内容不确定仍停止；背景 completed 与证据、头发状态检查、失败回退、无自动重试及请求预算保持原机制。

新增离线回归覆盖审计输入三图尺寸对应及 EXIF 显示方向。`tests/test_gpt_image_refine.py` 与 `tests/test_refine_state_ui.py` 共 76 passed；Python 编译、导入、真实三张 GPT 源图只读尺寸检查和 diff-check 通过。未在线复审，不能据此声称降低误拒率或历史三张现在会通过。

运行中的 app 需重启以加载新增尺寸输入代码；历史记录不自动重跑，本轮没有重启或提交。
