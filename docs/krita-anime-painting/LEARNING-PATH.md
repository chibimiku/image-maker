# Agent 分部位学习路径与记录要求

这份路径规定“怎样持续学习”，[统一手册](HANDBOOK.md)说明“目前知道什么”，[实践计划](PRACTICE-PLAN.md)说明“当前作品先修什么”。先读 [环境探索](ENVIRONMENT.md)；没有软件时可完成研究和评审，但不能把未实画的单元记为已练习。

## 每个部位都执行同一闭环

1. **看现状**：实际打开参考与当前图，指出一至三个可见问题；标明参考未收到、角度被遮挡等不确定项。
2. **针对性学习**：先读已有专题，再为薄弱点查作者教程、正规美术教学或官方工具文档。记录作者、链接、阅读范围和可实施的方法，不以搜索结果标题代替阅读。已有来源足以回答问题时不必重复搜索；新问题须补读。
3. **先建记录与要素**：复制 [学习记录模板](templates/lesson-record.template.md)，在绘制前写目标、来源、方向/光照、定位与遮挡；使用 [要素模板](templates/practice.template.json) 保存参数。记录会随工序追加，不等完成后补写成假定过程。
4. **独立部位练习**：先用新画布做结构草稿，再轮廓、底色、大明暗、中小结构和细节；初学部位先减少变量。原有主稿另存，不直接覆盖。
5. **每工序识图与返修**：导出并实际看图，检查全图和相关原尺寸局部；写具体错误、修改与复看结果。不能用“导出成功”“像素数更多”代替识图。结构错就返工，不继续堆细节。
6. **换方向或上下文检查**：先控制光源，再比较正面/适度转头或相近表情；只测过正面就记录正面范围。局部可用后放回完整头部/身体，检查角度、尺度、遮挡和光源是否一致。
7. **保存经验与推进**：保存改前/改后、失败版、可编辑稿、要素和来源，更新 [学习记录索引](learning-records/README.md)。把验证有效的方法与失败原因提炼回对应专题，不把个别结果写成普遍规律。然后选择下一个具体短板，在当前授权内继续，不需逐部位等确认。

没有明显改善时停止同一种低收益叠加，记录失败并改变造型或研究方法；不要求无止境打磨到“完美”才可学下一部位。未解决项保留到队列。

## 建议单元与顺序

已有学习不必全部从零重复：先核对记录，从实际短板进入。下表是依赖顺序，当前主稿的优先项仍以实践计划为准。

| 单元 | 学习目标与检查 | 已有入口 / 当前边界 |
|---|---|---|
| 00 环境与基础工具 | 确认软件、接口、笔刷和保存/导出能力 | [环境](ENVIRONMENT.md)，接收方必须重新探索 |
| 01 头型与方向 | 颅体、下颌、中线、定位、近远关系 | [头部方向](facial-features/head-and-direction.md)、[透视](facial-features/perspective-verification.md)；极端角度未验证 |
| 02 眉毛 | 眉弓、毛流、轻重、情绪联动 | [眉毛](head-parts/01-brows.md)，重复短线仍须检查 |
| 03 眼睛 | 眼睑/眼球、眼裂裁切、视线、虹膜/瞳孔、宝石反射 | [眼部](facial-features/eyes.md)、[宝石眼](gem-eyes-20261016.md)，不能只练反光 |
| 04 鼻子 | 前突、鼻底、方向、小色面及投影 | [鼻部](head-parts/02-nose.md)，体积仍弱 |
| 05 嘴唇与口部 | 唇缝、嘴角、开合、口部曲面 | [嘴部](head-parts/03-mouth.md)，与表情联动另查 |
| 06 耳朵 | 耳轮/内侧、眉鼻定位、方向、头发遮挡 | [耳部](head-parts/04-ears.md)、[体积练习](head-parts/tutorial-volume-20261017.md) |
| 07 发型设计 | 发际线、分缝、固定点、前后分区及各角度连续性 | [发型](hairstyles/README.md)，编发/盘发背面仍待学 |
| 08 头发材质 | 大中小束、三面转折、接触/投影、高光与细丝主次 | [差距复盘](hairstyles/detail-gap-and-hierarchy.md)，当前优先，带片感未解决 |
| 09 脸部与头颈 | 脸部转折、下巴投影、颈圆柱、锁骨和肩 | [最新练习](head-parts/tutorial-volume-20261017.md)，仍略图解化 |
| 10 表情专项 | 眉眼嘴脸颊联动，区分微笑/困倦、专注/不悦 | [独立 Topic](expressions/README.md)，单独画布，不干扰主稿 |
| 11 躯干与肩臂 | 胸腔/骨盆、肩带、关节和受力 | 当前缺系统专项记录，应先研究再实画 |
| 12 手与道具接触 | 手掌体块、手指关节、抓握/搭扶和遮挡 | 当前未完成系统专项；不得把早期简略手指算通过 |
| 13 腿脚与坐姿 | 髋膝踝连接、缩短、承重、脚与鞋 | [早期坐姿复盘](seated-practice-20261016.md)，需补分部位研究 |
| 14 衣料与饰物 | 受力褶皱、厚度、缝边、不同材质反光 | 目前有试验，未完成系统材质专项 |
| 15 椅子与场景 | 座面/扶手空间、接触、地面、视点与延长线检查 | [流程](painting-notes.md)、[透视要求](facial-features/perspective-verification.md)，不等于整场景已验收 |
| 16 整体插画 | 局部整合、统一光色、焦点、背景层次 | 完整成品仍待完成，按全图/中图/细节复看 |

每个单元可拆成更小的课题，例如眼睛先结构与视线，再虹膜材质；头发先发型再光影，不能混成一次“全部增强”。

## 文件与记录组织

新记录放 `learning-records/<topic>/<date>-<run-id>.md`，例如 topic 可用 `eyes`、`hair-material`、`hands`。每个 run-id 唯一，不覆盖旧记录。图片和可编辑作品放接收方自己的输出目录，在记录中链接；要分享时选择必要文件一并打包，不假定原机盘符存在。

索引至少登记：部位、当前问题、记录路径、已读来源、实画/自检状态、可见结果、未解决项、下一动作。已有专题本身就是历史记录，不需要伪造新课补齐表格。

状态建议：`待研究` → `已研究待实画` → `已实画待评审` → `已自检需返修` / `本轮局部可用`。`本轮局部可用`只限所测方向、光源和上下文，不等于掌握此部位。技术故障、无绘画环境、未看图分别记录，不能跳过评审改成通过。

## 完成一轮的最低交付

须有来源及阅读范围、绘制前目标与要素、阶段图/工序记录、实际识图问题、至少对发现的问题作针对性返修或说明未能返修原因、改前改后、未解决项、下一动作，并更新记录索引。没有图像工具时写“研究完成，未实画”，不虚构可编辑稿或视觉检查。

每轮记录之后再进入下一个有价值的问题；无需每次重新搜索同一教程，也不要用大量笔刷下载代替练习。新笔刷一旦使用，须记录作者页、下载地址、版本/准确名称、许可、校验与实际使用层。
