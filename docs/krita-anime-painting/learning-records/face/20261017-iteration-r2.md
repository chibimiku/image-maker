# 面部学习记录 · 2026-10-17 · iteration-r2

状态：已实画并实际读图，鼻唇方案局部采用，体积仍弱。环境沿用同批已确认的 Krita 5.3.3 / Bridge 1.0.0，原稿不覆盖。

## 本轮问题、来源与要素

先实际查看第一轮整图及两个原尺寸局部，发现钩状鼻侧、硬白亮斑和厚唇框。本轮沿用第一轮已读鼻、口唇、光影来源与同相机/光源，不重复声称新学习。依据是“先理解体块再风格化省略”，不是必须把全部体块边界画出来。

本轮只重画 `41 Nose planes and quiet lip opening`。鼻侧不从长鼻梁直连到底，改短范围软转折和轻鼻底投影；硬白块改软亮面。嘴轮廓不封闭描唇，开口更窄。眼形、虹膜、视线、脸型、表情和头发固定。JSON 与产物在 `data/test-result/20261017/krita-face-iterations/`。

无新下载资源；仍为程序路径/遮罩在 Krita 分层渲染。轮廓/底色/定位继承第一轮，返修集中于大明暗和小结构，不伪称从头重新起稿。

## 工序与结果

实际查看 `painting/03-round2-quiet-nose-lips.png`、`03-round2-face.png`、`03-round2-nose-mouth.png`。第一轮长钩与硬白块已消除，唇色和开口收敛，比较接近参考的省略量；但鼻子软化后体积又偏弱，鼻底小投影仍略几何，不能把更淡等同更立体。嘴有窄开口，缩小仍接近一条线。

下一轮不再不断削弱鼻唇，暂留此版；转向更显著的眼周问题：上睑等粗、下睑像封闭轮廓，双眼皮大弧与均匀眉毛短线使整脸图标化。保持虹膜和视线，重做眼睑粗细与断续，减淡规律眉毛，减轻全脸灰紫罩色。鼻唇的遗留问题列入下一批，不用更多高光点掩盖。
