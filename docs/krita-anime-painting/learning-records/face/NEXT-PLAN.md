# 面部下一批：下半脸比例与颧颊体块

状态：本计划已于2026-10-17执行，见 [比例与颧颊实画记录](20261017-proportions-r1.md) 和 [结果复盘](../../head-parts/face-proportions-20261017.md)。下文保留原前置方案，不能将计划文字本身当作完成证据；下一项转为B脸缘/发尾衔接及局部转折边缘。

## 为什么换层级

R4 上睑比 R3 合适，鼻唇比 R1 克制，但脸仍主要靠外轮廓读形；下半脸偏长、颧颊缺少有归属的大面。继续加虹膜、睫毛和腮红无法回答这些问题。

## 执行顺序

1. 补读已有头部构造、交叉测量与脸部光影来源，必要时找专门颧骨/面部平面的作者教程；先实际看文字与示范图，记录范围。不要只凭搜索摘要命名“颧骨已学”。
2. 从 R4 完整快照新建独立画布，先做三栏草稿：当前基线、A 保比例改明暗、B 调比例。对照统一眼线和显示尺度；这张不是自由设定新角色。
3. A：保留眼距、鼻底 y≈36、口线 y≈62、颏 y≈95，仅用无纹理的受光/转折/遮挡三面检查颧颊与口鼻周围关系；不要把硬楔形直接铺到脸上。
4. B：固定同相机、主光、虹膜、视线和表情，试把颏由 y≈95 调至约86、口线由 y≈62 调至约57；这是受控试验参数，不是测得的标准比例或参考精确坐标。先用草稿比较，不预先认定更短就更好。
5. 改脸型时同步更新脸形遮罩、耳/颌关系、颈部连接与下巴投影，检查所有旧 FACE 轮廓引用。不能只缩最终像素或让旧脖子阴影悬空。
6. 实际查看三栏草稿和无纹理灰度大面，评价自然程度、方向、角色感和体积。各记一个主要问题，再选一版返修；若两版都不优于基线，保留基线并记录失败。
7. 仅在选择后恢复底色与鼻唇/眼周，导出整图和局部再评审；下一动作由这一轮结果决定。
