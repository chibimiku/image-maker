# 统一绘画手册

截至 2026-10-17 的经验归纳。来源与逐轮证据保留在 [目录](CATALOG.md) 各专题；作者教程建议、本项目风格决策、本机测试结果应分开理解。

## 动笔前准备

先完成 [环境探索](ENVIRONMENT.md)，实际看参考，记录可观察内容和不确定部分。被发饰遮住的固定点、背面编发不能凭单张正面图唯一还原；本机参考路径不代表随包素材。

要素 JSON 至少包含画布/坐标、相机/朝向、视线/表情、头身比例与定位点、发型分区及固定点、姿势承重、椅子与地面、材质、主光、遮挡和工序检查。使用 [通用模板](templates/practice.template.json)；专项五官参照 [参数模板](templates/facial-study.template.json)。JSON 是前置约定，不保证造型自然。

## 固定工序，每步实际看图

构图缩略与承重草稿 → 体块和坐标 → 轮廓线稿 → 材质底色 → 大明暗及投影 → 中小结构 → 少量细节 → 统一光色。

每步执行“绘制—导出—查看全图与局部—指出问题—修改对应层—复看”。结构未通过就返回草稿，不用花纹、细丝或全图模糊掩盖。氛围和焦点在构图阶段确定，最后只协调。

保留原稿与失败版，写清看到了什么、修了什么、哪里还不行。PNG 解码、KRA 可打开、参数自洽属于技术检查，不能代替美术评价。

## 草稿、方向和透视

先建立颅体、下颌、侧切面、中线及五官构造线，五官服从同一朝向。眉线和嘴线是曲面上的线，不能强迫它们都交向一个消失点。转头后远眼受压缩和遮挡，不能把两只正面眼贴在侧脸上；视线单独检查。

盒体直边按三个轴分组，延长已画边检查同组消失方向；重新连接理想消失点会隐藏误差。头部转动后的局部灭线不一定等于场景地平线。结合镜像、缩略图及参考交叉测量判断自然程度。

本项目投影模型只近似验证过适度转头，绝对 yaw≤35°；极端侧脸/俯仰、完整眼球及耳部遮挡未验证。程序盒子残差小只是内部一致性。详见 [透视验证](facial-features/perspective-verification.md)。

## 五官按结构整合

| 部位 | 有用方法 | 常见失败与修正 |
|---|---|---|
| 眉 | 随眉弓方向，轮廓与细毛有主次，起止渐细 | 重复短线像刷子：减密度和对比，不持续加毛 |
| 眼 | 分开眼白、睑影、虹膜暗环、瞳孔、上暗下亮、纹理、反射；双眼同光源 | 虹膜越眼裂、视线不一、高光盖瞳孔：回查几何和遮罩 |
| 宝石感 | 少量折光面和次反射，保留虹膜曲面和深色瞳孔 | 放射线像标靶、纯白过多像发光石：减少规律和亮点面积 |
| 鼻 | 弱轮廓、小色面与投影表达前突，服从中线 | 单个 C 或黑钩子：重建体积，不能全抹平 |
| 嘴 | 嘴角、唇缝、下唇反光有轻重，服从口部曲面 | 厚色块突兀：收窄减淡，先确认开口与表情 |
| 耳 | 眉鼻辅助定位，耳轮与内侧 Y 可简化，跟随角度 | 被头发切成孤立色块：修遮挡顺序和露出范围 |
| 脸颈 | 下颌遮挡颈部，颈圆柱接肩与锁骨，肌肉轻提示 | 硬楔形脸影、颈部条带、均匀白边：回查转折与投影 |

精细眼睛不会自动提升皮肤、手和衣料。局部必须回到完整头部检查。依据见 [五官专题](facial-features/README.md)、[逐部位复盘](head-parts/README.md) 和 [最新体积练习](head-parts/tutorial-volume-20261017.md)。

## 发型先于头发材质

先定分缝、发际线、发量、固定点、刘海终点、侧发/后发、长度与运动方向。头发包住头骨，不能像断开的帽子；收束和配饰应影响附近发流。

按“大形—主束—中束—小束—细丝”推进，改变宽窄、弯曲、长短、末端分叉和负形。分片管理遮挡和形体，不要求每片描一圈同粗封闭线，也不允许每片独立光源。

共同光源下分开受光面、转折面、接触暗部与投影。高光随曲率、朝向、遮挡改变宽度和强度，不把圆管式白条复制到全部 S 弯。细丝在转折与焦点附近有主次，暗部允许留白。

尚未通过的办法：两条 S 带承担全部后发；每片包围盒独立渐变；平均长排线；为细致不断加路径。这些会造成 Flash、缎带或塑料束感，应先修中尺度结构。详见 [差距与层级](hairstyles/detail-gap-and-hierarchy.md)。

## 表情独立练习

眉、上下眼睑、瞳孔可见程度、嘴角、脸颊共同表达。只改笑嘴容易仍显呆滞；微笑时下睑收太多又像困倦。“专注/不悦”等接近神态需要对照。

独立画布控制脸型和角度，比较中性、只改嘴、眉眼联动；遮住标签判断，再迁移主稿。正面练习不代表侧脸已掌握。见 [表情专题](expressions/README.md)。

## 光影、笔刷和材质

区分形体转折与投影：圆面通常渐暗，接触处或近投影可能较硬；具体取决于光源与几何，并非所有投影都硬。局部反光服从环境，不在全部轮廓描亮边。

不透明圆笔建大面，尖细笔画轮廓和少量纹理，软笔薄叠圆面，混色笔需要已有像素。Krita 组内继承 Alpha 不等于其他软件逐层剪贴，先验证范围。笔刷名称、滤镜字段以本机实际清单为准。

滤镜放独立层局部比较；全图模糊无法修结构。下载笔刷≠安装≠实测≠掌握。许可、版本和倾斜输入条件见 [资源](resources.md)。

## 坐姿、衣料与整体

草稿先放胸腔、骨盆、椅面、膝盖、脚。骨盆落座，髋到膝有大腿长度和缩短，小腿从膝转折；重心接触可解释。椅子座沿与扶手留可读轮廓，人物椅子共用场景视点与地面。

衣料先受力和大褶皱，再花边织纹；皮肤、布料、金属不能共用一套白线高光。当前衣料和完整坐姿仍待练习，不把原则写成已完成验证。

## 三个尺度的评审

- 缩略：剪影、承重、主光、焦点；装饰是否抢脸。
- 中图：方向、视线、交叠、衣料受力、道具连接。
- 原尺寸：眼睑/虹膜边界、睫毛收尖、发丝归属、耳饰挂点、阴影边缘和规律性伪影。

每轮只选少数可见目标，先修最大问题，保留未解决项；不把详细文档或技术成功当画质进步。
