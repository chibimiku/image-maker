## 本轮实际阅读

- [BlueLuminary：4 Steps to draw & color any hairstyle](https://tips.clip-studio.com/en-us/articles/10796)。已读公开正文：先确定发际线、束发固定点与刘海终点，再考虑头骨外的发量、几何大形和运动方向；绘制与上色分阶段。采用这套规划方法；作者的混合模式和笔刷是个人方法，不是本项目必须照搬的规范。
- [MelanciaComics：Character Hairstyles: Shapes & Accessories](https://tips.clip-studio.com/en-us/articles/15907)。已读公开正文的分区、造型、发根、配饰与线稿部分：刘海框定正面，侧发衔接脸和后颈，后发决定后方体积；先检查大中小形，配饰应影响附近发量，并从不同方向检查发型。其 6–3–1 是设计启发，不作为精确比例规定；几何形状与性格也不机械一一对应。
- [Eridey：How to Draw Hair: 3 Tips for Beginners](https://www.clipstudio.net/how-to-draw/archives/159719) 已打开，列为后续按发质与方向补读的来源。本轮不声称看过视频和逐张看过教程插图。

## 与材质训练的区别

发型先回答：分缝在哪、哪些地方散落或收起、总长度与蓬松量、刘海怎样框脸、发饰固定在哪、转头后能否保持同一设计。材质随后回答：同一发型在既定光源下怎样明暗转折、反光、分束与表现细丝。

分片是管理形状和遮挡，不表示每片都是独立色彩、独立光源或要描出一圈同样粗的封闭边界。

## 重新观察目标参考

已实际查看用户本地原图。视觉上可辨认：中央长尖刘海、偏短的左侧贴脸发、左右垂肩长束、两侧很长且不等长的弯曲后发，右耳上方收拢的区域，以及头顶隆起发量与配饰。之前练习的大侧分刘海不符合这套主要特征。

背部和配饰挡住了连接点：具体盘起的方法、右侧到底采用哪种编束，不能只凭此正面参考唯一确定。本轮把这些标为暂定，不凭空称作完成了某种真实编发结构。

## 新模板和练习分区

[发型 JSON 模板](../../../data/test-result/20261017/krita-hairstyle-sections/hairstyle-template.json) 记录了发型意图、方向、各片轮廓、前后顺序、统一光源、流程和待检查项。当前为接近正面的简化示意，没有把此前头像的三分之四角度直接套入。

| ID | 分片 | 作用 |
|---|---|---|
| A | 头顶收起的发量 | 检查顶部轮廓，固定方式暂定 |
| B / C | 左右后发 | 定总长度、宽窄与不同的 S 弯 |
| D | 头骨外包络 | 保证发量包住头骨，衔接分区 |
| E / F | 左右垂肩发束 | 衔接脸旁与肩部，单独检查脸部遮挡 |
| G | 左侧贴脸短发 | 框脸，不应与垂肩束合为一整条 |
| H | 右侧刘海 | 向耳上收拢区域过渡 |
| I | 中央尖刘海 | 建立参考发型的正面特征 |
| J | 右侧收拢区域 | 示意局部收束，不声称完成具体编法 |

## 实际工序与自检

1. 新建空白文档，先画带 ID 的半透明分区草稿，显示头骨包络。分区色仅用于标记，不是正式上色。
2. 各片单独画轮廓并组装；五官只是定位占位，不替换已有宝石眼。检查发现 E/F 根部横线穿进额头，先修正脸部遮挡，保存修正版线稿。
3. 所有片使用同一个平涂底色，再查看整体轮廓，不加入密集发丝。
4. 各片共用同一局部坐标下的色场与左上方光照，另按发束转折画局部阴影。不是在每片内部重新居中一条高光。
5. 复看三栏：能辨认出中央刘海、侧边收拢与长后发；但后发简化成两条大弯束，体量与层次明显少于参考，头顶暂定发量也偏像规则圆团。当前只是设计与流程练习，不是完成的发型插画。

共同渐变只验证光照归属，不能代替各发片真实转折。下一轮先把后发补成少量互相遮挡的大块，再检查顶部连接；轮廓确认前不加细丝。

后续学习顺序：散发与分缝→束发固定点与拉拢方向→编发的交叠规律→盘发的体积与固定→相同发型的正面、三分之四、侧后视。后三类尚未完成练习，不把这张正面示意当成已验证背面连续性。
