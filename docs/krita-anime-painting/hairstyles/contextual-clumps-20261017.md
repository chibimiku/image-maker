# 在完整发型上继续中小束练习

用户要求继续上一轮“减少平面感、增加真实层次”的方向。本轮不再单独展示悬空发束，而是在新的完整发型示意头像上检查。原宝石眼头像与独立表情练习未改动；本轮五官是定位占位，不能称人物成稿。

## 实际过程

1. 保留中央刘海、左右垂肩发、右侧收拢与头顶发量的设计。把此前两条后发改成六组原创轮廓，各有不同弯曲、长度、终点与空隙。先保存轮廓和中束方向草稿。
2. 查看整张草稿，确认新分组能在头部两侧衔接，发尾完整在画布内；当前仍有根部斜角与规则顶部轮廓，不称结构完全自然。
3. 统一铺蓝灰底色，并根据每组流向加入渐细的中束暗部。第一次上色仍像贴色条；加入细丝后仍有大面积平面，细线无法遮盖这一问题。
4. 再修：为刘海、贴脸发、垂肩发和顶部发量分别设计较宽的转折阴影；局部反光向四周渐隐，不使用此前悬空发束的重复圆管亮度。后发的投影由前层实际轮廓偏移产生，并限制到接收投影的分片里。
5. 最后加轻微刘海接触投影，限制在露出的皮肤，扣除全部发片，避免把阴影再涂回前发上。查看完整输出后保存。

## 本轮识图判断

有效部分：不再只有两条单独长带；后发负形与终点有了变化；刘海和侧发有较宽的明暗转折；细丝在中束内有归属。

仍有问题：主要轮廓太光滑、一些中束像规则带片；接触暗部和反光的自然变化不足，发型右侧收拢部分只是示意；顶部发量仍像规则圆团，背面固定方式尚不明确。简化五官本身还有虹膜裁切等示意问题，不能拿这张代替已有面部练习成果。

当前比上一张分区图多了结构信息，但仍未达到用户目标的精细插画质感。曲线数、分片数、图层数及文件分辨率都不作为艺术通过标准。下一轮先修顶部连接与局部不自然转折，再选择一段后发把中束边缘拆成更有节奏的小束；继续同时查看整个头部和局部，避免只放大描线。
