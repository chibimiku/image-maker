# 绘画流程与本轮实施原则

## 1. 先解决坐姿与体积

本项目第一版的问题：椅子曾被头发遮住；膝盖和小腿几乎连续成竖线，坐姿较弱；头发像几片宽色带，脸部偏图标化。

后续构图先画胸腔、骨盆、座面、膝盖、脚五个大形。检查骨盆是否真正落在座面上、大腿是否存在前后缩短、小腿是否从膝盖转折。椅子座沿和扶手要留下可读轮廓。装饰、滤镜和密集发丝都不能修复错误的骨架。这是对本机结果的造型分析，并非声称已完成系统人体训练。

## 2. 分阶段工作

建议图层分为：构图草稿 → 人物及椅子轮廓 → 各材质平涂 → 形体硬阴影 → 柔和过渡 → 细节与高光 → 背景装饰。先用缩略图看结构，再放大看眼睛和手，最后回到适屏确认焦点。

Krita 官方工作流说明了线稿与底色分层，以及 Multiply 线稿、Levels 清理扫描稿等方法。自绘透明线稿不必机械地再做扫描稿清理。[官方 Common Workflows](https://docs.krita.org/en/tutorials/common_workflows.html)

## 3. 线条要有层次

外轮廓、遮挡边缘、内侧衣褶、发丝不使用同样的线宽。暗部交接可稍重；受光边与面部细节更轻。长发先用长曲线确定走向，再用少量细线描述发束内部，避免把所有区域填满等距平行线。

官方 Inking 教程讨论压感曲线与稳定器；过度平滑可能使笔触机械化。脚本曲线没有真实手部动作，因此只能借鉴线条层次，不能宣称实现了教程中的手绘训练。[官方 Inking](https://docs.krita.org/en/tutorials/inking.html)

## 4. 用材质组限制阴影范围

头发、皮肤、布料分别建组。组底部放不透明色形，其上阴影及高光层开启继承 Alpha。不要把整个背景也放进同一组，否则继承范围可能变成整张画布。剪贴组不要开启穿透模式。

这是 Krita 的组内合成与继承 Alpha 机制；它不等同于 Photoshop 的逐层剪贴关系。[官方 Alpha Inheritance](https://docs.krita.org/en/tutorials/clipping_masks_and_alpha_inheritance.html)

## 5. 硬阴影与软过渡并用

本轮选择上左侧柔光。刘海投影、下巴、袖口、裙褶背光面保留可辨认的硬边；脸颊、膝盖、胳膊圆面用低不透明度喷枪叠薄色。蓝色物体的阴影可向蓝紫移动，皮肤阴影向暖粉移动；不能只加黑。

这是本轮的配色和光照决策。不要理解成所有动漫插画都必须用同样的色相或混合模式。

## 6. 头发先大束再小束

先分出刘海、侧发、后发，明确每束的根部、走向与收束处。高光沿头部曲面形成有断续的亮带，亮带不能穿过所有阴影区。纤细发丝用于提示结构，不应掩盖大明暗。

社区作者的头发教程强调方向和明暗过渡，可作为画法研究的补充；本轮未观看其嵌入视频，不把文字检索当作完整视频学习。[Krita Artists 头发讨论](https://krita-artists.org/t/thread-focus-on-how-to-create-hair/41153)

## 7. 根据任务选笔刷

| 工具 | 本轮任务 | 使用限制 |
|---|---|---|
| Ink-3 Gpen | 发丝、细褶、收尖笔触 | 少画重复平行线；压感采样太少会折线化 |
| Basic-5 Size | 可控的不透明细节、高光 | 不能靠白线代替材质体积 |
| Airbrush Soft | 腮红、皮肤明暗、冷暖反光 | 小范围薄叠；全图喷会发灰、失去硬边 |
| WaterC Basic Round-Grain | 背景淡色和花心变化 | 对比轻，不承担清晰人物线稿 |
| Bristles-4 Glaze | 试样中的粗糙笔触 | 本轮人物未采用，纹理感偏强 |
| Blender Blur | 已有颜色的过渡实验 | 需要已有像素；不把它当绘制颜色的笔刷 |
| Texture Hair | 多股纹理试样 | 容易产生规则线群，本轮成图未采用 |
| Stamp Sparkles | 画面边缘少量亮点 | 避开五官与手，不让装饰抢焦点 |

工具的一般类别可参阅 [官方默认笔刷概览](https://docs.krita.org/en/reference_manual/krita_4_preset_bundle.html)；具体取舍来自本机试样，不是官方对本作品的推荐。

## 8. 滤镜只做局部收尾

Gaussian Blur 有独立水平、垂直半径。本轮将其用于独立腮红层和独立柔光层，保留原画层，比较开关效果。不要模糊整张图来掩盖手部、发束或座椅的结构问题。[官方 Blur](https://docs.krita.org/en/reference_manual/filters/blur.html)

Levels、HSV、颜色平衡适合检查或小幅调整整体关系；参数要以实际版本的 configuration 为准，不能从 UI 名称猜字段。本轮只探查这些调整滤镜，未在成图上套用它们。[官方调整滤镜](https://docs.krita.org/en/reference_manual/filters/adjust.html)

## 9. 后续每轮怎样学习

每轮明确一个可见问题，固定其余条件保存前后图；记录笔刷准确名称、尺寸、不透明度、混合模式、滤镜参数和实际结果。先验证结构，再扩充笔刷。新资源先看作者说明与许可，导入后先画试样，未试过不写成“已掌握”。
