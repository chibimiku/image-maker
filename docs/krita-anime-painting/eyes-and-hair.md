# 眼睛与密集发丝：第三轮研究

日期：2026-10-16。用户明确要求眼睛细致、发丝很多，并新建空白文档重新画。这一轮重新设计造型，不读取前两版图像、SVG 或场景几何。

## 查阅的资料

1. [daromart：How to Draw Anime Eyes](https://tips.clip-studio.com/en-us/articles/2674)。作者将眼睛分解为眼白、上方投影、虹膜边缘、瞳孔、虹膜结构和反光，分别建层；提供了对复杂眼部进行有序绘制的依据。
2. [Art Rocket：Paint Anime Eyes in 6 Steps](https://www.clipstudio.net/how-to-draw/archives/159611)。强调结合硬笔与软笔，上部较暗、下部较亮，基础亮色避免全用纯白；最终反光单独处理。
3. [Art Rocket：How to Draw Anime Eyes Like A Pro](https://www.clipstudio.net/how-to-draw/archives/162395)。从眼形、明暗和表情关系出发，提醒先理解结构，再做风格化细节。
4. [Laovaan：Anime Hair Tutorial for Beginners](https://www.clipstudio.net/how-to-draw/archives/171638)。查阅网页文字教程：从发根组织前后多层发束，改变粗细、弯曲与长短；近处发束可以更粗，避免所有曲线完全一致。本轮未观看嵌入视频。
5. [Art Rocket：Easy Guide to Drawing Anime Hair](https://www.clipstudio.net/how-to-draw/archives/161517)。先看整体轮廓，长曲线采用流动的 S 形，少量外逸发丝帮助避免过度整齐。
6. [Krita 官方 Brush-tips:Hair](https://docs.krita.org/en/tutorials/krita-brush-tips/hair.html)。普通圆笔刷也可以承担头发的轮廓与明暗；不需要将“有头发纹理的刷头”当作唯一解法。

这些资料中有 Clip Studio Paint 教程。本轮迁移的是画法原则，软件操作落实为 Krita 的透明绘画层、材质组、原生笔刷和局部绘制，没有假定两款软件的剪贴机制或资源格式相同。

## 本轮眼睛方案

眼睛的细致程度用“结构是否完整且可见”衡量，而不是只统计亮点。新作品将以下部分分层：

- 眼白与上睑投影：眼白略带暖色，上沿投影减少瞪眼感。
- 虹膜：深靛到蓝紫、浅蓝的明暗过渡，外缘暗环与中心瞳孔保持区分。
- 内部纹理：按虹膜椭圆组织放射细线与瞳孔周围的环状结构，不画成同心圆标靶。
- 睫毛与眼睑：上沿较重、下沿轻而断续，外眼角睫毛成小组；眉毛加入细毛方向。
- 反射：左右眼使用一致的主反光方向，并保留少量较弱的环境反光和泪点。

本轮美术决策：蓝紫虹膜、略收敛的眼形，角色视线面向画外的观看者；不靠额外发光滤镜提高眼睛可见度。眼睛要在完整脸部中检查，避免两只眼睛各自精致却视线不一致。

## 本轮头发方案

头发分为后发、发顶、刘海、肩前侧发、少量游丝。每一束单独确定中心走向、宽度和收尖位置，再添加内部线条。

程序构造是本轮的执行手段：中心曲线沿法线展开为发束形状，细线跟随同一束的弯曲与逐渐收窄。不同线有不同起止、色值、粗细和轻微偏移；高光分成短片段，避免统一白条。它仍是程序化绘制，不等于学会了手持数位笔的控制。

用户要求“发丝非常多”，因此本轮确实增加数量；同时保留浅淡线条和大明暗，让密度主要在发束交叠及转弯处起作用。适屏与原尺寸都要检查：若适屏看成灰色毛毡，说明深细线太多；若放大仍是宽平片，说明束内变化不足。

## 新空白文档与可复算证据

- 场景：`data/test-result/20261016/krita-anime-study-v3/new-canvas.scene.json`。
- 配方快照：[author_eyes_hair_study.py](tools/author_eyes_hair_study.py)，不读取之前的画面内容。
- 通用渲染入口仍是 `tools/krita_studio.py render`，不是 `revise`。
- 画布 2400×3600；先保存初始空白 `00-new-blank-document.kra`，再逐层绘制。
- 定义 15 个主要发束，1,082 条细发线／游丝／高光线，176 条虹膜内部纹理。数量是场景定义统计，不是显微意义的真实毛发数，也不是原生笔刷 API 调用次数。
- 基础轮廓及精细曲线由 Qt 在 Krita 内渲染；G-pen、喷枪和亮点笔刷用于独立收尾层。不能把全部细线声称为数位笔自由手绘。
- 另导出眼睛、脸与头发、长发局部，检查细节及遮挡；最终执行与目视结果另记实验报告。

## 后续检查清单

1. 缩略图能否看清椅面、骨盆与膝盖的关系。
2. 双眼的虹膜上下是否被眼睑合理遮挡，主反光是否同向。
3. 细发丝是否延续同一束的方向，有没有突然横穿脸或衣装。
4. 外轮廓、主束交叠、内部细丝是否有明显的线条层次。
5. 局部放大能否看到新增结构；全图是否因此更清楚，而非只有数量增加。
