# 海蓝宝石质感眼睛：分层练习与人物应用

用户认可上一版眼睛的改善，要求继续练习，追求宝石般的感觉。本轮先做独立眼部画布，检查后再把同一套虹膜替换回人物原有眼睛层，另存版本。

## 新读的来源及适用方式

- [Celsys 官方启动教程：虹膜/瞳孔上色](https://www.clip-studio.com/site/gd_en/csp/startupguide/csp_startup/CSPaint_02/Chapter02_5_1_3.htm)：虹膜在眼白上方独立处理，建立暗部后在下部增加较亮过渡。这里采用层次关系，没有声称直接使用 CSP 工具。
- [The Etherington Brothers / Art Rocket：Gems, Crystals, and Gold](https://www.clipstudio.net/how-to-draw/archives/163257)：用相连的内部形状、分散的明暗来表达宝石。本练习只借鉴少量折光色面；眼球和虹膜仍保留曲面关系，不把整个虹膜做成不透明石块。
- [CotonMainty：Simple 2D Sparkling Eyes](https://tips.clip-studio.com/en-us/articles/11782)：作者在 Celsys 平台发布的个人教程，并非 Celsys 官方规范。采用上睑阴影、下部受光、有限范围反射和双眼同光源方向的建议。本文写有混合模式方法，本轮未照搬所有混合模式，以透明渐变和独立层实现可控效果。

## 预设要素

保留原杏眼轮廓与头部朝向。虹膜改用与头部一致的投影，而非直接放置一个屏幕竖直椭圆。配色由深灰蓝过渡到浅蓝绿；上方较暗，下方保留透光；两眼主反射都来自画面左上。瞳孔保持深色且不被高光盖住。

[元素 JSON](../../data/test-result/20261016/krita-seated-practice-v4/gem-eyes/elements.json) 保存颜色、虹膜/瞳孔尺寸、亮点强度、工序和检查项目。

## 工序与检查

1. 新建 2400×1440 眼部练习画布，先画眼皮、虹膜构造位置。
2. 分层绘制虹膜深浅、少量透明色面、短曲纹、上睑遮光。导出并目视检查后才继续。
3. 检查发现构造圆仍露在眼皮外，移除其成稿可见线；草稿导出保留。
4. 加小面积窗光、次反射、下半部细小折光点；不增加眼外星形光效。
5. 检查过程展示卡发现矩形阴影越出虹膜，改成虹膜椭圆内的渐变阴影后复看。
6. 返回原人物，仅替换两个原有虹膜层，另存 KRA/PNG；看脸部局部及整图，确认瞳孔和光源方向可读。

小样使用同一份形状生成，放大展示不是另一种独立眼睛设计。最后四个过程卡展示底色/纹理/阴影/反射的叠加。

## 评价与局限

相对上轮，眼部上下对比和下方透亮感更明显，反射由圆点变为有方向的窗光；细小亮点帮助表现宝石感。全图尺度下只有明暗和主反射显著，微细纹理主要在局部可见。

纹理仍有规则的放射倾向，细节由程序曲线构造，不是光学模拟。整体人物的皮肤、布料与手部质量并未因本轮眼睛修改而自动提升。颜色比上一版稍偏蓝绿，这是本轮海蓝宝石方向的风格化选择。
