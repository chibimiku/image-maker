# 坐标草稿 → 线稿 → 底色 → 五官 → 氛围

## 每一工序的检查要求（后续练习持续采用）

完成一个工序后，先导出当前画布，查看全图及相关局部，再决定下一步。具体执行为：**绘制 → 导出 → 目视自查 → 修改具体问题 → 复看 → 继续**。草稿检查朝向、关节与承重；线稿检查遮挡及穿透线；底色检查轮廓与色块；阴影检查光向与体积；五官检查对齐和表情；细节检查归属与遮挡；最后看缩略、灰度、镜像及重点局部。发现结构问题应回到对应工序，不能靠装饰和光效覆盖。检查不等于自动通过，遗留问题要如实记录。

完整坐姿练习的实际执行与修正见 [第四轮工序复盘](../seated-practice-20261016.md)。

用户追加要求“先划线、草稿规定眼睛等坐标”。本轮把这一要求放在实画前执行。

## 查阅依据

- [Krita Inking](https://docs.krita.org/en/tutorials/inking.html)：降低草稿的不透明度，在独立层整理线稿；线条不宜因过度平滑而机械化。
- [Celsys 官方首次插画流程](https://tips.clip-studio.com/en-us/articles/1250)：从草稿到绘线和上色的分阶段演示。
- [Simple Anime-style Coloring Techniques](https://www.clipstudio.net/how-to-draw/archives/162911)：底色、阴影、高光分层，可用有限的柔和过渡辅助形体。
- [Detailed Anime Aesthetic Art](https://www.clipstudio.net/how-to-draw/archives/164520)：草稿阶段先安排构成，细化时也考虑光照；不是最后任意加滤镜才决定氛围。

## 实际顺序

1. **元素准备**：JSON 定义朝向、比例、视线、表情、光源及画布。保存模板 hash。
2. **坐标定位**：生成脸部中心线、眉线、眼线、鼻底线、口线、下巴点；同时保存数值坐标。
3. **结构草稿**：画头颅、颊颌、脖子、眼睛框、虹膜圆及鼻口占位；实际使用 Pencil-2。
4. **清理线稿**：独立 G-pen 轮廓层。草稿隐藏，定位线暂留以复核位置。
5. **皮肤底色**：显示预先准备在轮廓下方的肤色层，隐藏坐标线；不靠涂色覆盖线稿。
6. **逐项五官**：眉 → 眼 → 鼻 → 嘴 → 耳，每步保存一张完整画布阶段图。
7. **头发上下文**：保持前额与五官开放，避免刘海掩盖定位错误。本练习不是完整发型成品。
8. **整体氛围**：采用预定的上左柔光、暖肤色与冷蓝发色；少量腮红和下颌暖阴影，避免强光效压过五官。
9. **单部位小样**：从同一套参数分别画眉、眼、鼻、嘴、耳，验证参数和整脸结果一致。

氛围在计划阶段确定，最后阶段仅落实和协调。先看灰度和位置，再看冷暖；不要让“氛围漂亮”掩盖视线或结构偏差。

## 可以怎样迭代

眼形不对时改眼睛参数并重新生成草稿与五官；位置不对时改头部/眼距等坐标，不只挪最终像素。转头不对时先检查方向约定、投影和中线，而不是分别修补某一只眼睛。

每次换一个输出目录，保留草稿和失败结果。修改结果仍需目视检查，坐标统一并不保证画法一定自然。
