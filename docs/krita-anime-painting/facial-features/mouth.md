# 嘴与唇经验

目标嘴很小，近水平，略微张开；唇色大多融在肤色里。上一版上下两条明显弧线更像嘟嘴，与目标神态不同。

专门查阅 [Raquel Arellano：How to draw a mouth and lips](https://www.clipstudio.net/how-to-draw/archives/161618)。教程以结构解释嘴唇体积和开合，再讨论风格化；不是要求动漫脸画出完整唇框。

本轮 JSON 先规定口线高度、宽度、开口高度及表情。以窄缝表现轻微张开，不画牙齿、不描完整下唇。下唇只留极弱的色彩提示。鼻、嘴和下巴的中心线都随头部方向变化。

自检：嘴角是否意外下垂、开口是否过黑、上下两笔是否产生不需要的撅嘴感。不要用“很短的一根线”作为无需检查方向的理由。
