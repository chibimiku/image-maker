# 脸型、朝向与坐标

## 从参考观察

目标面部接近正面，左右有轻微差异，但被刘海和耳饰影响。不要把这些不对称直接解释为确切的 yaw 角。

## 专门查阅

[Liz Staley：多角度眼睛](https://tips.clip-studio.com/en-us/articles/6311) 说明头和眼球都有体积，转头时远眼通常更窄、更靠近鼻子；俯仰时各横向五官线需要随头部变化。

[Sara Tepes：女性脸部入门](https://www.clipstudio.net/how-to-draw/archives/172148) 用于复习结构、比例与软硬形状之间的关系；不是将写实脸部比例直接套到二次元参考上。

## 本轮构造

先定义局部脸坐标，再做浅曲面投影：脸宽、颅顶、颊线、下颌和下巴决定轮廓。眼、眉、鼻和嘴都由同一套局部位置生成。转头产生远近侧压缩；鼻子额外前突；视线单独补偿，不能仅把两只正面眼睛平移。

模板约定：正 yaw 向观看者右转，正 pitch 朝下，正 roll 在画面内顺时针。三栏分别为正面、向右 25°、向左 25°加轻微俯仰和倾斜。

用户强调透视后，最新模板在旋转后增加针孔透视相机，并保存包围盒与侧面构造检查。早期平行投影试画另存，不与最新结果混淆。检查依据和限制见 [透视验证要求](perspective-verification.md)。

这仍是浅角度风格化练习，不是完整三维头模；不支持侧脸、极端俯视或鼻子完全遮住远眼的角度。其真实范围在模板中限制为绝对 yaw≤35°。
