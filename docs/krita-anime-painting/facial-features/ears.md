# 耳朵经验

参考主要露出一侧的耳与耳饰，另一侧受头发遮挡，不能据此假定耳朵完全对称可见。

专门查阅 [Eridey：Ultimate Guide to Drawing Ears](https://www.clipstudio.net/how-to-draw/archives/160418)。耳外缘、内部折叠与耳垂可以从结构中简化；眉与鼻底等位置关系帮助放置耳朵。转头后还应考虑可见面和遮挡。

本轮将耳朵位置、宽高、内部线宽分别参数化。外缘用一条清楚的弧线，内部只保留能说明折叠的少量线。三栏按方向弱化远侧，再用少量头发提供遮挡上下文。

当前只是浅角度练习，远侧使用弱化近似，尚未建立完整的耳廓旋转模型。不能把这一简化当作所有角度都正确的解法。
