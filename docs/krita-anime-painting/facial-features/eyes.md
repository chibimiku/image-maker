# 眼睛经验

目标的眼形较收敛，外眼角细长，虹膜低饱和灰蓝。上一版虽然增加了纹理，仍因圆眼、深瞳孔和较强蓝紫对比而偏离目标。

专门来源：[daromart 的分层画眼](https://tips.clip-studio.com/en-us/articles/2674)、[多角度眼睛](https://tips.clip-studio.com/en-us/articles/6311)。前者用于拆分眼白、虹膜、瞳孔和反光，后者用于转头时的体积与远近关系。

本轮先画眼睛定位框和虹膜圆草稿，再以眼宽和开合高度构造眼睑。虹膜和纹理被明确遮罩限制在眼睑开口内。上眼睑较重，下眼睑较轻、部分断开；下睫毛减少。瞳孔变小、对比降低，高光保持同向。

JSON 把眼距、开合度、虹膜直径、瞳孔宽高比、上下眼睑线宽分开，使后续能逐项改动。判断应优先看眼形、视线和神态，再看纹理数量。不能用增加亮点补救眼睛位置错误。
