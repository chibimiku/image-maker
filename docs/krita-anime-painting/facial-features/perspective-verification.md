# 透视应怎样验证：可靠来源与本轮检查要求

用户强调透视后，补查系统美术教学来源。以下分别写清来源规则、迁移到本作品的办法、以及能证明到哪一层。

## 来源

- [Proko / Stan Prokopenko：How to Draw the Head from Any Angle](https://www.proko.com/course-lesson/how-to-draw-the-head-from-any-angle)。采用页面公开 Lesson Notes：先建立颅体与下颌，侧面切片和眉线用于判断转头、俯仰；脸部各方向需要与同一头部体块一致。这里学习构造关系，不把写实三庭等分强套到二次元目标脸上。
- [Love Life Drawing：Measurements](https://www.lovelifedrawing.com/measurements/)。采用页面文字课程：交叉测量角度、对齐与相对长度，不能只靠已知的人体符号推测位置。修正前保留错误线作对照。
- [Drawabox 作者站内公开讲评](https://drawabox.com/r/artfundamentals/post/7uvodp)。其讲评明确区分延长已画线与重新向理想消失点连线；前者才能暴露误差。关于一点透视练习，是延长已画边到地平线并比较偏差，而不是重画线指向 VP。
- [Drawabox 官方 Rough Perspective 演示](https://www.youtube.com/watch?v=hbjFN6RN1jA)。检索可见官方章节在 07:42 进入检查延长线。本轮未观看视频，不声称完成视频学习。

Drawabox 的主课程文字页本轮返回 403，因此未声称通读其最新正文，也未绕过访问限制。采用的可读文本是作者在自己网站保存的公开讲评；不依赖第三方搬运文章作规则来源。

## 适用边界

头部包围盒的**直线边**适合检查同方向的消失点；脸面上的眉、眼睑和嘴是曲线，不能强行让所有五官曲线延长后交到一个点。侧切圆的透视形状可用投影后的椭圆辅助判断方向，但不能把任意画出的眼形当作严格投影圆。

头部在转动，其局部水平平面的灭线也会变化；这条灭线不必等于固定场景的地平线。独立视图练习中的包围盒、眼球和五官应共用相机与方向约定，不能混用。

## 本轮检查表

| 编号 | 要检查什么 | 怎样检查 | 不合格时怎样处理 |
|---|---|---|---|
| P01 | 相机与方向约定 | 明确相机距离、焦距、主点、yaw/pitch/roll 正负；检查点在相机前方 | 不继续添五官，先修正相机与坐标约定 |
| P02 | 包围盒直线透视 | 显示全部 12 条边，按三个轴分组；延长原边检查各组 VP；平行于画面的方向允许 VP 在无穷远 | 找出不一致的一组边，保留旧线作比较；不重连理想 VP 来冒充通过 |
| P03 | 颅体侧面与中线 | 显示投影侧切圆、中线；头顶、眉、鼻、口、下巴都服从同一朝向 | 修改头部体块，不能分别旋转某一个五官掩盖矛盾 |
| P04 | 远近眼与眼球 | 比较投影后的两眼宽度、间距及曲线；观察远眼是否变窄、向鼻侧收；视线单独处理 | 调整曲面和视线，避免两只正面眼睛贴到侧脸上 |
| P05 | 鼻前突、鼻口中线 | 鼻尖比脸面突出，转头后投影位置变化；嘴和下巴仍连接同一中线体系 | 检查深度，不能只在最终图里横移鼻子 |
| P06 | 耳朵与遮挡 | 耳位跟随颅体、眉鼻高度和角度；观察哪侧应被遮挡 | 修耳的位置、可见面或遮挡，避免两侧同样露出 |
| P07 | 俯仰和倾斜 | 检查眉眼、鼻底、口和下巴的压缩、上下位移及倾斜是否一致 | 修改 pitch/roll 后整组重画，而非只转脸轮廓 |
| P08 | 与参考交叉对齐 | 统一比较尺度后检查眼角、鼻底、口角、下巴的相对角度和距离 | 保留风格化差异，但记录明显结构偏差 |
| P09 | 最终自然程度 | 同时看裸草稿、无引导线结果、镜像和缩略图 | 几何自洽但神态不对，仍需修改；数值通过不是成品通过 |

## 本轮实际执行

原试画采用浅曲面上的平行投影，仅可称转头关系练习，不能据此声称有限消失点的透视已通过。用户强调透视后，模板新增明确的针孔透视相机，最新输出改用此版本。

最新相机：距离 1500、焦距 1422，均为一致的头部空间单位，不是毫米，也不是对用户参考的镜头标定。每个独立练习视图的主点为自身画面原点。

在新画布的 `01b-perspective-structure.png` 中保留：

- 头部包围盒三组颜色的边与沿既有方向的短延长线。
- 侧切圆的投影，中心线与各五官横向构造线。
- 草稿、五官定位框、数字坐标；最终绘制时隐藏这些检查层。

对应 `perspective-checks.json` 保存各轴的有限 VP 或无穷远方向、12 条边的数值残差与两眼投影宽度。它检验的是**按这套相机生成的包围盒是否自洽**；因为盒子由程序构造，残差接近零本来就是应有结果，不能把它解释成美术能力评分或独立验收。

这一轮额外检查：正面双眼等宽；左右转头时远侧眼宽小于近侧，鼻尖与嘴因前突深度不同而有不同偏移。耳廓只是简化轮廓和远侧弱化，尚未做完整三维遮挡，列为 P06 的待改进项。

完整头部形体和眼球转动仍是近似，模板限制绝对 yaw≤35°。极端侧脸、鼻遮远眼、极端俯仰不在已验证范围内。
