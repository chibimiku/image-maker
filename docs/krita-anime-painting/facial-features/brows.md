# 眉毛经验

目标是浅灰蓝的细眉、低拱、安静的表情。虽然细节不多，眉眼距离仍明显影响神态。

专门查阅 [葉蘊儀的眉毛与睫毛教程](https://tips.clip-studio.com/en-us/articles/16997)：眉头、眉峰、眉尾共同构成眉形；更强的眉峰会增加锐利感。使用的是网页文字段落，未声称观看完整视频。

本轮 JSON 单独规定眉宽、线宽、弧高与距眼高度。先用定位线固定眉眼关系，再画浅弧；只加少量几乎不显眼的毛线。转头时整条眉随脸部曲面压缩，不能让眉毛保持正面长度。

自检：眉峰是否过高、两端是否下垂成悲伤表情、眉眼距离是否与同一情绪一致。并非“画得越多根越接近参考”。
