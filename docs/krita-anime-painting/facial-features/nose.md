# 鼻子经验

目标鼻子采用很强的省略：没有从眉间连到鼻尖的长轮廓，只以浅亮斑和很短的暖色笔画提示体积。

专门查阅 [Raquel Arellano：How to Draw a Nose](https://www.clipstudio.net/how-to-draw/archives/160376)。先理解鼻梁与鼻尖的简单体块及不同角度，再决定风格化时省略哪些线。

本轮鼻底位置来自坐标表，额外设置鼻子前突深度；转头时高光与鼻底短线一起投影。正面不描鼻梁，鼻翼只在偏转角度加极淡提示。高光用小面积暖白形状，不画成圈。

单独练习放大鼻子是为了检查短线和亮斑关系，不代表整脸中应把鼻子画得更突出。前突偏移必须与眉眼中线一致，不能只在二维画面中任意挪动鼻点。
