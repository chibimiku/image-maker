这里的描述来自对**用户原图**的人工目视观察，教程只用于解释画法，不替代对这张图的判断。原图 1696×2528；面部检查裁剪 `[625,390,1060,675]`，没有为了画图而将参考像素贴入新画布。

| 部位 | 目标可见画法 | 上一版的差距 | 本轮落实 |
|---|---|---|---|
| 脸型 | 脸颊平顺收窄，小而略圆的 V 形下巴 | 下半脸偏几何，额头与五官关系较生硬 | 先画头部曲面、颊线、下巴点，再放五官 |
| 眉 | 细、低拱、浅灰蓝，部分藏在刘海后 | 单根眉毛细节偏显眼，眉形更像刻画过的线条 | 以细弧为主，少量低对比毛线 |
| 眼 | 上沿较平，外眼角细长，眼白暴露适中 | 偏圆、瞳孔高且暗，有凝视感 | 用宽高比控制开合，收小瞳孔，降低虹膜对比 |
| 虹膜 | 浅灰蓝，顶部阴影、下部反光，纹理服从小面积明暗 | 蓝紫饱和与对比过强，细节有宝石／机械感 | 灰蓝色阶、小而柔和的瞳孔、轻细纹理 |
| 睫毛 | 上重下轻，外眼角成少量小组 | 下睫毛与硬边过多 | 减少下睫毛，保留上眼睑轻重差 |
| 鼻 | 基本没有鼻梁轮廓；一点亮色与下方短线 | 鼻梁线和环形高光过显眼 | 撤去鼻梁长线，按朝向偏移短线与高光 |
| 嘴 | 很小、近水平、略微张开，唇色极淡 | 上下两道线制造了嘟嘴感 | 窄开口，不描完整唇框，降低下唇线 |
| 耳 | 靠近眼鼻高度，主要露出一侧，耳饰与头发遮挡 | 相对独立于转头关系 | 与头部一同投影，远侧弱化 |

## 比例观察的限度

目视粗估中，单眼宽约占可见面部宽度的三成，虹膜直径约占眼宽四到五成，嘴宽远小于一只眼。发际线与部分轮廓被遮挡，不能据此宣称还原了精确头型或头部角度。

本轮 JSON 中的数值是**为练习选择的构造参数**，不是将原图做了可靠三维测量。参考近于正面；±25° 两栏是额外练习，不声称原图存在这些视角。
