# 动漫头发专项：先学习结构，再练习细化

最新：[第三轮分束、遮挡与画质自检](quality-pass-20261017.md)。

后续实作：[连贯大形、软硬边缘与高光](material-practice.md)。表情另建 [独立 Topic](../expressions/README.md)，不改变本专项流程。

本轮由用户明确要求“先专门学习动漫人物头发”。之前的头部练习保存不覆盖，先停止继续堆叠它的发丝，转向独立结构练习。

## 实际阅读的美术资料

1. [Hyanna Natsu / Art Rocket：Easy Guide to Drawing Anime Hair](https://www.clipstudio.net/how-to-draw/archives/161517)。阅读公开文字；重点是以头骨帮助定位发根、先组织外形、使用长而流畅的 S 曲线，并按光源安排阴影。另用浏览器实际看过其直发与卷发的简洁轮廓对照图。未声称观看嵌入视频。
2. [Stan Prokopenko / Proko：How to Draw Hair](https://www.proko.com/course-lesson/how-to-draw-hair)。阅读公开 Lesson Notes。先理解头部和头发体积，再组织明暗与纹理；阴影应成组，细节不宜均匀铺满。这里学习体积与明暗原则，没有把写实画法全部强套到动漫作品。
3. [KevinFarias：Draw and Paint ANIME Style Hair](https://tips.clip-studio.com/en-us/articles/5999)。阅读页面公开文字；该页英文为机器翻译。采用“方向线—几何体积—细节”的训练顺序，以及底色、阴影、高光、细丝分层的方式。作者在 Celsys 平台发布，不能称为 Celsys 官方绘画规范；未观看视频。

资料是绘画思路，不是固定比例法规。本练习中的头发与头骨间距、色值和分束数量均为自己的设计参数。

## 对自己原画的识图评价

评价对象是本机头部练习的实际输出，非教程成品：

- 顶部的几片形状分别闭合、根部过窄，组合后容易读成叶片、厚带或假发片。
- 每个发束使用近似的横向渐变，亮部缺少整个头部上的共同方向。
- 大量等间距细丝覆盖所有区域，使明暗和纹理同样密集，呈现重复的塑料丝感。
- 更换前发后，旧遮挡没有同步更新，出现平直空白带与细丝越界。
- 现有算法适合控制曲线与图层，不能据此假定生成的几何已经像自然头发。

因此这次的训练重点是统一外轮廓、发根与体积，不使用旧的逐片带状生成器来作为新练习的大形基础。

## 新练习的执行顺序

1. 空白画布画头骨包络、发根位置和方向箭头，显示头发离开头骨后的厚度。
2. 先识图评价草稿。第一稿发尾尖角过密，像锯齿；修改为较少的主发尾、较长弧线和不同长度后复看。
3. 下一工序只画连贯的后发、前额和侧发大形，用少量明暗检验体积；此时没有密集细丝。
4. 再画中型分束与少量高光、细丝。第一稿细线越过刘海落到额头；改为前发与后发分别蒙版，后发额外扣除脸部。
5. 减淡过亮的高光带，再查看完整三栏练习图。

三栏沿用同一份原创轮廓，分别展示构造、明暗和选择性细化；没有描摹或粘贴教程图片。

## 后续必须逐项自查

| 检查 | 看什么 | 发现问题时先改什么 |
|---|---|---|
| 头骨与厚度 | 外轮廓是否包住头骨，顶、侧厚度是否合理 | 头发总外形 |
| 发根与分缝 | 分束是否有可解释的来向 | 发根位置与流向 |
| 整体轮廓 | 去掉细线后是否仍能读为同一发型 | 大束与长短节奏 |
| 前后关系 | 刘海、侧发、耳朵、后发是否互相穿透 | 遮挡与分层 |
| 明暗归属 | 明暗是否跟随共同头部体积 | 大片阴影和转折 |
| 高光 | 是否形成过硬的头箍、每束是否同亮 | 亮区位置与边缘 |
| 发尾 | 是否每束同样尖、同样长、同样张开 | 轮廓节奏 |
| 细丝 | 是否只是平均排线，是否越过所属发束 | 减少、重新分布或裁切 |
| 整脸尺度 | 是否比头发局部看起来更僵硬 | 回到整体结构 |

这张练习还很简化：发尾节奏仍有规律性，后发体积信息少，高光边缘偏硬。因此它作为结构训练保存，未直接替换人物正式发型，不能称头发已经画好或达到参考完成度。
