# 综合复看：眼睑、睫毛和耳饰连接

大分辨率重新绘制后，逐部位又出现了小图里不明显的问题：眉毛短线像整齐的缝线；耳饰挂点偏高；外眼角睫毛是几根等粗平行线。

修改与实际复看：

- 眉毛减少重复短线，打散间距、长度和方向，收在基础眉形内。重新查看眉毛局部，缝线状外缘减轻。
- 耳饰从原位置移到耳垂附近，挂点、短钩、吊坠单独一层。按前发形状扣除遮挡后，左侧被挡部分不再穿过头发，右侧挂点与耳垂关系清楚。
- 先查看 `eyelids-before.png`，再把睫毛改为尖端收细、根部略宽的小簇。下眼睑减淡，眼角增加很小的暖色提示。复看 `final-head-reviewed/eyes-detail.png`，睫毛不再是等粗的杆，宝石虹膜保持可读。

经验：部位单独成立还不够，组合后要检查连接和比例。高分辨率不是把小图放大，而是用同一曲线几何重新绘制，让重复规律和错误端点更容易被识别。

当前限制：睫毛仍有设计上的规则性，耳饰和耳垂的空间接触是风格化表达；头发仍是下一项重点，不能因为其它部位改善就称整个头部已完成。
