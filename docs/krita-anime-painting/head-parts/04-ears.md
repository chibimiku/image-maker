# 耳朵：先检查无遮挡结构，再放回头发后面

修改前识图：人物耳廓基本被侧发遮住，只能看见耳饰，不能从当前画面确认内部结构是否正确。因此另开空白画布练习。

先画耳轮、内部折叠、耳甲腔与耳垂的构造线，查看后发现内线交叠，需要用前后遮挡和明暗区分。随后画软骨明暗，再画较少线条的二次元简化版本。

第二次检查发现凹陷的柔和阴影几乎没有显示。实际离屏探测确认，这台 Krita 的内置 SVG 渲染器把 objectBoundingBox 径向渐变渲染成透明，而显式 userSpaceOnUse 版本正常。将每次使用的渐变按对应形状边界转换后重新绘制，复看时耳甲腔已能读到浅凹陷。

当前评价：外缘、内部 Y 状折叠、凹陷的关系比初始不可见的耳廓更清楚；线条仍偏示意图，耳垂和内部折叠的自然变化不足。它是结构练习，不作为严格解剖准确性的证明。

经验：被头发挡住的部位不能直接判定“画好了”；先做无遮挡版本。构造稿可以保留穿透线，最终简化时要说明遮挡和凹凸。不能把“代码里添加过渐变”当成实际画面已经出现了渐变。
