# 头发：先修整体连接，再讨论细丝

修改前实际看图：头顶分缝两侧有鼓包，发丝高对比而重复，局部高光像白色刷痕。当前细丝数量已经足够多，问题在整体发束、发根和明暗关系。

第一稿重新建立后方头顶体块、降低前发细丝对比，并把右侧发束向外整理以露出耳朵。复看拒绝这一稿：后方体块画成了厚环状带，像头箍；发根与前额衔接不顺。失败图保存为 `first-head-rejected.png`。

第二稿把后方体块改为完整轮廓，并补上冠部两侧发束。复看仍有局部鼓起；旧后发蒙版按以前的前发形状扣除，留下平直空白带。此稿另存 `second-head-review.png`。

第三稿降低冠部曲线鼓起，重新生成后发遮挡；肤色层也跟随新前发形状更新蒙版，避免皮肤色覆盖头发。实际复看头部与耳朵：发根衔接比前两稿连续，旧白色刷痕消失，右耳可见且位于前发后、后发前。

经验：发型变化时，遮挡蒙版、皮肤亮面与后发细丝都要一起更新。分组的大形不对，细丝只能让错误更清楚。先检查缩略轮廓和体积，再看根部与末梢的细节归属。

当前限制：发束仍有规律性，冠部表面还有较平滑的路径质感，耳后部分层次不够自然。不能把三轮修改称为已达到参考画质。
