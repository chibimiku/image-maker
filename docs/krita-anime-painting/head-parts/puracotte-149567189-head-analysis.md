## 先定头部方向，再定五官

图中眼睛大致位于原图 `(345,463)` 与 `(521,403)`，嘴部约 `(463,546)`，下巴约 `(480,606)`。这些是人工读图定位，非测绘真值。两眼连线向画面右上倾斜约 19°，说明明显的画面内头部侧倾；不能据此认定水平转头角度也是 19°。

头颅、眉眼线、鼻口及下巴一起偏转。额头到下巴的中轴朝右下走，和眼轴大致构成一组局部坐标。先画颅球及下颌，再标眼轴、中轴、鼻底、口线，最后加颅骨外的发量。左右眼不要求机械镜像，须看眼角、眼皮开合、遮挡及远近关系。被刘海挡住的额头和发际线只能推断，不能按看得见的发边直接当颅骨边。

## 五官为什么柔和、但不模糊

| 部位 | 成图观察 | 可执行方法 | 要避免 |
|---|---|---|---|
| 眼睛 | 上睑及睫毛最深；虹膜上暗下粉紫亮，有多种大小的反射；眼白受环境暖色影响 | 先眼球开口和共同视线，再上睑投影、虹膜明暗、少量主反射，最后小碎光 | 把两颗虹膜做成同尺寸宝石贴纸；所有亮点同强度 |
| 睫毛与眉 | 睫毛成组、长短不齐；眉毛被头发遮住，存在感弱 | 外眼角稍强化，内侧更细；眉色顺整体紫灰色系 | 全眼等粗描边、均匀梳齿状睫毛 |
| 鼻子 | 只有极小的暖色提示，鼻梁基本省略 | 用局部肤色转折提示前突，把鼻底笔画留到最后 | 长鼻钩、硬白三角或完整鼻轮廓 |
| 嘴 | 小而偏暖的微弧线，两端与唇边轻；口周没有厚唇膏边 | 沿头部坐标定位，开口线比唇色清楚；笑意另归表情专题 | 移动一边嘴角而不检查面中方向，给主稿擅自换表情 |
| 脸颈 | 脸大部分很亮；下颌到颈部有明确投影，侧脸有局部亮边 | 先大肤色，分开画脸的缓慢转折与下巴遮光 | 用腮红代替形体阴影；整圈等宽白描边 |

## 腮红：底色、血色、细线是三件事

1. **位置和形状**：主要横铺在两眼下方的上颊，轻带鼻梁。不是低处两颗圆红点，也不延伸到整个下颌。顺着倾斜的眼轴安排，不能把两边腮红贴在画面水平线上。
2. **底层软红**：大范围低对比的桃粉/玫粉渗入肤色，中心略暖、外缘逐渐消失。局部不均匀会更像皮肤，但先保证整体范围。
3. **细短红线**：眼下有疏密变化的细短线，长度、间距和透明度不同。线是血色的附加表现，不应变成两块栅栏。先看缩小图，细线不该抢过眼睛和嘴。
4. **受光与反射**：颊部有很轻的浅亮，侧缘局部接近白色；不要在每块红上都放同样的白圆点。这里的高亮和腮红可以共存，腮红不是涂上去的哑光红圆片。
5. **Krita 层次建议**：肤色 → 形体阴影 → 独立软腮红 → 少量短线 → 局部浅亮。腮红层用正常或正片叠底都可，先看实际叠色，不把模式名称当配方。透明度分别控制，擦掉过整齐的边缘。

补读了 CELSYS 发布的 [Tsunoju 皮肤步骤](https://tips.clip-studio.com/en-us/articles/1210) 的公开文字：分开处理肤色阴影、冷色、柔和腮红和高亮。它支持分层观察方法，不是这张参考的作者流程证明。

## 头发的立体来自哪些层

| 分区/层级 | 图中表现 | 画法与验证 |
|---|---|---|
| 颅顶与根部 | 分缝在头顶偏左；顶部大块近白，发根转折带淡紫，发量包住颅球 | 草稿先画颅球，再画发量外壳和分缝；遮去细线后仍应看出圆颅顶 |
| 大分区 | 刘海、两侧脸旁束、耳后聚拢区、后部垂发不同走向 | 各区先整体轮廓，标明确固定点，不能全部从一个点喷射 |
| 中发束 | 刘海粗细不一，发尾翻卷、互相搭接；侧发与后发穿插 | 先决定谁在前，再画覆盖边。接触阴影贴下层，被压住处窄且清楚 |
| 形体转折 | 面向光的宽面近白；转走处宽幅冷紫灰；转回来的下缘有粉色 | 用宽面建立亮/中/暗，暗面不是每束等宽描边；亮带随弧度改变宽度与位置 |
| 遮挡投影 | 刘海下缘、耳后和束间缝隙的局部暗线较深 | 与宽幅转折暗面分层；线到空处停止，不穿越前束 |
| 反射/透亮边 | 粉紫薄边和暖亮点参与环境配色 | 主光仍控制最大亮面；反射比主亮面弱，不能把整圈边缘照亮 |
| 小束与发丝 | 大束里有分裂、合拢，线色随所在面变化；少量飞丝脱出轮廓 | 大明暗读得懂后再加，亮面少深线，阴影内弱对比；避免等距全长平行线 |
| 边缘控制 | 强光处轮廓淡失，眼周/遮挡处较清楚 | 让视线落在眼睛与脸旁，避免所有头发外缘同粗同深 |

光源方向只能从成图推测：上部及画面右上有强亮环境，正面也有柔和补光；并非可从单张插画还原的唯一物理布光。橙花、黄绿叶、冷紫背景与粉紫发色共同制造清透感，孤立头发小样无法复现完整氛围。

补读 [Esseyli 的头发教程](https://www.clipstudio.net/how-to-draw/archives/162964) 公开文字：先整体轮廓和光影，再缩小笔刷细化；细节无法掩盖基础光影错误。本轮未观看内嵌视频。

## 接下来的头部实画工序与验收

1. 头颅/下颌草稿和倾斜局部坐标：同时检查眼、鼻、口、耳，不能靠加头发遮盖结构错误。
2. 发型草稿：分缝、颅顶体积、前后分区与束的覆盖顺序；先画少量不等宽中束。
3. 轮廓与底色：减少眼周以外的硬黑边，确定浅皮肤、浅紫发和紫粉眼的明度关系。
4. 大明暗：缩到 25% 看颅顶是否圆、发束是否在转；没有体积就返工，不加细丝。
5. 脸部：腮红软色块与结构阴影分开，近距离看边缘、缩小看是否过红。
6. 精细：上睑、虹膜、接触阴影、发尾分叉和少量飞丝；保留大块安静的亮面。
7. 总评：同时看头部方向、眼神、面部血色及头发体积。当前练习只验证局部方法，不宣布达到参考完成度。
