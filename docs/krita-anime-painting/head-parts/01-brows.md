# 眉毛：观察 → 修改 → 复看

修改前实际看图：眉毛像等粗的灰色弧线，两端截断明显；颜色偏灰蓝，神态平静，这两点可以保留。

修改：先画收尖的浅灰蓝眉形，再加入沿眉头至眉尾方向变化的低对比短毛线。眉眼间距和原有朝向保持。

修改后实际查看 `01-brows/brows.png`：眉尾变细，眉头不再像硬切的一根线；细毛只在放大时可见。右眉上缘仍稍碎，缩略看时应主要读到眉形，不能继续加黑加粗来追求“每根可见”。

经验：眉毛细节需要依附整体眉形；对浅色头发角色，用少量柔和毛线即可。线条数量不能代替眉形、方向和表情。
