# 脸部体积：软色块必须服从部位边界

修改前实际看图：脸颊大片同色，主要靠轮廓读形；下颌与脖子的投影较硬，五官与皮肤的体积不协调。

使用已修正的径向渐变补右侧冷阴影、颧颊暖色与左侧柔和亮面。第一次复看时，左眼被皮肤亮面盖淡，说明皮肤色层虽然在脸形范围内，仍会误盖五官。

修改蒙版：肤色亮面避开双眼的眼白轮廓及眼睑线，保留已完成的宝石虹膜。再次查看整头，眼部对比恢复，脸颊冷暖比原稿清楚。

经验：只给一个“脸形蒙版”不足以保证正确分层；同一脸形中还有眼睛、鼻唇、头发的不同覆盖关系。软边也必须有部位归属。

当前限制：脸部仍是浅曲面与色块的风格化处理；下颌线条和脖子投影仍偏机械。本轮保留已接受的外轮廓，没有把加腮红误称为完整解剖建模。
