# 嘴部：控制开口与唇色的主次

修改前实际看图：一条细口线与另一条下唇亮线分离，既没有明显唇体积，也有双线符号感。

第一次尝试加小开口和唇色后，实际查看局部和整头：唇色偏重偏紫，开口比预期突出，下方亮线仍分离。因此没有把第一稿当作已完成。

二次修改：缩窄唇色面、降低不透明度，口缝保持很细；把下唇高光收近并减淡。

复看：嘴缝与唇色更集中，平静神态保持；在正常看头部的尺度下，浅唇色主要起柔和过渡作用。当前没有完整口腔和牙齿设计，因为这个表情只需要极小开口。

经验：唇部细致不等于明显描上下唇框；先控制开合，再决定哪些边缘应弱化。每次应在整脸里复看，防止局部漂亮却改变表情。
