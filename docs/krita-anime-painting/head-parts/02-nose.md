# 鼻子：拒绝第一次仅“加细节”的修改

修改前实际看图：短弯线和亮点像分开的符号，鼻尖体积弱。

第一次修改后查看局部与整头：缩小高光、补暖色渐变后，弯线仍清楚地像 C，改善有限。这次未据此直接进入下一部位，而是继续修改。

第二次：去掉较长的侧面弯线，只保留浅短鼻底线；以小块暖色形状提示鼻尖转折，高光收成小亮面。鼻尖仍沿先前规定的前突深度投影，没有随意挪位置。

复看：字母状轮廓消失，鼻底与亮面更集中；在整脸尺度下仍是风格化的弱提示。当前阴影非常轻，不能称已经建立完整鼻梁与鼻翼的三维形体。

经验：二次元小鼻子首先控制符号感和明暗归属。软渐变叠在错误轮廓上，不会自动修好轮廓。
