# 面部四轮迭代：实际读图如何决定下一轮

2026-10-17。用户要求本地研究，连续画几轮，每轮实际读图，再制定改进方案与保存学习记录。本批完成结构定位和四轮局部绘制；不是四张从零设计的角色，也没有把每一轮都判断成改善。

## 环境、控制条件与研究

先只读探索，确认本机 Krita 5.3.3、Bridge 1.0.0、已有主稿未修改；新建 1920×2240 独立练习画布并保存空白 KRA。继承此前自绘图层，改变展示范围和尺度，固定近正面方向、虹膜几何、视线、脸部轮廓、中性表情、发型及左上柔光。表情专项没有被覆盖。

实际查看本地用户原参考与旧稿；原参考只作观察，不复制像素。重新阅读三篇已有来源，再补读一篇眼部来源，均为公开文字，没有声称看过视频或逐张分析网页插图：

- [Raquel Arellano：鼻子](https://www.clipstudio.net/how-to-draw/archives/160376)：以体块理解鼻部，再决定风格化省略。
- [Raquel Arellano：嘴唇](https://www.clipstudio.net/how-to-draw/archives/161618)：口部有体积，唇缝和局部转折应有区别。
- [Luisa Preissler：肖像光影](https://www.clipstudio.net/how-to-draw/archives/158015)：光源一致，区分形体转折与投影。
- [Raquel Arellano：动漫眼睛](https://www.clipstudio.net/how-to-draw/archives/162395)：眼形与整体角色协调，眼睑遮光及上暗下亮先于细纹装饰。

具体省略量、眼线厚薄和眉毛减线是本批设计决策，不是作者统一规定。

## 每轮结果与下一步的因果链

| 工序/轮次 | 实际查看 | 可见判断 | 因此制定的下一步 |
|---|---|---|---|
| 结构定位 | 同尺度基线整图、鼻唇辅助线和面部特写 | 鼻是小亮点、口缝直；下半脸长、眼周线条匀 | 先固定比例，只练鼻唇体积，避免同时改全脸 |
| R1 鼻唇体块 | 整图、面部、鼻唇局部 | 鼻有连接，但长侧边像钩，白块硬；唇框像口红 | R2 缩短鼻侧提示、软化亮面、收窄开口与唇色 |
| R2 省略返修 | 整图、面部、鼻唇局部 | 钩鼻和厚唇减轻，鼻体积又偏弱，鼻底小影略几何 | 暂留局部方案，不继续无止境减淡；转查眼周的更大问题 |
| R3 眼周与肤色 | 整图、面部特写 | 下眼缘断续、眉毛减线及去灰有收益；新上睑太厚像浓眼线 | R4 只减上睑中段与外角，保持其遮挡虹膜 |
| R4 眼睑返修 | 整图、面部、原尺寸眼部 | 眼线减轻，虹膜与反光露出更多；下眼缘较轻 | 本批局部保留，但比例、颧颊体块和鼻体积仍需下一批 |

所有轮次都是先绘制、导出、实际读图，再制定下一轮，不是预先批量画完后写评价。工具层的清理/追加中间保存不另算独立美术工序；没有把移除旧符号但尚未画新五官的临时版本当成成稿。

逐轮前置目标与后续追加见 [R1](../learning-records/face/20261017-iteration-r1.md)、[R2](../learning-records/face/20261017-iteration-r2.md)、[R3](../learning-records/face/20261017-iteration-r3.md)、[R4](../learning-records/face/20261017-iteration-r4.md)。

## 可复用经验与失败边界

1. 体块理解不要求描出全部体块边界。鼻梁长侧边和小高光一叠，可能增加钩状符号感。
2. 把唇缝、上唇、下唇各自封闭铺色，容易超出目标风格的省略量。轻微开合也要在整脸读图，不只放大看形状。
3. 上睑的遮挡顺序正确不代表厚度合适。R3 的技术实现正确但美术结果偏重，R4 必须返修。
4. 断续下眼缘、减淡规律眉毛能降低轮廓框感，却不能解决长下半脸和扁平颧颊。不能以眼睛更精致宣布面部完成。
5. 缩小、变淡、细线更多都不是立体感的充分条件；R2 的鼻体积仍弱是实际反例。

本批没有更换笔刷或使用下载资源，没有新增滤镜或生成式图片接口。路径和遮罩由程序规划，在 Krita 中分层渲染；不是数位笔自由手绘，也不代表学会了完整头像素描。
