# 本知识包的协作入口

本说明适用于本目录。先读 README.md，再读 ENVIRONMENT.md；接收方可能未安装 Krita、Python、MCP 或笔刷。先只读探索实际环境、工具、权限和参考可用性，未知项明确记录，不能套用原作者路径、端口、协议或运行状态。

绘画原则见 HANDBOOK.md，进度与协作见 COLLABORATION.md，执行限制见 TOOLING.md。阅读和评审无需安装绘画软件；安装、启动、连接或外部发送按当前用户授权及适用项目规则处理。

必须按 LEARNING-PATH.md 分部位学习：先看现状和薄弱点、针对性读教程、在动笔前建立学习记录和要素，再分工序实画、每步实际识图、返修、复看、保存经验。每轮复制 templates/lesson-record.template.md 到 learning-records/<topic>/<date>-<run-id>.md 并随过程追加，完成后更新 learning-records/README.md；无绘画环境时标为研究完成待实画。不能只写资料摘要不练习，也不能只画不保存来源、自检和失败记录。随后按已获授权的队列继续，不需逐部位等待确认。

不要批量运行或导入历史 author/review/refine/inspect 脚本；它们有历史数据依赖、顶层写文件和活动文档前提。优先阅读 examples/，确认接口兼容后才考虑独立场景复算。修改画稿按草稿、轮廓、底色、明暗、细化顺序，每步实际导出识图、返修与记录；文件或脚本通过不等于画质通过。

协作时不要同时修改同一活动文档；各任务使用独立输出目录，保留失败版。表情专题保持独立，避免未经比较覆盖主稿。教程只保留链接、摘要和实际阅读范围，不把未看视频写成已学完；不要分享桥接令牌或私有配置。
