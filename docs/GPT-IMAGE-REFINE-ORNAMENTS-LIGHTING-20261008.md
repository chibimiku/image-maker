# 配饰花纹 refine：两步与一步对照

用户要求增加独立配饰花纹修复步骤，用已完成的“三条微调组合版”再次 refine，对比先修后调光与一次修复＋调光，授权三次请求和失败重试。原图为 `refine-three-clause/combined_004234-4d0e81.jpg`，以用户认可的当前外观为比较基准，不沿用此前主观瞳色否决结论。

## Prompt 与请求

新增生产模板 `prompts/gpt-image-optimize/refine-ornaments.md`（71 英文词）：保留可识别纹样、金边路线/宽度与连接点；清除无法组成可读纹样的孤立破碎线，融回现有材质；不发明装饰、不重新设计配饰，保留真实破损、裂口与血迹，人物设计、画法和背景不变。

两步：共同输入 → 配饰模板一次 → 返回图经代理人体检查 → 既有 73 词光照模板一次。

一步：共同输入 → 组合 140 词模板一次。组合仅删除配饰模板末句 `Preserve the current lighting.`，追加原光照模板；其他条款相同。组合模板位于 `prompts/style-tests/refine-ornaments-lighting-20261008/repair-and-lighting.txt`，不启用为生产合并模式。

沿用当前重绘配置的 Flash Image / 2K，3:2，源图单附件；360 秒、每请求 repeat=1、无自动重试，无画风附件/细节后缀。用既有实验 CLI 冻结 hash、独占请求记录及预算账本。实际 3 次均成功，约 22.75/27.42/22.70 秒；没有失败或重试，没有文本请求、在途。用户授权的失败重试预留未使用。后台生成 API 自述不作为验收证据。

## 代理视觉观察

检查四张全图及等尺度颈/胸甲、腿甲金边、脸部裁剪。本样本暂时偏向两步处理：配饰修复使腿甲金边更连贯，后续光照基本保留整理结果；颈部配饰仍接近输入的金属形态。一步版颈部变成深蓝底金色卷纹，是更明显的配饰设计变化。

两步版冷月光、暖火光与金属反射更突出，但高光增强，需要用户判断是否过亮；不能宣称量化证明物理光照更正确。修复阶段本身也重新组织部分小纹样，不宣称严格设计保真通过。两条路径主要裂口、裙布破损、血迹、坐姿、两臂两手及场景物件基本保留，未见明显额外肢体，不保证细指完整。眼睛外观直接展示，无校准色度测量，不因代理主观色偏判断自动否决。

一源图、两步与一步各一组，有随机波动及生成次数差异，不能证明稳定优势或哪句话有因果效果。本轮没有付费文本审计、没有自动 pass、没有用户成品验收；未替换原图。
