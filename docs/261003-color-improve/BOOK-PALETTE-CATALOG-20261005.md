# 书籍配色方案全量目录

## 数量与收录范围

以现有 PDF 转录知识库 `data/color-knowledge/palette_library.json` 为来源，全部收录 31 个案例，每个案例 5 个色格，共 155 个色格。此数为已提取案例数，不把方法笔记、绘画过程的中间色板或 130 色基础表当成独立可执行方案，也不宣称完成了对 PDF 所有图示的新增普查。

此前试验的冷蓝+红、深绿+玫红、蓝紫+金是 3 个独立实验预设，不是书籍案例数，不能把它们的测试成绩套给书中案例。首版现在不必只保留这 3 个预设：后续方案选择可展示全部 31 个书籍案例，以及单独分组的 3 个实验预设。

## 新增交付

- `prompts/color-knowledge/book-palette-catalog-v1.json`：31 套方案的统一数据，含名称、作者、PDF/印刷页、5 色、色值来源、未测试状态、区域绑定要求和逐方案 hash。
- `prompts/color-knowledge/book-palette-catalog-v1.html`：31 套色板的离线预览，缺失色值以空白虚线色格表示，不猜颜色。
- `python tools/color_knowledge.py catalog`：离线可重复构建入口，不调用 API，不修改上游知识库。

## 数据边界

155 个色格中只有 10 格带 `measured_hex`。优先使用这些扫描实测值，但印刷扫描值不等于原稿；其余有 NCD RGB 的标为 `ncd_nominal`，无可靠数值的保留 `null` 和 `name_only`。不按相近色名补值，不把 NCD 标称值冒充扫描实测值。

书中五色色板的顺序不能自动解释为主色/辅色/点缀色。本版 `role` 全部保留 null；色相关系和面积原文保留为溯源资料，尚未编译成通用区域合同。原作品的故事与作者是元数据，不直接作为新图的内容或画风指令。

全部书籍条目的 `generation_validation` 为 `untested`。`selection_enabled` 表示允许列入未来选择列表，不表示已接 GUI 或自动生图。有效画风参考图存在时不允许使用这些配色。下一步接线需要把方案主次、既有可改色区域和保护色显式绑定；不允许为用某方案而强行新增腰带、鞋蝴蝶结或原书物件。

## 验证与下一步

三个 unittest 全通过，核对完整收录、实测/标称/缺失区别、离线导出与上游文件不变；Python 编译检查通过。无新增收费调用、没有修改 GUI 或全局配置。

下一步做全量目录选择与合同编译的最小接线，默认关闭，展示来源和未测试状态。可逐步补齐其余扫描色值、核对主次角色，不以未测完全部案例为理由阻塞目录展示，也不以目录收录为理由宣称全部方案可靠。
