# 二阶段统计与回放修复，以及下一轮交接

本轮仅离线修改和验证，没有调用收费服务，没有修改原图，没有重启正在工作的 app。

## 已修复的两个问题

`utils/color_direction_pack.py` 不再仅凭 content_status 判“可用成功”。现在分别输出方向观察、候选合规与完整对照成功。候选需内容、色板/落点、保护色、细节可读性通过，无未经授权的新增；不确定、partial、缺少必要证据均不冒充通过。完整对照还需基准通过，且没有已声明的比较混杂。此为实验结论统计，不是给生产 app 新增严格面积/饱和度门禁。

旧评审使用中文区域名，不把中英名称不匹配误判为缺失；其覆盖度保留人工核查提示。新一轮要求英文 literal region_id，漏项会阻止完整合规判定。方向观察始终保留，不能把对照不干净解释成色调完全无效。

`modules/others/api_backend.py::_generate_request_replay` 改用 `utils/request_replay.py`：认证头完整脱敏，结构化 body 的凭据字段与 URL 中认证信息也脱敏；不修改实际发送用的 headers/body。回放脚本在真正运行时从所登记环境变量读取凭据，缺少变量则发请求前停止，不打印解析后的认证头。Bearer 环境变量只填 token，不带 Bearer 前缀。URL/body 含认证信息时需要分别提供 IMAGE_MAKER_REPLAY_URL / IMAGE_MAKER_REPLAY_BODY_JSON。

此修复覆盖新进程产生的正常回放文件；没有批量清理旧日志、历史回放或更换密钥，也没有改变独立 Debug HTTP trace 功能。运行中的旧 GUI 不会自动换成新模块，仍按用户要求暂不重启。DeepSeek 必须使用新 CLI 进程。
