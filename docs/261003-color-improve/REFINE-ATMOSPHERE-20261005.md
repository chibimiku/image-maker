# 精修阶段的可选情绪与季节

2026-10-05：按用户要求增加主动选择的情绪和季节，作为二阶段的独立生成氛围选项。默认均关闭；本轮没有付费联网分析或生图，也没有本地图片叠加。

## 使用入口

图片分析 Tab 的服装选项现有行末新增「情绪/季节」按钮，不增加常驻行。点击后分别选择：

- 情绪：关闭 / 愉快活跃 / 平静放松 / 忧郁沉静 / 紧张凝重。
- 季节：关闭 / 春 / 夏 / 秋 / 冬。

两组可以单独选择，也可以同时选择；取消不改变之前的选择。下一次提交分析时固定本次选择。界面记忆在现有 `analysis_gpt_pipeline.atmosphere_selection` 节点，保存过程合并其他配置。历史重新分析采用该历史任务的冻结选择；老记录没有选择就关闭，不吸收当前界面的新选择。已生成的历史提示词和断点继续使用保存的正文，本功能不修改旧任务。

无头完整分析使用任务配置 `refine_atmosphere`，例如 `{"mood":"relaxed","season":"spring"}`，未配置与全关闭保持旧行为。本轮没有给批量提示词页、GPT 专用页增加同名入口：这些页面没有图片分析 Step 2。

## 如何进入 refine

1. 提交时冻结选项、源 PDF 页、完整条款、精简条款和 SHA256。冻结后的快照复用时校验，模板后来修改不改变已有快照。
2. 仅在 Step 2 请求末尾添加独立说明：这是用户主动选择的生成方向，不是原图观察事实；仍按照原精修规则编辑描述、标题与标签。原 Step 2 system、过滤/拒绝处理不变，不增加模型调用。
3. 服装检查、照片风格清理、标签重算完成后，保存未添加氛围条款的 `factual_english_description` / `factual_short_description`，再在优化正文中加入完整条款。原始描述、源图标签和画幅不被这些条款覆盖。
4. GPT 内容锚从未追加氛围的正文压缩，保留人物、服装与姿势的原有压缩预算；然后追加不足 180 字符的精简条款。完整锚和短锚因此可以分别超过原 1400 / 500 字符上限，新增部分是明确保存的用户条款，不截断内容锚来腾位置。完整生成请求仍经过原有组合长度提示；画风参考压制风险仍需后续实图验证。

最终分析 JSON 保存 `generation_atmosphere`；队列的 `analysis_options.generation_atmosphere` 保存提交快照。实际 refine 文本进入现有 `cache/temp/analysis-refine/` 请求证据。关闭时不添加新正文和结果字段。

## 色彩边界与来源

季节来自已整理的 PDF 第 37 页，情绪来自第 53 页。选项是工程化的定性转译，刻意省略“某情绪必须用红黑”“冬季必须无彩色”等会覆盖固定色板的条件，不能称为书本原文规则或已验证生图能力。

情绪只表达画面色彩感受，不推断人物心理、不改表情。季节只表达色调感受，不添加雪、落叶、花朵、季节服装，也不改变天气、时间和光照方向。只允许温和调整明度、彩度、对比；固定色板、颜色落点、用户显式色调、主次关系优先。情绪和季节冲突时保留温和的共同效果，避免强行同时实现两个极端。没有严格面积数值或精确上色要求。

这是二阶段的一个已实现组件。独立色调选项、主色/辅助色/强调色及宽松视觉份量选择仍按主路线继续推进；三阶段仍是有条件的材质、光照、色彩知觉与画法共存。情绪和季节不能成为自动替换色板的入口，蒙版精确编辑不进入主线。
