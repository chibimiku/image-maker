# 固定配色的单画幅与人数约束验证

## 范围与规则

本轮只加强内容保持约束，目标仍是固定配色，不是画质改善。不改生产 GUI、全局配置、画风固件或身份/质量门禁。旧 v1 提示词、协议、请求和结果保持原样。

新提示词：`prompts/color-knowledge/book-single-scene-guard-v1.md`。核心规则：每个预定人物只出现一次；单一连续场景；禁止重复场景、分栏、前后对比、插图窗、拼贴，以及文字色卡/图例。配色编号只用于执行，不进入画面。

这些是针对模型输出的工程保护约束，不是书籍提取出的色彩理论，也不计入新增书籍知识条数。

有明确内容参考图时，保持其实际人数、身份、相对位置、互动、姿势、物体与取景。画风图、书籍示例、色卡和同一人的细节裁剪不决定人数。没有内容参考图时，以内容描述的人数及场景为准。内容源与明确指令冲突时停止澄清，不暗自加减人。此规则不限制双人原图变成单人：原图有两人就保留两人。

编译器仅在显式选择 `composition_guard: "single-scene-v1"` 时追加新护栏；未选择时原编译行为不变。固定配色仍禁止有效画风参考图，当前实验没有任何图片参考，因此本轮不验证真实参考图的人数保持。

## 新版实验

协议：`prompts/color-knowledge/book-palette-ablation-v2.json`，继承旧 v1 结构并冻结继承文件 hash。冻结 hash：`467b653f2acb6abde4fd75c02efe3aa5d30dfd23413a172ee8c896f4b3b3496c`。

原两套色板 C13/C16，每套 simple/knowledge 两轮，B0 两轮，共 10 个固定排程样本。颜色绑定、区域、绘画描述、模型、参数、顺序不变；所有组（含 B0）都增加同一单画幅护栏。Flash / 1K / 3:2，无图片参考。关闭底层自动重试，不用内容失败图重抽挑图。

输出：`data/test-result/20261005/book-palette-ablation-v2/`，保存冻结请求、原始响应、所有失败、实际产图、逐张/汇总 JSON、调用账本和内嵌评价页。评审附加协议把人数/布局问题放在内容项，不当作固有保护色改变；近景未授权植物保持固有色不构成配色失败。

## 结果

10 次生成全部成功，底层自动重试为 0；5 次文本评审完成，未追加请求。Codex 直接查看全部 10 张实际产图，原始评审保留，4 条岸地区域漏项在 `adjudications.json` 绑定产图 hash 单独更正。

人数与画幅：7/10 同时满足单人、连续画幅、无色卡；B0-r2 在连续场景中出现两人，C13-simple-r2 为双栏重复人物，C16-simple-r2 附带右侧色卡。配色组为 6/8 满足这三个内容条件。这些结果证明加强文字仍不能保证结构保持，不宣称解决。

8 张配色图最终 3 conform / 5 partial，严格可用 1/8；不是只有一张产生了目标色。主色与腰带/双鞋结普遍执行，但“全部 riverbank ground”这一宽泛绑定包括对岸，不能只核近岸。C13-knowledge-r1 远景植被偏绿由模型判 partial；其 r2 中景大片岸地偏粉紫；C16 三张单人图的对岸平坦岸带仍为蓝灰。对 simple/knowledge 使用同一岸地判据，未因画面整体蓝黄红正确就忽略区域漏色。

远景植被/岸地边界未做蒙版分割，局部边界仍有语义不确定；上述 partial 是逐图定性判断，不是面积百分比。近景未授权植物保持绿色不扣分。无真值参考图，不把蕾丝/裙摆变化自行判为身份变化，也不把人数错误塞入保护色失败。

旧 v1 最终人数/画幅/色卡失败 3/10，新 v2 仍 3/10；新增的长文字约束没有在这批重复测试中显示明确改善，且不是配对因果试验。不晋级、不自动接生产。

交付含 `RUN-REPORT.md`、`book-per-image.json`、`book-summary.json`、`call-ledger.json`、冻结协议、请求与原始响应及内嵌 10 张产图的 `evaluation.html`。37 条书籍相关 unittest 通过，改动 Python 编译通过；扩大到全部 `test_color_*.py` 的检查未完整运行，因为当前工具执行环境无法导入 pytest，不能据此称用户环境缺少 pytest。

## 下一步研究

不继续堆更长的否定词。下一轮优先验证指定内容参考图能否锚定人数/构图，并明确近岸/对岸、近景/远景植被的区域合同。挑选参考不能按美感：取本批排程最早且符合单人连续场景的实际首图，原图 hash 固定；双人保持另用已确认两人的内容源，不把错误生成的双人图冒充授权内容源。先做配色绑定保持和原图人数保持的独立小实验，再讨论生产接线。固定配色仍只限无有效画风参考图。

## 解释边界

这是新版提示词的完整重复测试，不是同 seed 配对实验。历史 v1 含选择性失败重试，不能据 v1/v2 比例声称因果或统计显著。统一色调、真实内容参考图、多人物参考保持、重绘继承和生产接线不在本轮内。
