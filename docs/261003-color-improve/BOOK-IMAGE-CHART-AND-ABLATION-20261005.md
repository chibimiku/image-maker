# 意象图提取与首轮生图对照

日期：2026-10-05。目标是固定配色与落点执行，不是画质改善。本轮完成离线测色与实际生图/评审，未改生产 GUI、画风固件、全局配置或质量/身份门禁。

## 提取结果

PDF 74 与 147 是同一张暖—冷、柔—刚三色意象坐标图。74 页叠加作品定位圈和连接线；采用较清晰且无遮挡的 147 页图实测，计数一次。两页文字用途仍分别保留；147 页第三标准「清晰—模糊」不伪造为图上的第三坐标。

逐组人工定位并核对 **50 组三色板 / 150 色格**。两个「悠闲的」、两个「理性的」具有不同位置和颜色，不能按词名合并。意象词只作检索标签，不注入人物情绪、题材或画风。

色值使用每格内缩 25% 区域的 RGB 中位数，记录样本坐标、像素数、P10/P90 差、来源图片 SHA256 与 ROI 清单 hash。近白色正常测量，不通过“彩色像素筛选”把白色剔掉。无色名的原色格命名为 C1/C2/C3，不编造 NCD 编号、标准色名或主次；角色由生图选择另行明确分配。色值是未校准印刷扫描值，不是原稿精确颜色。

交付：

旧 v1 及既有实验不覆盖。目录里的 untested 是冻结时状态；本轮两条色板的验证结果在独立实验目录，不回写冻结知识包，也不将其推荐为默认。

## 冻结与执行

协议：`prompts/color-knowledge/book-palette-ablation-v1.json`。既定选择第 13 组「女性化的」与第 16 组「快乐的」，不按生成美感挑选。为两组三色分别显式指定环境基调、岸地辅助、腰带及左右鞋蝴蝶结点缀；这套区域角色是实验设计，不是书中的角色声明。

每组 simple / knowledge 各两轮，加 B0 两轮，总计 10 个计划样本。simple 保留颜色、角色与区域；knowledge 只增加大/中/小面积关系及明度分离。所有配色组共用保护块。未给三种混合色调强塞一个 NCD tone，因此**本轮只验证面积/分离规则，不验证 12 类统一色调选择器**。

模型显式传递 `gemini-3.1-flash-image-preview`，1K / 3:2，无图片参考；成功响应的 modelVersion 与之相符。`IMAGE_MAKER_IMAGE_MAX_RETRIES=0`，底层自动重试始终关闭。首轮未重试；随后用户授权对三个失败样本各原样重试一次，见下节。未补抽、未修改协议、未追加修图。无模型生成 seed；排程 seed 仅控制顺序。

## 离线复核与更正

Codex 直接查看了全部 7 张完整产图，在 `adjudications.json` 单独保留基于图片字节 hash 的两条复核，原始评审 JSON/文本不改：

1. C16-knowledge-r2：模型正确发现双栏双人，但漏掉左栏中景绿色岸地，将其配色和区域从 conform 修为 partial。
2. B0-r2：模型把多层裙摆当作“设计变更”，又将其错放在保护色失败里。该首图没有精确服装真值图，文字允许蕾丝与丰裙，不能如此断言。保护色修为 true；内容仍为 false，但依据改为画中新增的远处房屋与冻结文本不新增物体约束冲突。

结构化逐张结果同时保留 `model_review`、最终 `review` 和 `adjudication`，不隐藏分歧。近景未授权植物保留绿色不自动算漏色；中景岸地已授权黄色与它不是同一区域。区域语义仍有边界歧义，不能声称已完成分割蒙版级验证。

## 能与不能得出的结论

已证明：新提取三色板可以通过现有 Gemini 通道编译为实际首图，颜色和三个点缀落点可以得到执行。109 条记录不是空目录，已有两条新增方案的实际消费与可追溯产图。

不能证明：知识版比简洁版更好。C13 只有 r2 有双方可评图；C16 简洁版完全缺图，且每组只有两轮非同 seed 的随机样本。不能将知识版生成数较多当成颜色规则的因果收益。本轮不晋级任何方案。

没有进行重绘、统一色调试验、区域分割面积实测、身份真值图对照或生产入口接线。不能把“符合文字中的固有颜色”称作完整身份保持验证。光效、材质、知觉规则仍为检索资料，尚未全部编译为生成约束。
