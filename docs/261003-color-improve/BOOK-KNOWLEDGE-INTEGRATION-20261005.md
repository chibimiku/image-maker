## 可编译能力与保护

`utils/color_extract.py::compile_generation_palette` 新增 `scoped_rules`、`region_facts`、`region_tones`、`audit_rules`。条件规则最多选 4 条；只作用于已经授权且绑定的区域。缺条件、重复/未知规则、未授权区域、保护区域、全局/局部 tone 冲突均报错。审计与检索标签不进入生图正文。

白瓷和不锈钢另检查已绑定色族是否兼容，避免蓝色契约与“白瓷保持白”冲突。RGB 通道跨度和浅中性色保护阈值是透明列出的保守工程判据，不是书籍/NCD 标准或校准色度指标；无可靠 HEX 时只接受明确白/银/灰色名。调用者的 `region_facts` 是显式事实声明，当前并无自动材质识别，不能把通过条件验证称为已识别真实图像材质。

例子：`prompts/color-knowledge/book-generation-example-v3.json`。已通过 CLI 编译到 `data/test-result/20261005/book-generation-knowledge-v3/example.compiled.json/.prompt.txt`：蓝色环境局部 L 调、已选色族控制、局部明度变化、单场景保护，以及不入正文的三项审计快照。这个例子没有玻璃/白瓷，所以不会加材质规则。

材质规则已可离线编译，但尚未进行实际生成实验。现有 GUI 与画风、质量、身份固件不修改，不需要为这些隔离研究变更重启生产 app。
