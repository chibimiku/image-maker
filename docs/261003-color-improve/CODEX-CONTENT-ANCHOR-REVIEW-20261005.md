## 对执行报告的解释修正

1. C13 两张参考图的平均绝对 RGB 差为 **2.3575/255**，最大单通道差为 61；C16 为 **14.4500/255**，最大为 129。这是解码像素的描述性差异，不是色度指标，也不能证明请求不独立、服务端缓存或随机性降到零。可以说两张 C13 的可见变化很小、内容覆盖有限。
2. 内容分支附图之外，还新增了 `book-content-anchor-v1.md` 的角色说明。因此比较的是“图像附件 + 内容源说明”的整体干预，不是纯粹只增加一张图片。两轮小样本、无配对 seed，不能把分栏差异称为唯一可归因于参考图的收益。
3. C13-text 的超时意味着自动评审缺失，并不意味着内容不符合。报告中 true=0 是没有记录到 true，不能解读为观察到两次 false。
4. C16 参考分支对白裙的保持并无明显失败证据；主要保护问题是对岸和近景植被。灰度可辨性只说明轮廓有一定明度区分，不能证明人体拓扑、配色落点或固定色相正确。
5. “配色符合”只是在近似扫描色族和区域合同下的观察。没有蒙版或校准色度/面积测量，不能给出精确面积百分比。

## 接下来如何用书籍知识

当前优先顺序应是 **授权合同自洽 → 区域落点与保护 → 条件知识消融 → 画风/重绘兼容 → 生产接线**。

新增的 7 条条件生成规则、局部 NCD 色调、3 类只读审计与 8 组检索标签仍保留；这批没有使用它们，不能把成功归到它们头上。区域控制通过后，先对已授权环境区域做“无局部色调 / 一项局部色调”的小实验；玻璃、白瓷、金属另用确实存在相应材质的内容源。季节/情绪/意象继续做检索，不改变人物或天气。灰度继续只读。
