# 二阶段首版：独立色调与宽松主次

2026-10-05，按用户“可以推进第二阶段”的要求接入现有文字首图流程。阶段目标是定性提示词控制，而不是精确上色。本轮完成代码、离线验证和下一轮实图验收设计；没有调用付费接口，没有操作图片，没有重启正在执行任务的 app。

## 已接入的入口

批量提示词/生图与 GPT 专用 Tab 的现有「配色」选择旁，原「落点」按钮改为「规则」。常驻行数和按钮占用宽度不变，参数在弹窗内：

| 参数 | 可选项 | 生效边界 |
|---|---|---|
| 独立色调 | 未指定、明亮、深沉、清色、浊色 | 配色关闭时仍可单独使用；保留原正文所有色相，只温和调整明度或彩度 |
| 宽松主次 | 沿用方案、主色主导/少量强调、双色并重、主色/辅助/强调 | 开启配色并明确已有区域；没有固定比例，没有面积硬门禁 |
| 辅助色落点 | 正文已有区域短语 | 只在三层模式启用，与另两组区域分开 |

配色和色调都关闭时沿用旧流程。旧任务未选择新规则时，第一阶段生成条款保持原文；“沿用方案”明确保留第一阶段已有的大环境主色与小点缀声明，并不是声称书中已指定了每个方案的角色。

选择双色并重时用新的中性绑定模板替换旧“大主色/小强调色”条款，避免互相抵触。它要求的是宽松的视觉份量：现有物体大小不能满足时以构图为准，不扩大蝴蝶结、衣服或背景物体来凑覆盖率。

三层模式的辅助色由试用方案明确指定：冷蓝/红的 muted blue-grey、深绿/玫红的 subdued green、蓝紫/金的 subdued violet-grey。来源是第一阶段设计方案已有的颜色名称，并非从书中五色的排列顺序推断主次，也不是书中实测角色。区域须由用户明确填写；未填、与主色/第二色重复或正文中找不到均在发请求前拦截。它没有将辅助色反向写成某个书本方案的历史事实。

## 来源与规则

色调取自已有 12 类简化 NCD 目录，新增四个 UI 入口是宽泛偏好，不是一一对应的精确分类：

| UI 偏好 | 原目录参考代码 | 注意 |
|---|---|---|
| 明亮 | B / P / Vp | 不是加太阳、改成白天或全图漂白 |
| 深沉 | Dp / Dk / Dgr | 不是夜晚、阴天或压黑所有细节 |
| 清色 | V / B / P / Vp | 不是换色板或全图饱和度滤镜 |
| 浊色 | Lgr / Gr / L / Dl | 不是统一灰色、薄雾或抹掉色相区别 |

映射保留 `mapping_note` 与原目录对应条目；不会把候选代码集合说成严格或穷尽映射。来源页 14–16 / 110 / 129 的色调内容作为工程转译依据，不引入 HSV 阈值。局部允许不同层次，不强制主色和强调色采用完全一致的明暗/彩度。

主次依据页 18 / 146，双色并重依据页 79。室内页 77 的百分比、页 59 的个案比例没有编译到通用插画规则。

明确色板与颜色落点保持；显式色调优先于情绪、季节的色彩建议。人物身份、表情、服装设计、构图、天气、时间、光照方向和画法不由这些规则改写。关闭色板、只选色调时保留画风文本中的 `Palette:` 字段；不会因为要调明暗就撤销已有颜色约束。

## 冻结与当前覆盖

选项保存在两个入口各自现有 `theme_color_ui` 节点；读旧配置、只合并本节点，取消弹窗不改选择。新请求快照为 schema 2，保存完整条款、tone/area、来源 NCD 条目、辅助色来源和 plan hash；没有新选项时仍生成 schema 1。实际提交 prompt 与图片 hash 继续进入 `cache/temp/theme-color/` 和同名 `.color-plan.json`。改变模板不会修改已落盘请求快照；快照校验失败则停止使用。记录 `generated` 只表示产图，不表示配色验收成功。

本版继续限定无图文字首图。即便只选色调，内容图、画风图、编辑、重绘和 GPT 后处理也沿用首图试用范围的拦截，不暗中开放未经验证的后续工序。没有新增本地图片计算、滤镜、蒙版、羽化叠加或拼回。

图片分析 Tab 的情绪/季节是上一轮独立功能，本轮没有将这里的三层区域改色绑定接进源图分析、身份审计或重绘。不能宣称所有 Tab 与历史断点已覆盖二阶段改色。直接生成请求的保存路径可以保留完整证据；从当前控件发起新任务仍是新的选择，不冒充原任务的逐阶段重跑。

## 下一轮实图验收

先冻结一组模型/尺寸/画质/画风文字，不带参考图；用同一冷蓝/红试用色板，不同时变衣装、情绪、季节或其他工序。建议两种已具有充分颜色落点的主体，每种比较五个变体，共 10 张：

| 变体 | 唯一改动 | 主要验收 |
|---|---|---|
| A | 沿用第一阶段条款 | 基准内容与色板是否可用 |
| B | A + 明亮 | 方向是否更明亮，身份/颜色落点是否保留 |
| C | A + 深沉 | 方向是否更深沉，是否仍有可读细节 |
| D | A + 双色并重 | 强调色是否更有视觉份量，是否新增/扩大物件 |
| E | A + 三层主次及明确辅助落点 | 辅助层是否可辨，是否污染未授权区域 |

只看相对方向与内容保持，不按严格 RGB 或像素面积打分。保留不确定与失败，不用总分掩盖人数、身份、对象新增或颜色串染。清色/浊色作为下一组单变量对照，不一次扩成全组合。先确认真实请求、产物与评审落盘，再决定是否增加柔和/更丰富的 NCD 入口。当前表格是可执行前的实验设计，不是已运行结果或本轮的付费请求包。
