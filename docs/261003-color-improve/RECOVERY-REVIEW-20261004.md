用户在本轮明确修正目标：增加配色方案是为了让画面拥有指定的一套色彩，例如冷蓝基调搭配红色强调，不是改善画质。因此旧实验的“美学收益不稳定”不再是阻止接入的理由；本记录后续路线按方案执行与稳定性重排。

## 3. 现有证据支持什么

**方案能改变颜色组织；是否优于基线不是当前验收目标。** 主试验每组三张，是独立随机生成，构图、人物占比、服装细节与背景也在变化，不能把所有视觉差别都归因于颜色。没有蒙版的全图亮度/HSV 统计只能描述颜色分布。现有图可以继续按各自实际方案重评符合度，不必重生图片；旧结果不改写。

**明确的冷暖指令在本主题的 Gemini 上有强效果。** 冷暖试验的原图接触表、现有色相统计和匿名读数方向一致。但它测的是指令执行，不是书中知识相对普通冷暖短句的增益，也不是美学提升。T1/T2/T3 各有一张双人或重复人物；T2 还出现主体色变化，T3 的金黄色环境带来明显黄昏感。

**评价模型适合做观察助手，目前不足以独自选“最优配色”。** E0 能识别双人和同图平局，但交换校准用的是含明显内容失败的图对，没有验证细微配色偏好。主试验 G6/G1 的镜像比较翻转，说明该对结论不稳定；随机性与位置/标签影响在这几次调用中没有被分离，不能据此确定唯一原因。G7 的偏好没有严格镜像复核，应保留为线索。

**内容合格是模型的已有判定，不能当作全面认证。** 主报告曾漏判 G5-r2 的针织外套，后续才识别；接触表也不足以确认所有手部、厚底结构和蝴蝶结细节。继续评价时要将单人、固有色、服装设计、鞋型/厚底/蝴蝶结、动作与画法分别列项，允许 uncertain。

本轮目视检查两张接触表，并打开 T4-r1、T4-r3 原图：粉发、浅象牙裙、粉色厚底鞋与蝴蝶结可见；冷青环境明确，同时背景更接近平涂、大块阴影与硬边。它说明“配色执行好”可以伴随画法变化，不能把旧报告的 T4 3/3 内容 pass 扩大为画风完全保留。

## 4. 保留的候选与用途

| 候选 | 适合继续检验的用途 | 尚未解决的问题 |
|---|---|---|
| G1 仅内容保护 | 不改配色的共同对照 | 不是已证明最佳的美学方案 |
| G7 暖柔春景 | 保留河蓝、自然绿和日光，粉发作强调 | 优于 G1 的偏好未镜像复核 |
| G3 春绿层次 | 更沉稳的绿色背景与人物分离 | 整体更暗；不能自动等同于更好 |
| T4 冷青环境 | 明确换环境色，同时保护人物固有色 | 画法更平、更硬；仅三张 |

这些候选承担不同意图，不应排成一个通用质量榜。G4 柔蓝关系方案与 T4 强冷青指令也不是同一个效果目标，不能仅凭冷色占比判定谁更优秀。

## 5. 修正后的验收与继续顺序（设计，未执行）

主判据为：指定颜色是否到位、主辅分工与区域是否正确、冷暖基调是否正确、是否混入大块非目标色、重复生成是否稳定、后续工序是否保留。每项记录符合/部分符合/不符合/无法判断与实际区域证据；内容和画法保持单列。评价模型需要看到方案才能判符合度，美学盲评不再是必经步骤。

“冷蓝 + 红”的示例契约：蓝色承担环境基调，红色作为指定区域的局部强调；肤色和经允许的中性色可保留，光影允许合理变化。红色存在不意味着冷基调失败；必须分别观察蓝色基调与红色强调。具体比例、颜色容差与换色范围尚未由用户指定，不把例子中的分工当作固定产品默认，也不硬造精确 HEX 门槛。

1. **先重评已有图的方案符合度。** 逐条对照 G2～G7、T1～T4 的实际条款，记录目标/实际/区域/偏差及重复稳定性。G7 不必先证明比 G1 好看；T4 能执行冷青环境，但不能声称已验证“蓝+红”双配色。
2. **下一轮直接测试固定颜色组合。** 预先固定少量方案，如冷蓝+红，明确主辅分工、可换色区域、受保护颜色与从属色。各方案重复生成；无方案对照只帮助辨认控制效果，不作为美学竞赛。新协议单独目录。
3. **必要时对比短句与知识编译方案。** 两者使用同一颜色组合与授权，检验知识中的基调/强调/面积关系能否提高执行准确性和稳定性；不以更好看作为知识有效的条件。
4. **检验画风兼容和全链保留。** 协调 Palette/Lighting，逐阶段查看首图、重绘、身份修订和最终图的目标色保留。tone、加墨与画风专用后处理分别检查。直接生成与同图编辑分开报告。
5. **实施配色选项与自动选择。** 每个选项对应明确颜色组合、分工与修改范围；手动方案优先，LLM 不擅自替换颜色。冻结方案快照，向后续工序与审计传递；配色结果不覆盖人体/身份/质量失败。

GPT 补跑是独立事项，不阻塞现有 Gemini 复核。恢复服务后沿用旧协议补跑时保留失败 attempt；更换模型或请求参数则另开实验。模型列表可见不等于生图服务可用。
