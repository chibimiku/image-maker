结论（已修正上一轮的说法）：把「加锁前」的原提示词原样重跑 3 次，0/3 复现； 加锁后累计 8 次也全部正常。所以这是**低概率采样事故**（当前样本下发生率 < ~15%）， 不是「范围句一定导致」。
机制仍然是：画风参考图是一张**完整角色插画**，而 person_noface 明确允许改头发/衣服/身体 —— 模型偶尔会选择参考图当设计来源，于是整套角色（粉发 + 水手服 + 金鱼/水波）被搬进来。 要根治就不能给「允许改设计」的档位递一张角色插画：① 这类档位干脆不挂参考图（风格靠条款 + 色调校准）； ② 或把参考图做成**无角色的风格板**再挂；③ 或只用渲染类档位（lines_only / details）。
