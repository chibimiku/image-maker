# Gemini 重绘参数追溯：023401 / 024958 / 030736

日期：2026-09-25

## 结论

这三张被认可的成图并不是只靠“2K”得到的。共同的有效链路是：

1. gpt-image-2 首图为 1024×1536 / high；
2. Gemini `gemini-3-pro-image-preview` 对整图做一次 v5 保守重绘，输出 1696×2528；
3. 整图重绘时输入两张图：GPT 首图 + 原始画风参考图；
4. 使用 `aspectRatio=2:3`、`imageSize=2K`，关闭 detail suffix；
5. 再做本地 `sline50`；
6. 最后对人物、鞋、束腰、袜带等裁切区域分别做 2K Gemini 重绘并羽化贴回。

线条完整度的主要提升来自第 2 步整图重绘。`sline50` 只做小幅巩固；局部重绘改善的是指定结构的可读性，并没有显著提高全图线稿指标。

## 为什么第一次整图重绘有效

### 1. v5 固件明确要求主轮廓连续

固件并不是普通的“提高清晰度”。它要求把头发外轮廓、主要发束、下颌、颈肩、服装轮廓和遮挡边界组织成少量连续中细线，并合并散乱微笔触。这与三张图的指标变化一致。

### 2. 2K 给了模型重新组织线条的像素预算

首图为 1024×1536，重绘输出为 1696×2528。它不是普通插值放大，而是一次生成式重画；轮廓、脸、发束、蕾丝和腿部都会重新采样。

### 3. 旧链路在整图重绘时再次发送了画风参考图

冻结基底的历史矩阵显示，这个输入有时能显著提高线条组织。例如 N 基底使用 source-only v5 时段长为 86.1，加入画风图后为 101.6，端点从 27.62 降到 21.31。但在 A0 基底上，source-only 为 108.2，加入画风图反而变成 101.9。它不是普遍成立的参数。

更关键的是，原始画风参考图含角色。再次发送它会提高 Gemini 借用参考角色脸、头发、衣服和身体结构的概率。这正是后来出现“重绘后变成参考图角色”的根源之一。因此当前 GUI 改为 source-only 是身份安全取舍，不能同时宣称可原样复现这三个旧样本。

### 4. 首图质量决定重绘上限

023401、024958 的 GPT 首图已经具有深蓝色调、清楚的服装大轮廓和较完整的人体结构；030736 首图也已有完整姿态和良好轮廓。Gemini 是在较好的结构上整理线条。对当前那张复杂室内照片生成的首图，source-only v5 没有得到同样幅度的提升，不能只靠把分辨率设为 2K 解决。

## 局部重绘带来的收益和风险

局部 prompt 会强制模型把结构变成可数系统，例如鞋带必须连续交叉、束腰绳必须穿过等距孔眼、袜带必须连接扣件。这能让局部“看起来完整”，但本质上是重建，不是忠实修线。

`030736` 的终图明确新增了首图和整图重绘中并不存在的绿色袜带与扣件；`023401` 的局部贴回改变约 9.75% 像素，且全局线稿指标略退。历史矩阵还记录过 `subject_no_face` 三次中一次产生双人鬼影。四区链也可能逐次提亮、降低饱和度，或被安全策略中途拦截。

因此局部链适合作为手动“结构重建”工具，不适合当默认的无损线条优化。

## 可复现的旧强力配方

若目标是尽量接近这三张旧图的线条处理方式，参数为：

```text
模型：gemini-3-pro-image-preview
固件：repaint-system-conservative-v5.md
输入 1：GPT 首图
输入 2：该画风的原始参考图
分辨率：2K
比例：跟随源图；这三张实际为 2:3
detail suffix：关闭
重绘范围：整图
之后：sline50 = strength 0.5 / min_len 120 / darken 0.18 / 1px
可选局部：subject_no_face → shoes → waist → thigh，2K，feather 48
tone / ink：这三张均关闭
```

这套配方有参考角色迁移和局部重构风险，不应恢复成默认值。

## 建议的下一轮受控实验

要同时争取线条完整和角色安全，应冻结同一张 GPT 首图，每组至少重复三次：

1. source-only + v5 + 2K；
2. source-only + v4 + 2K；
3. source + 原始画风人物图 + v5 + 2K，作为旧配方上限；
4. source + 去角色的风格板/纹理裁片 + v5 + 2K。

先只比较整图重绘，确认身份、段长、端点、色彩和采样方差；不要混入 sline50 与局部链。若第 4 组接近第 3 组且不迁移角色，再把它做成“强力提线”高级预设。局部结构重建应单独开关，并明确提示它可能新增或改写服装结构。
