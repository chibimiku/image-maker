ChatGPT, and the same undocumented effect on Responses, uses your prior chat and “vision” of prior images when making a new response.
When the image tool is triggered, a 
gpt-4o
 version with image creation takes over and looks at the chat. That includes billed images again also, of whatever length OpenAI decides to include, and will affect the generation which is then in “edit” mode, looking to improve what it sees.
Don’t use Responses and a chat to make images with their tool.
Use the API edits endpoint, and control the inputs of individual images and prompt language.

If using the playground, and you previously attached or generated images in earlier turns of “chat”, those indeed are all seen again by the underlying tool model in a new image creation prompt triggering another generation.
API calls are otherwise unconnected. If you whack the “new chat” reset button to clear the messages, it is just going to be the monotonic style of the model itself.
DALL-E 3 used by the “generate” image endpoint (can’t see images) will make extremely varied fulfilling generations for a prompt, with less instruction-following, while gpt-image-1 is more consistent but unimaginative.
