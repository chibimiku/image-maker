# 完整画风图重绘的内容锚修复（2026-09-26）

完整画风参考能提高局部线条和渲染贴合度，但在 Kishida Mel 与 Sakurapion 的五轮测试中都出现严重内容泄露。继续增加禁止复制文字没有稳定解决。

实测最有效的补救是第三次 Gemini 修订：输入 1 为有画风但内容错误的重绘图，只提供画法与完成度；输入 2 为同轮 Gemini 直接生成图，作为人物、发色、瞳色、服装、姿势、构图和背景的唯一真值。两组均比 source-only 文字回修更好地兼顾内容和画风。

建议把它作为泄露检测后的条件式恢复工序，而不是每张默认执行。没有生成图内容锚时，才退回 source-only 修订。指标不能替代目视或语义审计：线条更连续并不代表角色正确。
