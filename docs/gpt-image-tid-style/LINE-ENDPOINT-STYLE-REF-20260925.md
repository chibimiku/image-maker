## 可执行结论

当前默认仍应是 GPT 首图挂画风图、Gemini 重绘 `source-only`。身份审计发现发色、瞳色、裙型等差异时，只允许再做一次 Gemini 定点修订；修订后即使仍有轻微差异，也保留修订图并标记复核，不再回退 GPT 首图。GUI 和无头实验链均采用这条规则。

若用户把“线条完整度”置于身份稳定性之上，可显式启用 Gemini 的完整画风参考图，再接身份审计和一次定点修订。本轮固定历史 GPT 源图时，这组把平均段长从 source-only 的 74.5 提到 92.2，端点密度从 34.35 降到 33.07；定点修订后仍保留段长 89.1、端点 32.35。但复审仍有轻微身份差异，所以它不能成为默认。

## 线条优先固件与本地运算

新增实验固件 `repaint-lines-priority-v6.md`，把外发轮廓、发块、颌线、肩颈、袖/裙/腿鞋边界列为强制检查项。source-only 两次结果的段长为 75.0、74.7，未超过 v5 的 74.5，也没有接近完整风格图组的 92.2。仅靠加重文字要求没有带来大幅提升，因此 v6 暂不替换默认 v5。

在同一张 v5 source-only 重绘上测试本地工序：

| 本地工序 | 平均段长 | 端点密度 | 判断 |
|---|---:|---:|---|
| 无 | 74.5 | 34.35 | 基线 |
| 结构线 0.28 | 73.8 | 34.06 | 外轮廓稍清楚，整体段长无提升 |
| 结构线 0.35 | 72.8 | 34.29 | 继续加深，没有连通收益 |
| 结构线 0.50 | 73.6 | 34.81 | 线更硬，端点变差 |
| 0.35 + ink10 | 70.3 | 34.81 | 过度压暗并增加碎线 |
| contrast0.55 + 0.35 + ink10 | 67.7 | 35.22 | 本轮最差 |

历史文档中“结构线叠加提高段长”的结论不是普遍规律；它依赖源图边缘。当前算法会把已有长边重新叠回，能增加轮廓可见度，却不会真正补出缺失路径。在本样本上叠加强度不应超过 0.28，加墨和白区对比应保持关闭。真正的大幅连线仍来自 Gemini 在完整风格参考下重组线稿，代价是身份泄露风险。
