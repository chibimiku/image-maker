# 2. 工作流过淡：原因和可替换措辞

## 原因判断

更可能是两个因素叠加：

### 因素一：当前“不许提饱和度”过于单向

如果固件只强调：

- 不改变颜色；
- 不增强颜色；
- 不增加饱和度；
- 保守处理；

模型可能把源图中原本很微妙的粉色、棕色、蓝色层次也当成“需要避免增强的风险”，最后变成：

> 保守 = 更白、更灰、更低对比。

### 因素二：模型对高调素材有“奶油化”先验

工作流源图本身就是高明度、低对比、白色服装和浅色背景。模型很容易把：

- 白纱；
- 高光；
- 皮肤；
- 浅棕头发；

统一压成浅灰粉或乳白色。

所以不能只写“不要增强饱和度”，必须明确：

> 保持源图的低饱和，但不能在此基础上继续去饱和。

---

## 可直接替换文本

把原来类似“不要提升饱和度 / 不改变饱和度”的表述，替换成下面这一段：

```text
色彩以源图为基准进行匹配：保留源图已有的色相、明度、对比度、饱和度以及局部色彩分离。源图本身偏淡、低饱和或高调时，保留这种高调和低饱和风格，但不得在重绘过程中进一步去饱和、漂白、降低对比度或覆盖成灰白雾状。

不得把肤色、发色、眼睛、服装和背景统一处理成乳白色或灰粉色。恢复源图中实际可见的肤色、发色、眼睛颜色和局部冷暖层次，使它们至少达到源图中的可辨识程度。

这是色彩匹配，不是整体增艳：源图没有的鲜艳颜色、滤镜、强烈暖色偏移、强烈冷色偏移和额外高光不得添加；源图原本存在的颜色不得被删除或稀释。
```

再加一句，专门防止高光扩散：

```text
保留源图的高光位置和范围，不要让高光扩散到整张脸、头发、衣服或背景；白色区域保持白色，但不要将邻近的粉色、棕色、蓝色和肤色漂白。
```

这段的核心不是“提升饱和度”，而是：

- 源图高饱和：不额外增强；
- 源图低饱和：不继续降低；
- 源图已有局部颜色：必须保留。

# 3. 清线变弱怎么补

## 先不要追求回到 cel 的 266 段长

旧 cel 固件的长线占比高，并不代表它完全正确。它可能是通过：

- 黑色外轮廓；
- 大面积硬边；
- 过度简化；
- 赛璐璐式色块分割；

强行制造出长线。

建议目标不是回到旧 cel 的指标，而是让当前结果在不 cel 化的前提下恢复一部分连续性。可把操作目标设为：

- 平均段长：提高约 **10%–25%**；
- 端点密度：降低约 **10%–20%**；
- 长线占比：提高约 **0.02–0.05**；
- 头部 MAE、配色相似度不明显恶化。

这些是验证目标，不是已经验证过的固定阈值。

---

## 推荐的线条提示词

把下面这段加到当前中性固件中，放在“保留绘画风格”之后、“负面约束”之前：

```text
在保持源图人物、构图、五官、材质和色彩关系不变的前提下，保留并重建源图已有的主要连续边缘结构。

头发外轮廓、主要发束、刘海分组、上下眼睑、鼻唇、下颌、肩颈、衣物轮廓以及前景遮挡边缘，使用少量连续的中细笔触表达。同一条主要边界尽量保持为一条连贯的曲线或一段连续笔触，不要被密集短笔触、颗粒、噪点和重复勾线打断。

发束内部保留少量有方向性的长笔触，不要把每一根头发拆成许多碎线。线条应有自然的轻重变化，线色随局部颜色变化，并与色块和软边融合。保留绘画性、透明叠色和柔和边缘，但提高主要轮廓的连贯性。
```

配套负面约束：

```text
避免均匀黑色外轮廓、硬黑描边、赛璐璐分层、平涂、漫画墨线、矢量线稿、过度锐化、过度清晰的卡通边缘、每根头发都勾线、密集短划线、断续毛刺、重复描边和高频噪点边缘。
```

关键措辞是：

- “主要连续边缘结构”
- “一条连贯的曲线”
- “少量长笔触”
- “不要被短笔触打断”
- “线色随局部颜色变化”

不要使用：

- `clean line art`
- `crisp black outlines`
- `sharp ink lines`
- `precise contour drawing`

这些词很容易重新触发 cel 化或漫画化。

---

## 改良版锚图提示词

用于第一阶段“源图 → 锚图”：

```text
生成一张供后续重绘使用的结构辅助参考图。

必须保留输入源图中的人物身份、人物数量、姿势、镜头、构图、头部位置、服装轮廓、主要背景布局和主要色彩关系，不要重新设计人物，不要改变发色、眼睛颜色、脸型或服装样式。

这不是线稿，也不是漫画墨线图，也不是赛璐璐图。保持原图的绘画性、软边、透明叠色、空气感和自然笔触。只对已有的主要边缘结构进行有限增强，使其更容易被后续重绘识别。

优先增强以下结构：
1. 人物外轮廓和肩颈轮廓；
2. 头发外轮廓和主要发束；
3. 刘海的分组边界；
4. 上下眼睑、眉毛、鼻唇和下颌；
5. 衣服的主要轮廓、褶皱方向和前景遮挡边缘。

每个主要发束由一条连续、自然弯曲的主导笔触统领，发束内部只保留少量方向一致的中长笔触。主要边界尽量保持为连续曲线，不要由大量短线、碎片和重复勾线拼接。

线条应有自然的粗细变化，线色随局部颜色变化，并与附近色块融合。保留柔和抗锯齿边缘和绘画笔触，只增强结构连贯性，不增加黑色外轮廓，不增加漫画化细节。
```

负面约束：

```text
避免黑色统一描边、硬黑外轮廓、赛璐璐分层、平涂、矢量线稿、漫画墨线、过度锐化、每根头发都勾线、密集短发丝、碎片化边缘、重复描边、交叉乱线、网纹、排线、噪点轮廓、额外饰品、额外人物、改变姿势、改变发色、改变服装和改变背景构图。
```

这里最重要的改动是把“结构清晰”具体化为：

- 主要边缘；
- 连续曲线；
- 每个发束一条主导线；
- 少量中长笔触；
- 不用短碎线填充。

这样更有机会把锚图的平均段长从目前的 **103–150** 再往上推，同时避免重新触发 cel 化。
