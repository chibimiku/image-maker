- 亮度 P95 / P99；

1. 单纯高调画风；

# 2. 肉眼缺陷的严重程度排序

由于图片本身未传到当前上下文，下面是建议的**验收优先级/高风险排序**。

## 1）保脸区域与重绘区域的接缝——最高风险

重点检查：

- 下颌到脖颈；
- 耳朵、鬓角、刘海；
- 脸与头发交界；
- 面部边缘的线宽和锐度；
- 肤色与颈部、手部肤色是否一致；
- 脸部噪声/纹理是否与插画化身体不同。

如果“保脸”保留的是重绘前的插画脸，问题通常是锐度、线密度和色温不一致；如果保留的是照片像素，则会出现更严重的“真人脸贴在插画身体上”的拼贴感。

羽化只能隐藏硬边，不能自动解决：

- 局部色温不同；
- 线条频率不同；
- 明暗塑形方向不同；
- 发丝跨越保护区后被切断。

建议至少有一个“接缝环”处理：脸核心区完全保护，外围一圈允许低强度重绘或做颜色与线条融合。

## 2）手部及手套状态

“锁定戴手套”只能锁语义状态，不能保证：

- 手指数正确；
- 手掌和手腕连接自然；
- 左右手套造型一致；
- 袖口、手套口不粘连；
- 手指关节不融化；
- 手与衣物、花束或身体不穿插。

由于手参与了整身重绘，而脸没有参与，人物内部会同时存在两套更新强度，容易使手的画法比脸更厚、更简化或更“模型化”。

应把以下检查独立自动化：

- 手指数；
- 手套颜色一致性；
- 手部局部锐度；
- 袖口闭合轮廓；
- 双手尺寸和左右对称性。

## 3）整体发白、低饱和和白色细节丢失

这是指标已经能够确认的全局风险。

尤其要看：

- 白花、白裙、蕾丝与背景是否融成一片；
- 肤色是否泛灰；
- 阴影是否被抬得过高；
- 黑发是否变成浅灰；
- 鞋底、裙边、袖口是否缺乏层次。

最终图比历史最佳亮 18.5、饱和低 11.6，肉眼上大概率会显得更“洗白”。这通常比单个小部位错误更影响整体成片质感。

## 4）发丝断裂、粘连或被拉成长硬线

本轮段长异常偏高，发丝是最容易暴露问题的区域：

- 刘海跨过保脸边界时被截断；
- 零散发丝被结构线叠加成粗硬长线；
- 多根发丝合并成带状轮廓；
- 头发内部仍有短碎线，但外轮廓过重；
- 发梢与背景出现双边或黑边。

建议发丝不要使用与衣服外轮廓相同的结构线叠加强度。

## 5）鞋子、蕾丝和裙边等高频细节

这里容易出现两种相反问题：

- 提线后图案过密、发脏；
- 重绘后细节被概括成不连续或无意义纹样。

重点看：

- 左右鞋结构是否一致；
- 鞋底透视和脚踝连接；
- 鞋带是否形成闭环或穿插错误；
- 蕾丝孔洞是否规律；
- 裙边是否出现重复纹理、伪文字或局部融化。

最终碎线占比仍为 0.007，是历史最佳的两倍多，细碎装饰区很可能是主要贡献源。

## 6）背景风格及局部贴回的一致性

由于局部重绘区域覆盖整身、背景大概率沿用底图，人物轮廓附近容易出现：

- 羽化光晕；
- 双轮廓；
- 人物边缘背景被污染；
- 重绘区域与原背景颗粒度不同；
- 地面接触阴影方向不一致；
- 头发和裙边之间残留旧像素。

如果背景本身是高亮浅色，这些接缝可能在普通尺寸下不明显，但在深色显示器或提高对比度后会很明显。

# 3. “直接用分析原图做首图”何时更划算

## 更划算的场景

### 1）构图、姿势和人物身份必须高度保真

例如：

- 商业人物照转插画；
- 委托人要求脸、姿势、服装不能漂；
- 手持物、配饰、衣服纹样需要保留；
- 背景空间关系不能改变。

这种情况下，先让 gpt-image 重新生成一张首图，实际上多引入了一次语义漂移和身份漂移。直接编辑照片更短、更稳定。

### 2）目标只是“风格化”，不是重新设计

例如：

- 保持原人物和场景，只转成 tinkle 风格；
- 不改镜头、不改姿态、不换服装；
- 不需要新增大量画面元素。

直接重绘原图通常能节省一次生成成本，也减少后面修手、修脸和修构图的概率。

### 3）原图质量高、遮挡少、结构明确

本次原图是 6336×9504，高分辨率本身有利于：

- 五官定位；
- 手指结构；
- 衣褶和鞋型；
- 发丝及装饰物边界。

当然，送入模型前仍应按模型输入策略缩放，不应直接依赖超大尺寸带来输出分辨率提升。

### 4）当前首图生成阶段持续产生发白、低饱和偏差

本次首图已经把亮度拉到 212.1、饱和降到 41.2。直接从照片进行受控重绘，至少有机会减少“先洗白一次，再在洗白结果上继续加工”的累积偏差。

---

## 不适合或不能直接使用的场景

### 1）目标风格要求大幅改变人体比例或视觉语法

例如：

- Q 版、娃娃化；
- 极端大眼、小脸；
- 平面海报化；
- 大幅改变透视；
- 油画、水墨等需要重构形体的风格。

此时照片结构反而会把模型锁得太死，容易形成“照片套滤镜”，而不是目标画风。

### 2）需要显著改变内容

例如：

- 换服装；
- 改姿势；
- 替换背景；
- 新增复杂道具；
- 从半身扩展到全身；
- 修复原图里被遮挡的肢体。

这种任务先生成语义合理的中间首图更有价值。

### 3）原照片的光照、纹理和景深会污染目标风格

例如：

- 强烈摄影棚高光；
- 复杂皮肤纹理；
- 大面积散景；
- 压缩噪声；
- 背景杂物很多；
- 衣物花纹过密。

直接重绘可能保留过多照片感，或让线条检测把阴影、毛孔、布纹都当成结构。

### 4）源图本身有严重结构问题

例如手被遮挡、鞋出画、肢体透视极端、头发与背景难分。此时“忠实于原图”不一定是优点，需要先重建一个更适合插画化的中间图。

## 建议的路线选择规则

可以简单划分为：

- **内容保真优先**：原图直接重绘；
- **设计变化优先**：先生成首图，再做提线与局部修复；
- **介于两者之间**：原图作为强结构参考，风格图作为风格参考，而不是只靠文字锚重新生成。

# 4. 比例锁修法及隐患

## 修法是否合理

合理，而且从结果看确实解决了最严重的问题：

- 旧结果：2048×2048，比例 1.000；
- 新结果：1696×2528，比例约 0.671；
- 源图：0.667。

显式指定官方比例比依赖 `auto` 更可靠，尤其是在：

- 双参考图；
- 长提示词/长固件；
- 编辑或重绘接口；
- 多个输入图比例不一致

这些情况下。

不过这应被视为**第一层保护**，不能认为比例问题已经完全解决。

## 隐患 1：1696×2528 仍不是严格 2:3

1696 / 2528 ≈ 0.6709，而严格 2:3 是 0.6667，差约 0.63%。

差异不大，但如果贴回时直接把它非等比缩放成严格 2:3，会造成：

- 人脸轻微横向压缩；
- 细长物体宽度变化；
- 局部重绘区域和底图坐标不完全对应。

更好的处理是：

- 优先等比缩放；
- 再做少量中心裁边或按主体锚点裁边；
- 不要分别拉伸 X、Y。

以 2528 高计算，严格 2:3 宽约 1685～1686，1696 宽只需裁掉约 10～11 像素，通常比非等比压缩更安全。

## 隐患 2：局部裁切区选择 3:4 后，不能直接拉伸贴回任意 ROI

如果原局部区域不是严格 3:4，而是“选择最近的官方比例，然后请求 3:4”，生成结果不能直接缩放到原 ROI 的宽高。

否则会出现：

- 手变宽或变窄；
- 脸形变化；
- 衣服纹样形变；
- 羽化边缘与原图不重合。

正确做法应是：

1. 计算 ROI；
2. 将 ROI 向外扩展或补透明/上下文 padding，使画布成为官方比例；
3. 蒙版、源图、参考输入使用同一个补边画布；
4. 输出后按同一几何变换等比映射；
5. 去掉 padding；
6. 再贴回原 ROI。

也就是说，应该“补画布适配比例”，而不是“把内容拉成比例”。

## 隐患 3：最接近比例的选择可能抖动

当两个官方比例都很接近时，ROI 尺寸轻微变化就可能从 2:3 切到 3:4，导致批次之间：

- 输出尺寸变化；
- 主体占比变化；
- 模型构图倾向变化；
- 羽化宽度的实际视觉尺度变化。

建议：

- 给比例选择加入滞回或固定规则；
- 人物整图优先锁源图比例；
- 局部 ROI 优先扩展到预定比例，而非每次重新择近；
- 将选择结果和 padding 参数写入运行日志。

## 隐患 4：多参考图可能重新影响构图

显式比例能约束画布，但不能保证模型不在画布内部重新缩放或移动主体。需要额外检查：

- 人物 bbox 的中心偏移；
- bbox 宽高变化；
- 脸部关键点位移；
- 蒙版外像素是否被改写。

## 建议增加的硬性验收

每次模型返回后立即检查：

- 输出比例误差；
- X/Y 缩放比差异；
- 主体 bbox 偏移；
- 关键点位移；
- 蒙版外差分比例。

例如：

- 禁止非等比缩放；
- `|sx / sy - 1|` 超阈值直接失败；
- 全图比例误差超过 0.5% 时自动等比裁边；
- 局部重绘必须保存完整的 pad/crop/scale 变换矩阵。

因此，当前修法可以评价为：

> **方向正确、足以止住 1:1 灾难，但仍需补上 pad/crop/坐标回映，才能成为可靠的比例锁。**

# 5. 下一步最值得做的 3 件事

## 第一优先：加入稳定的色调校准，先解决发白和低彩度

这是成本最低、覆盖全图、收益最直接的一项。

建议不要只在 prompt 里写“不要发白”，而是在后处理增加可测量的色调校准：

- 使用 Lab 或 OKLab 做亮度与色度分离；
- 将平均亮度从 206.9 拉回约 190～198 的区间；
- 将饱和度/色度提升到接近历史最佳的 50～56；
- 对高光使用曲线压缩，而不是整体简单变暗；
- 肤色、白花和白裙使用保护蒙版；
- 增加高光剪切比例检测。

同时检查 `tinkle` 的 664 字符短版是否遗漏了全量 prompt 中有关：

- 阴影深度；
- 色彩浓度；
- 避免 washed-out；
- 白色物体层次

的关键约束。字符数在上限内不代表信息完整，短版可能恰好删掉了最重要的反发白描述。

## 第二优先：把结构线叠加从固定 0.50 改为分区或自适应

现有证据很明确：线条过长主要是后处理造成的。

建议先用同一个首图做低成本消融，不需要重新生成：

- 0.50：当前基线；
- 0.35；
- 0.25；
- 主轮廓 0.40、内部细节 0.20；
- 发丝/蕾丝/鞋带区域禁用或减半。

验收目标不应只追求更长段长，而应同时看：

- 段长；
- 端点密度；
- 碎线占比；
- 长线占比；
- 人脸、发丝和蕾丝的局部指标。

比较合理的方向是让最终段长靠近历史最佳的 115～125，而不是继续维持 142；同时把端点压到约 20，碎线尽量接近 0.003～0.005。

## 第三优先：完善局部重绘的几何闭环和保脸融合

将以下几件事作为一项工程改造完成：

1. ROI 自动 padding 到官方比例；
2. 输出只允许等比缩放和裁边，不允许 X/Y 独立拉伸；
3. 保存坐标变换矩阵；
4. 保脸蒙版分为：
   - 核心保护区；
   - 过渡融合环；
   - 正常重绘区；
5. 过渡环执行颜色、锐度和线宽匹配；
6. 对发丝跨脸区域使用独立蒙版；
7. 对手和手套增加专门的语义/结构验收。

这一步比单纯扩大羽化半径更重要。羽化过大可能只是把接缝变成一圈模糊带，并不能解决风格和色调不一致。

## 推荐的最小验证矩阵

下一轮无需大规模重跑，可以固定同一首图，只测试：

| 方案 | 结构线强度 | 色调校准 | 保脸融合 |
|---|---:|---|---|
| A | 0.50 | 无 | 当前 |
| B | 0.35 | 无 | 当前 |
| C | 0.35 | 有 | 当前 |
| D | 0.35 | 有 | 核心区 + 过渡环 |

这样能够快速区分：

- 线条过冲是不是由 0.50 导致；
- 发白是否可由确定性后处理解决；
- 接缝是否主要来自保脸贴回方式。

最终建议不要只按单个线条指标选图。至少同时设三类门槛：

1. **几何**：比例、关键点、手部、贴回形变；
2. **线条**：端点、段长、碎线及局部线宽；
3. **色调**：亮度、色度、高光剪切和肤色偏移。

当前版本可以评价为：**比例灾难已修复，线条连续性明显改善，但提线略过量；色调仍未达标，保脸局部融合是最大的潜在成片风险。**
