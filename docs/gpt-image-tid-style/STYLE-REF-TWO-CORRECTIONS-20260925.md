# 完整画风图默认方案与两轮身份修订（2026-09-25）

## 最终配方

单图分析的 GPT 通道默认配方升级为 v5：

1. GPT 首图继续使用内容锚、完整画风文字和画风参考图。
2. Gemini 2K 重绘接收两张图：GPT 首图为内容与身份真值，完整画风图只负责渲染语言。
3. 文本模型读取**实际发送给 GPT 首图的最终 prompt**和当前图片，从中提取稳定身份锚点，并列出明确差异。
4. 有高置信差异时，Gemini 最多执行两轮定点修订。每轮完成后重新审计当前图，下一轮只处理尚未通过的差异。
5. 两轮后仍有差异则保留最后一轮图并标记复核，不回退 GPT 首图。

结构线、局部贴回、色调校准和加墨仍默认关闭。

## 两轮修订为何比一次更有效

历史 tinkle 大偏离样本包含蓝发、蓝眼和长拖尾裙，而实际首图 prompt 要求暖棕发、青绿色眼睛和短层叠裙：

- 初始重绘：审计为 major。
- 第 1 轮：只修正发色和瞳色。复审确认颜色已正确，随后识别出剩余的长裙问题。
- 旧第 2 轮：普通“缩短裙子”指令只把部分裙褶改短，仍保留大块拖尾，复审为 minor。
- 通用结构例外：仍保留拖尾，复审反而为 major。
- 改进第 2 轮：明确“可见主裙摆止于坐姿上大腿、删除该位置以下所有裙片/拖尾、不得改名为后摆或衬裙、按邻近证据补回椅子和地面”，复审通过。

这验证了两轮闭环的价值：第一轮修正显著颜色偏差后，第二次视觉审计能更准确聚焦剩余结构问题。一次把发色、瞳色、裙型同时交给 Gemini，容易导致大范围重画。

## 提示词改进

身份审计现在返回 `stable_anchors`，来源是实际 GPT 首图 prompt，而不是泛化的长篇分析描述。修订 prompt 包含：

- 当前轮次，例如 `PASS 1 OF 2`；
- 全部稳定身份锚，作为锁定项；
- 本轮审计仍不符合的差异；
- 禁止削弱当前已经改善的线条连续性；
- 对裙长等结构差异，提供局部几何终点、必须删除的错误结构和背景补全方式。

结构修订会改变较大面积，自动线条指标可能下降。例如成功短裙修订的段长为 73.2，而未完全修对裙型的旧第二轮为 82.1。因此身份正确性与线条指标必须分别检查，不能为了指标保留错误服装。
