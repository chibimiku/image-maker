横图被生成成纵图：根因与修复

任务 691f9293 的分析 JSON 明确记录 aspect_ratio=4:3，但 GPT 首图请求记录为 size=1024x1536，首图实际也是 1024×1536；Gemini 重绘随后保持为 1696×2528。根因不是重绘，而是 GPT 首图尺寸选择误用了纵向 TID 画风参考图。自动任务包没有携带原图路径，剪贴板输入又天然没有文件路径，于是风格图成为唯一候选。

修复后顺序：原始分析图实际像素 → 分析 JSON 的 source_image_path → 分析得到的 aspect_ratio。画风参考图不再参与画幅选择。4:3 会映射到 1536×1024。
