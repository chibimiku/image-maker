# 拦截后的合规替代方案研究

用户要求不要停留在否决，尽可能提供允许范围内的新提示词。旧实现只有原目标能够保留时才给 prompt，参考图被认为不适合就直接终止；这导致两个普通礼服素材没有得到可用的新方案。

新版要求文字接口优先构造实质不同的安全替代：原照片中的完整礼服与身份特征保留，去掉内衣改款、身体材质和挑逗性表达。若画风参考图不适合新的普通服装插画，明确 reference_policy=none，首图及之后的重绘不再发送该图；使用普通调色、笔触和纹理文字近似部分画风。完整替代 prompt 取代原请求，不叠加旧改款指令。仍不能提供安全替代时保留失败，第二次拦截不继续循环。

精确的在线生成方案已保存为 `safe-alternatives-20260928/satou-plan.json` 和 `wardrobe-plan.json`。生图参数、回放和输出位于 `data/test-result/20260928/safe-alternatives/`。

测试提示词已有完整主体描述；后续模板进一步明确无附图时不能让生图模型查看未提供的源照片，并优先用正面服装描述，不重复罗列已删除的敏感改款。这条措辞补充没有额外重新生成本批图片。

## 实现和验证

`utils/first_image_review.py` 输出明确的参考图策略和安全渲染条款。GUI/CLI 后续工序清除旧改款、身份回改、画风收尾和旧风格目标，停用不合适的参考图及基于该图的色调操作；保留正常人体检查。原请求与参考图路径、改良原因、尝试状态、成功输出均保留。未提交过替代的旧否决断点可以按新版规则再研究，已经提交过的替代不自动重复收费。

7项安全替代回归、5项最终修复回归通过，修改文件语法编译通过。缓存、二次拦截、普通网络错误不触发、参考图从首图和后续工序移除、旧否决方案升级均有回归覆盖。
