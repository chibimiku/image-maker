# 画风五官与头发画法优化（2026-09-26）

## 目标与控制变量

固定使用素材 `data/20260921/sucai/2026-07-24 12_17_40_1.jpg` 及 2026-09-25 已生成的同一批 GPT 首图，只改变画风文字和 Gemini 重绘逻辑。完整图片横向对比见 [style-face-refine-20260926.html](style-face-refine-20260926.html)。

## 已固化的逻辑

1. 完整画风图重绘允许迁移五官与头发的**抽象绘画语法**：眼睑角度和线重、睫毛分组、虹膜与瞳孔比例、眼部高光设计、脸颊到下颌的简化、发束分组、轮廓节奏、内部发丝密度和高光形状。
2. 源图继续决定角色身份、表情、视线、瞳色、发色、具体发型与长度、服装、背景、构图和裁切。上述画法例外不允许复制参考图角色。
3. `face_hair_refine=true` 的画风在首次完整重绘后，再发送“当前图 + 完整画风图”做一次只针对面部和头发画法的修订。目前仅对 `puracotte-style-v2` 和 `say-hana-v4` 开启。
4. 修订后执行基于实际 GPT 首图提示词的身份审计；检测到发色、瞳色等差异时，只发送当前图和文字差异做最多两轮定点修正，不再附带画风图。
5. `skip_quality_refine=true` 用于首次完整画风重绘已经优于 source-only 二次质量修订的画风。目前仅 `iris-mix-style` 开启。

## 实测结果

- `puracotte-style-v2`：专用修订明显增强圆润大眼、上睑、宝石状虹膜和顺滑发束。第一版条款中写了紫粉虹膜环，确实造成紫瞳泄漏；改成“只用源瞳色族构建层次，禁止借参考图虹膜色”后，青绿瞳直接通过身份审计，无需补救修订。
- `say-hana-v4`：矿物颜料、深橄榄轮廓、发束组织保持稳定，专用修订没有造成身份偏移；眼型提升较克制，仍是后续可继续加强的一项。
- `dall-e-v2`、`sheya-style`、`shiratamaco-v2-style`：分别改善了眼部层次、锐利眼角、可爱夸张脸部比例。
- `satou_kuuki-style-v2`：衣装出现更明确的皮革质感、反光与缝线。
- `waterink-style`：粗线、水墨晕染与纸面留白成为主导语言。
- `inf-nikki-v1`：转向 UE5/PBR/体积光的实时角色渲染，不再只是普通二维 anime。
- `ajicoma`：降低过亮高光，并加入细花边、票券和邮票式装饰语汇。
- `goto-p`：透明水彩叠染、柔软边缘和背景消散更明显；本轮身份审计确认未带入参考图瞳色。

## 画风启用状态

配置条目新增 `enabled`。app.py 的画风编辑区可切换“在生图与测试画风列表中显示”。管理列表始终保留全部画风；所有生成下拉、服饰采集画风数据和无头 `--list-styles` 只列启用项。缺少该字段的旧配置兼容为启用。

本轮隐藏旧版/重复项：`puracotte-style`、`puracotte-v3`、`tinkle`、`fuzichoco`、`dall-e`、`dall-e-v3`、`satou_kuuki-style`、`shiratamaco-style`、`say-hana-style`、`say-hana-v2`、`say-hana-v3`、`say-hana-v5`。

## 局限

专用五官/头发修订是一次完整图编辑，不是像素遮罩编辑。它已通过强范围锁和后续身份审计降低越界，但不能保证每次只改变头部像素。参考图角色本身的瞳色、发型和脸型仍可能影响模型，因此每条画风文字不能写入参考角色的固有颜色；应写“源角色自身颜色下的结构与层次”。
