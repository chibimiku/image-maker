# 最终候选图兜底

最终图片审计沿用配置中的文本通道，当前解析结果为 `gpt-6-luna`。
文本模型接收图片并返回缺陷 JSON，检查逐角色肢体归属、手脚、连接、显式比例目标及画风。
不对 Q 版施加成人比例，不凭空补遮挡肢体。归属不明确时要求人工检查。

GUI 最终审计发现明确缺陷后保存 JSON 与修复提示词，以当前图单图调用 Gemini。
默认 `gemini-3.1-flash-image-preview`，最多一次；配置为
`prompts/gpt-image-optimize/config.json` 的 `final_candidate_repair`，max_repairs 可设 0–2。
本地价格快照 Flash 单次基价 0.1655、Pro 0.33；不是实时价格或稳定性保证。
按源图尺寸选 1K/2K/4K，使用 auto 比例，严格核对返回像素尺寸。
微小舍入不足（每边不超过 8 像素且差值不超过对应边的 0.2%）只延展边缘像素补齐画布，
不缩放人物、不裁切；其余尺寸变化、联网失败、复审失败均不发布。
成功图片调用缓存，复审失败续跑不重复生成。
无缺陷只审计；修图后重新审计；原候选保留。

CLI 有参考图的最终审计复用该函数；上游质量与身份门禁仍可能提前停止。
五项无网络 unittest 验证修后复审、尺寸参数、提示词落盘、不确定归属、微小画布补齐、
GUI 测试过程隔离与发布 hash 保留。
随机五图在线测试中 Flash 两次均返回图片，1694×2528 比 Pro 的 1696×2528 少 2 像素；
补齐后两张均通过文本复审，断点复用未重新收费生图。仍不能据此保证所有 case 稳定。
