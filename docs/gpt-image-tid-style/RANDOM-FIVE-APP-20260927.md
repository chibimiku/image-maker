## 被拦截请求的实质安全修改

新增 `utils/first_image_review.py` 与 `prompts/first-image-safe-review.md`，GUI 与 CLI 首图共用。只有显式 moderation_blocked/content_policy_violation 才触发文字复核；普通网络错误不触发。复核必须提供基于素材的实质修改及理由，禁止年龄虚构、关键词掩饰或保留不安全目标。参考图也参与复核；无法安全保留目标时停止。

最多一次改良提交；GUI 断点缓存方案、尝试状态和成功产物，二次拦截保持失败。重启首图工序才清除这份记录。五项独立回归用例通过：明确拦截识别、普通失败不分析、否决不重试、成功缓存、二次拦截不重复提交。

在线使用临时 GPT 5.6 Luna 对两个拦截请求及原照片/参考图复核，均返回 retry_allowed=false：satou 的参考图被判为明显性化；wardrobe 的参考图及内衣改款指令不适合本次普通服装插画。未再次调用图片接口。模型判断保存在各任务目录的 first-safe-review-online.json；这是复核模型的判断，不是服务端对原拦截原因的说明。

后续用户要求尽可能给出合规新方案。新版已为两例生成不附原画风图的完整礼服替代 prompts，并各成功生成一张首图；具体实验与画风退化限制见 `SAFE-ALTERNATIVES-20260928.md`。本表保留原五图全链路结果，不把新首图算作原流程完成。
