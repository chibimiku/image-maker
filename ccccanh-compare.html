5. 结论速览

  • 甲级（同类根因）：millon-knots —— prompt_gemini 与 prompt 逐字相同且缺内容锚。sheya-style 写法相同但只有 1097 字符，不构成问题。
  • 乙级（系统性缺口）：启用且有参考图的 25 个画风里，21 个缺 gemini_content_field。旁证：原本唯一配了该字段的 3 个画风（sheya / kishida-mel / sakurapion）正是历史上被反复判「不像」的那几个，`GEMINI-STYLE-SIMILARITY-20260927.md` 记 tid 补了 `prompt_gemini` 后 0.7052 → 0.8558。
  • 隐藏依赖：内容锚字段只在本次任务算过 gpt prompts 时才存在；今天 20261006-014944-abc123-白发少女.json 就是 0 字符 → 会静默退回长描述。
  • 丙级（疑似未确证）：taya_oco（1:9）、renian（1:10）、myc0t0xin（无 compressed，回落 prompt_gpt 584）、sakurapion-style（实收 2573）。
  • 指标口径提醒：Gram / AdaIN / LPIPS / CSD 与 render_score 都是诊断量，不是验收标准 —— 这次 taya_oco 就是「指标不动、观感也没变」的例子。
