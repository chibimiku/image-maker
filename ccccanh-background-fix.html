1. 根因：三条叠加

① 内容锚太薄：priority 模式用的是 gpt_image_prompt_short，只有 351 / 480 字符； 完整场景在 english_description（3317 / 3264 字符）里 —— 抓娃娃机、玻璃柜、价格标签、玩偶、书架、窗、墙纸 根本没进请求。
② 我上一轮的 v5 规格里有"少画"指令：background painted only where the description asks + pale subordinated surroundings —— 锚已经薄了，这句等于判定"背景没被要求"。
③ 参考图是高饱和洗色（饱和度 53.8），纯度不足时模型退化成"白底上画个人"。

3. 三种改法（round13，两个案例上都测）

每行左边是参考图。第 1 行=现状（背景几乎全空）、第 2 行=v7 规格+短锚（房间/窗/书架回来了）、第 3 行=v7 规格+长锚（结构最全但湿边被削弱）。

案例 2：第 2 行新增了墙面与灯的层次、床品结构；第 3 行进一步补齐但整体偏干。

4. v7 规格加了什么

SCENE COMPLETENESS (do not skip):
7. Paint the ENTIRE setting the text describes — every wall, window, furniture, prop, object,
   plant, decoration and background figure it names — in the same watercolour language.
8. Lightness is a matter of VALUE and EDGE, not of deletion: keep each background element readable
   at a pale value with soft edges. Never replace the described setting with an empty or blank field,
   never delete or merge objects the text names separately, never move the subject onto a bare backdrop.
9. Keep the number of subjects and background elements exactly as described.
Density: a finished watercolour plate, not a cut-out figure on blank paper.
